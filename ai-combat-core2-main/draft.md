# INDI 제어기 최적화가 F-16 근접 공중전(Dogfight) 성능에 미치는 영향 — 논문 초안

> 작성 상태: 방법론·실험설계·결과(E4·E3·E5·E2) 반영 완료 (2026-09-29). 서론·논의 문장화 남음. 수치 출처는 `results/indi/summary.md`
> (자동 생성: `research/indi/analyze.py`). 근거 문헌·결정은 `paper.md`, 실험 경과는 `plan.md`.

## 1. 서론 (골격)

- 배경: AI 공중교전 연구는 전술 판단층(규칙기반·강화학습)에 집중해 왔고[1][3], 저수준 비행제어기는
  고정된 도구로 취급되는 경향이 있다. 그러나 전술 판단이 요구한 기동을 기체가 얼마나 정확·신속하게
  실현하는지는 교전 결과에 직접 영향을 준다 — 교범은 기총 사격해가 "표적 기동면·속도·G 가 일정할 때만"
  성립하며 조준 오차에 조종 오차가 포함된다고 명시한다[6].
- 선행 근거: 계층형 RL 교전 연구[3]는 동일 전략에서 비행제어기만 RL→PID 로 교체하자 승률이
  0.844→0.313 으로 하락함을 보였다. 다만 G·AoA 한계 준수는 검증되지 않았다.
- INDI 는 센서 기반 증분 제어로 모델 오차·외란에 강건하며[2][5], 고정익 실기 비행시험으로 검증되었다[G].
  그러나 INDI 파라미터 튜닝이 **교전 성과**에 미치는 영향을, **실제 F-16 한계 준수** 조건에서 정량화한
  연구는 없다.
- 기여:
  1. JSBSim F-16 기반 5계층 교전 스택에서 INDI 6개 파라미터의 추종 성능·조종 부드러움·교전 성과를
     단일 변수(E2)·복합 최적화(E4)·대응 비교(E3)·강건성(E5)으로 체계적으로 분석
  2. 교범(MCH 11-F16 Vol.5) 기반 가용 G 봉투와 달성 하중 감시로 모든 설정의 물리 한계 준수를 검증
  3. 공개 JSBSim F-16 모델의 flaperon 혼합 부호 결함(롤 명령 → 대칭 양력)을 식별·수정

## 2. 시뮬레이션 환경

### 2.1 교전 스택 (5계층)
| 계층 | 주기 | 역할 |
|---|---|---|
| L1 전술 행위트리 | 20 Hz | 추격 유형·G 버스트·조준점 기하 선택 |
| L2 BFM 가이던스 | 60 Hz | 교범 기반 G 조절, 리프트벡터 배치(롤 증분), 추력 |
| L3 제어 | 120 Hz | 쿼터니언 자세 shim → 한계 리미터 → **INDI 각속도 제어** |
| L4 비행역학 | 120 Hz | JSBSim 1.3.1 F-16(내장 FLCS 포함) |
| L5 디브리핑 | — | 읽기 전용 기록 |

INDI 출력은 조종면이 아니라 FLCS 명령 입력(`fcs/*-cmd-norm`)이며, 효과행렬 G0 는 트림점에서 ±0.02 섭동의
중앙차분으로 식별하고 동압 비례로 스케줄한다: G = (q̄/q̄_ref)·G0.

### 2.2 INDI 제어 법칙과 튜닝 변수
ν = K(ω_sp − ω_f) + k_ff·d(ω_sp,f)/dt,  Δu = (GᵀG + λ·diag(GᵀG))⁻¹ Gᵀ(ν − ω̇_f),  u = u_f + Δu

- 각가속도·조종명령·각속도에 동일 2차 Butterworth 동기화 필터(차단 f_c)
- λ 는 Levenberg–Marquardt 형 채널별 정칙화 — 단일 스칼라 정칙화는 효과가 작은 요 채널의 수렴을 막음을 확인
- 튜닝 변수 6개와 탐색 범위 (문헌 공통 변수, `paper.md` §7):

| 변수 | 의미 | 기준값 | 범위 | 근거 |
|---|---|---|---|---|
| k_p | 롤 각속도 게인 [1/s] | 9 | 4–20 | [2][5] |
| k_q | 피치 각속도 게인 [1/s] | 9 | 4–20 | [2][5] |
| f_c | 동기화 필터 [Hz] | 25 | 3–40 (로그) | [2][4][5], 실기 3.2 Hz[G] |
| k_att | 자세 게인 [1/s] | 4 | 2–8 | [2] |
| k_ff | 각속도 명령 피드포워드 | 0 | 0–1 | [2][4] |
| λ | Δu 정칙화 | 0 | 0–0.5 | [3][4] |

### 2.3 F-16 물리 한계 (교범 해석 봉투)
교범[6] §4.6.5.2: 최대 AoA/G 선회반경은 170–330 KCAS 에서 일정, 최대 G 는 440 KCAS 에서 도달.
G_max(V) = 6.75(V/330)² (V<330), 9V/440 (330≤V<440), 9 (V≥440); 음의 한계 −3G, 롤 220°/s.
교차검증: 350 KCAS → 7.16 G (교범 EEGS 가정 7.3 G). 리미터는 이 봉투로 각속도 명령을 제한하고,
**달성** 하중배수 Nz 를 매 틱 감시해 구조한계(+9/−3G) 초과 또는 봉투 +0.5 G 초과 시 실격 처리한다.

### 2.4 비행 모델 수정 (f16fix)
공개 JSBSim F-16(pip 1.3.1 및 2026-09 기준 master)의 flaperon 혼합은
left = −tef − ail, right = +tef − ail 로 합이 −2·ail 이 되어, 롤 명령이 대칭 양력·항력을 만든다
(5,000 ft/400 KCAS, 승강타 고정 에일러론 단독: 오른쪽 −2.1 G, 왼쪽 +4.1 G). 원본 모델에서는 기준 제어기도
교범 봉투를 36기체 중 28 회 초과(최대 10.7 G)했다. 기준 공력 데이터(NASA TP-1538 → Stevens & Lewis →
NASA TM-2003-212145)의 수직력 계수 CZ = f(α, β, δe, q) 에는 에일러론 항이 없으므로, 오른쪽 aileron 부호를
반전해 좌우 상쇄시켰다(CLDflaps ≡ 0). 롤 성능은 유지(±84.7°/s, 원본 85.8/85.3), 수정 후 기준 제어기의
봉투 초과는 0/60. 한계: 저속(<250 kt) 후연 플랩 양력은 원본처럼 0 이며, 코너 플래토 밖이라 영향이 작다.

### 2.5 센서 모델
각속도 자이로에 백색잡음 σ = 0.1°/s(명목, 실기 Citation II 의 0.036°/s@52 Hz[G] 를 120 Hz 로 환산한
약 0.055°/s 의 2배), 스트레스 0.3°/s. 각가속도는 동기화 필터된 차분으로 추정. 참값 각가속도를 쓰면
f_c 변화가 추종에 전혀 영향을 주지 않아(8–40 Hz 동일) 필터·정칙화의 잡음↔지연 상충이 사라지므로
잡음 모델을 필수로 두었다.

- **k_q 는 추종 성능의 지배 변수**: ×1.5 이상에서 잡음 증폭으로 추종이 발산(J 3.0 절단). k_p·k_att 는 단독으로는
  추종·교전 모두 거의 무영향.
- **f_c 는 6 Hz 부근에 최적**(J −7 %), 40 Hz 에서 J +32 % — E4 의 3–8 Hz 수렴과 일치.
- **k_ff 는 단독으로는 해롭다**(f_c 25 Hz 에서 J ×3): 계단형 60 Hz 명령의 미분을 넓은 대역 필터로 통과시키기 때문.
  E4 최적해는 k_ff 0.28 을 f_c 4.3 Hz 와 **함께** 선택 — 변수 간 상호작용으로, 단일 변수 스윕만으로는
  최적에 도달할 수 없음을 보여 복합 최적화(E4)의 필요성을 뒷받침한다.
- 교전 수준의 단일 변수 효과(Δ승점 ±0.15)는 대부분 CI 가 0 에 걸치며, 50 쌍·24 수준 다중 비교를 감안하면
  개별 수준의 유의성 주장은 삼간다(방향성 참고용).

## 5. 논의 (메모 — 문장화 필요)
1. **이상 조건에서 튜닝 효과는 작고, 현실 조건에서 크다.** 명목 조건(참값에 가까운 측정, 지연 0)에서 Δ승점은
   +0.025~+0.049 로 부호 검정 유의 수준에 미달했으나, 실기 수준 측정 지연(33/92 ms)에서는 +0.34~+0.46
   (p < 0.001)으로 승률이 0.45–0.52 → 0.86–0.93 이 됐다. 원인은 기준 INDI 의 좁은 지연 여유(E1 에서 피치 추종
   ISE ×51) — 튜닝은 지연 여유를 넓히는 방향(f_c 25 → 4–5 Hz)으로 수렴했고, 이 이득이 교전으로 전이됐다.
2. **추종 개선 → 승률 전이는 비선형.** 명목 조건 추종 −8~12 % 는 승점 +0.05 수준에 그쳤다. 논문 3 의
   대폭 효과(−53 %p)는 비스케줄 PID 대비였으며, 이미 강건한 INDI 의 미세조정은 한계효용이 작다. 반면
   기준 제어기가 **불안정 경계에 가까운** 조건(지연)에서는 같은 튜닝이 결정적이다.
3. **절충형(γ=0.3)의 가치: 동일 이상의 전투력 + 조종 활동 −84 %.** HP 차 기준으로는 잡음·G0 과대·난류·MC
   조건에서 성능형보다 일관되게 크고 유의(ΔHP +8~12, p ≤ 0.005) — 부드러운 제어가 피격을 줄인다.
   교범의 "신속함과 부드러움의 혼합"[6]과 정합.
4. **한계 준수.** 모든 실험(E2·E3·E4·E5 누계 약 4,300경기, 벤치 2,400평가)에서 교범 봉투 실격 0.
   튜닝이 물리 한계를 넘지 않고 교전 성과를 개선할 수 있다.
5. **변수 상호작용.** k_ff 는 단독 해롭지만 저대역 필터와 결합하면 유익 — 단일 변수 민감도(논문 2 방식)만으로는
   최적 설계에 도달하지 못하며 복합 최적화(논문 4 방식)가 필요하다.
6. 한계: 단일 blue 전술 트리, red 는 기준 INDI 고정, 시뮬레이션 전용, FLCS 경유 명령 구조, E2 표본(50 쌍) 제한,
   γ=0 해의 k_p·k_att 탐색 상한 접촉.
