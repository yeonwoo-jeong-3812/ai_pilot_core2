# L3 오토파일럿/제어 계층 비교 — core-live vs core2

> 대상:
> - core2 `control/{indi.py(207), attitude.py(88), limiter.py(73)}` — 3파일 분리 스택
> - core-live `control/{indi.py(214), lqr.py(253), autopilot.py(323), controller.py(65), linearize.py(124)}` — INDI+LQR 이중
> 방법: INDI 법칙·자세표현·리미터·제어기 다양성 4축 대조.

## 결론 먼저: **제어공학 품질=core2 우위 / 검증된 전투기반=core-live 우위**

이 계층은 L4(동일)와 달리 **실질적 설계 분기**가 있다. 요약:
- **core2**는 교과서적으로 *더 정확하고 감사가능한* INDI 스택(2차 동기화필터 + 쿼터니언 무특이점 + 분리형 감사 리미터). 순수 제어공학 품질은 **core2가 우수**.
- **core-live**는 *검증된 전투 기반*(LQR+INDI 이중 제어기 + 조건부 high-g/러더 전술게이팅)으로 **42/42를 실제 생산**. 제어 다양성·전투튜닝·실증은 **core-live가 우수**.
- ⚠️ **미검증 갭**: core2의 더 깨끗한 L3가 *더 나은 전투결과*를 낸다는 증거는 아직 없다. 도크트린 메모리([[ai-pilot-doctrine-optimizes-gun-wez-dwell]])상 "정교함이 이기는 게 아니다"가 반복 확인됐으므로, core2 L3 우위는 **후보 실험**이지 확정 우열이 아니다.

## 축 1: 제어기 다양성 — INDI-only vs INDI+LQR

| | core2 | core-live |
|---|---|---|
| 제어기 | **INDI 단일** (설계결정 D2: PID/LQR 명시 배제) | **LQR + INDI 이중** ("엔진 갈아끼우기") |
| LQR | 없음 | `lqr.py` GainScheduledLQR — Stevens&Lewis Riccati, Mach×alt 격자 K 보간 (정본/원본) |
| INDI 위치 | 순수 내측 rate-loop 독립 | 외측(고도/heading/속도 PI)+내측 INDI 번들, LQR와 교체 가능 |

- **core-live 이점:** 독립 제어기 2개 → **교차검증**("전술이 LQR·INDI 양쪽에서 이기는가"가 강건성 판별자, 메모리 canonical=both-INDI). LQR은 선형화 plant에 대해 증명적 최적. 폴백 제어기 존재.
- **core2 이점:** 단일 경로, 죽은 LQR 잔재 없음. INDI가 모델오차/비선형을 LQR보다 잘 흡수(thesis RMSE~23%↓). 배포 단순.

## 축 2: INDI 정확도 — 동기화필터·효과행렬 식별

| | core2 | core-live |
|---|---|---|
| 각가속도 추정 | **2차 Butterworth LPF** (accel·actuator **동일 동특성 지연정합**) | 단순 유한차분(동기화필터 **없음**) |
| 효과행렬 G | **온라인 유한차분 식별**(`identify_G0`, 조종면 섭동 중앙차분) | **LQR 격자 B 쌍선형 보간**(precomputed 선형화 재사용) |
| 근거 | Smeur et al. 2016 (clean-room, 라이선스 자유) | Şahin ITU 2025 thesis §3.4 |

core2 docstring은 동기화필터를 *"작동하는 INDI 루프의 핵심(the crux)"*이라 명시한다 — accel 추정과 actuator 지령을 같은 지연으로 정합해야 증분가정이 성립. core-live는 이 필터가 없고, 대신 결정론 sim에서만 유효함을 정직하게 명시(docstring 한계 §). 효과행렬도 core2는 비행조건별 온라인 식별(더 정확·자기적응), core-live는 LQR 선형화에 결합(INDI가 LQR 인프라에 의존).

- **core2 우위:** 교과서 정합, 노이즈 강건, 자기식별 효과행렬, LQR 비의존.
- **core-live 현실:** 더 단순하지만 *실제로 42/42를 이긴* 구현. 동기화필터 부재는 결정론 sim에서 무해(실측).

## 축 3: 자세 표현 — 쿼터니언 vs Euler

| | core2 | core-live |
|---|---|---|
| 표현 | **쿼터니언 shim**(D3, `QuaternionAttitudeShim`) | **Euler** φ/θ (MAX_THETA_RAD 클램프) |
| θ≈±90°(수직 BFM) | **무특이점**(gimbal lock 제거) | θ 클램프로 특이점 회피(수직 제약) |
| yaw | 자세추종 아님, r→0 감쇠 | 협조선회 + β→0 (전술게이트 러더) |

core2의 D3는 "루프·수직기동 = BFM이 실제 벌어지는 곳에서 Euler가 특이(gimbal lock)"라는 정확한 진단 위에 쿼터니언으로 수직기동을 무특이점 처리한다. core-live는 Euler를 쓰되 θ를 클램프해 특이점을 회피 — 대신 급수직이 제약된다(그럼에도 SMART_DIVE/CLIMB/VERTICAL_PURSUIT로 42/42 달성; 가이던스가 클램프 안에서 동작).

- **core2 우위:** 진짜 수직기동(루프·high-yo-yo)을 특이점 없이. 제어공학적으로 정석.
- **core-live 현실:** θ-클램프가 수직을 제약하지만 실증 승리에는 충분했다 — "수직 표현력이 승패를 가르지 않았다"는 증거.

## 축 4: 리미터 — 분리형 감사 vs 결합형 전술

| | core2 | core-live |
|---|---|---|
| 형태 | **분리 `CombinedLimiter`** (INDI 앞단 안전 실행기) | INDIController 내장(조건부 high-g 게이트 + MAX_PHI) |
| 한계 모델 | 코너 플래토 + (AoA_max→G) ∩ 구조 9G, 물리식 명시 | 4.8g 기본 + 조건부 8.2g(조준+에너지 게이트) |
| 감사가능성 | **플래그 반환**(어느 축 포화·g_max·q_max) — 신뢰성평가 로그 요건 | env-튜너블, 전술 게이트(추적시 러더/high-g) |

- **core2 우위:** 분리·재사용·감사가능(어떤 한계가 언제 걸렸는지 로그), 교범 근거(코너 플래토·9G 구조한계). "당김=조절, 상한=코너플래토"라는 D6 불변식을 명시 강제.
- **core-live 우위:** high-g 게이트가 *전술적*이다 — 조준 중+에너지 충분일 때만 8.2g로 컷(blanket 9g는 회귀). 안전클램프가 아니라 *승리에 기여한 전술 리미터*.

## 판정표

| 축 | 우위 | 성격 |
|---|---|---|
| 제어기 다양성(교차검증·폴백) | **core-live** | LQR+INDI 이중, both-INDI canonical |
| INDI 제어공학 정확도 | **core2** | 2차 동기화필터·온라인 G 식별 |
| 자세 무특이점(수직 BFM) | **core2** | 쿼터니언 D3 |
| 리미터 감사가능성·교범근거 | **core2** | 분리형 CombinedLimiter, 코너플래토 |
| 리미터 전술 기여 | **core-live** | 조건부 high-g 게이트(승리 기여) |
| **검증된 전투 실증** | **core-live** | 42/42 무패, both-INDI 300s |

## L3 총평

**core2의 L3는 동료가 우리 INDI의 거친 모서리를 다듬은 결과다** — 동기화필터, 쿼터니언 shim, 감사가능 분리 리미터는 우리 구현을 보고 개선한 정석화. **순수 제어공학 품질로는 core2가 명확히 우수**하다.

그러나 두 가지를 정직하게 병기한다:
1. **core-live L3만이 42/42 실증을 갖는다.** core2의 더 정확한 제어가 더 나은 *전투결과*를 낸다는 증거는 없다 — 도크트린 반복결과("정교함≠승리")를 감안하면 이는 확정이 아니라 **검증 대상**.
2. **core-live의 제어기 이중성(LQR+INDI)은 강건성 판별 인프라**다 — 전술이 양쪽 제어기에서 이겨야 canonical로 인정하는 우리 방법론의 토대. core2는 이를 버려 단순해졌지만 교차검증 능력을 잃었다.

**흡수 후보(core-live로 역이식 가치 큼):** ①INDI 2차 동기화필터(노이즈 강건·실HW 이식성), ②쿼터니언 자세 shim(수직 BFM 특이점 제거), ③감사가능 분리 리미터(신뢰성 로그·교범근거). 단 각각은 42/42 틱-동일성을 깨므로, 병합 전 both-INDI 300s 재검증 필수.

**검증 실험(후속 제안):** core2 L3 스택(쿼터니언+동기화필터+분리리미터)에 우리 챔프 전술(FullUnified BT)을 얹어 canonical 17 + held-out 25를 돌려, "더 정확한 L3가 전투결과를 개선/유지/악화하는가"를 실측. 이것이 L3 우열의 유일한 확정 방법이다.
