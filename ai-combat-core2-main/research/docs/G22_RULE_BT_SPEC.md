# G22 — 12문장 규칙의 행동 설계도 (정형 명세)

작성 2026-07-16. 이 문서는 데이터에서 뽑은 12문장 규칙(내력은
`rollout_distillation_methodology.md` 4부)을 **조종사 프로그램이 그대로 실행할
수 있는 설계도** 형태로 적은 것입니다. 모든 용어는 아래에서 풀어 씁니다.

- 이 문서의 12문장 단독 검증 성적(성적 계보 [4]단계): 배운 상대 84판 78승 6패
  (사람 손튜닝과 동률 = 대체 성공), 처음 보는 상대 44판 42승 2패.
- 이후 반복 루프가 지는 판 8개에서 **귀납 문장 6개**를 추가로 만들어
  (계보 [5]단계) 최종 **128판 전승·암기 0**이 됐습니다. 본 문서는 그 바탕이
  된 12문장의 설계도이며, 귀납 6문장은 `data/induced_rules.json`
  (수치 조건+행동 형식, 본 설계도와 같은 문법)에 있습니다.
- 규칙 원천 데이터: 되감기 정답 1,162개.

---

## 1. 조종사가 판단에 쓰는 값 — 전부 합법 관측

아래 값들만 쓰며, 전부 경기 규칙이 허용하는 관측(내 계기 + 상대를 눈으로 본
정보)에서 계산됩니다. 상대 체력을 직접 알려주는 반칙 정보는 쓰지 않습니다.

| 이름 | 뜻 (쉬운 말) | 규칙에서 쓰는 기준값 |
|---|---|---|
| 점수차 | 내 체력 − 상대 체력. 상대 체력은 "내가 상대를 원뿔에 넣었던 시간"으로 스스로 계산(오차 ±1.9점 실측) | −2.5 / +25.2 |
| 물림시간 | 상대가 나를 조준각 45도 안에 담아둔 **연속** 시간(초) | 4.5초 |
| 내 고도 | 지금 높이 | 8.1km (26,548ft) |
| 내 속도 | 계기 속도 | 시속 733km (396노트) |
| 접근속도 | 서로 가까워지는 빠르기 | 시속 151km (81.6노트) |
| 내 조준각 | 내 기수가 상대에서 벗어난 각도 (0=정조준) | 43.9도 |
| 상대 조준각 | 상대 기수가 나에게서 벗어난 각도 | 71.3도 |

기억(상태)이 필요한 값은 점수차 계산용 합산과 물림시간 딱 두 개뿐이라,
대회 제출용 행동트리 형식으로 그대로 옮길 수 있습니다(기존 챔피언 제출물이
쓰는 공유 메모리 방식과 동일 수준).

## 2. 설계도 본문 — 위에서부터 차례로 검사해 처음 맞는 칸을 실행

```yaml
# 위에서부터 순서대로 조건을 검사하고, 맞는 첫 칸의 행동을 한다.
차례검사:

# ── 1칸. 과속 경보 ─────────────────────────────────────────────
# 근거: 시속 733km 초과 상태의 되감기 정답 23개가 전패 (뭘 해도 짐)
- 조건: 내 속도 > 시속 733km
  행동: 아무 승부수도 던지지 말고 감속부터   # 싸움 판단은 그 다음

# ── 2칸. 뒤지고 있을 때 (점수차 −2.5점 이하) ────────────────────
- 조건: 점수차 ≤ −2.5
  차례검사:
  #  2-1. 상대가 나를 4.5초 넘게 물고 있음 = 상대가 나에게 몰빵 중
  #       근거: 해당 정답 6개 전승 — 몰빵은 역이용 가능 (미끼 되치기)
  - 조건: 물림시간 > 4.5초
    행동: 물린 방향을 역으로 낚아채는 되치기
  #  2-2. 고도 은행이 있음 (8.1km 이상)
  #       근거: 해당 정답 4개 전승 — 높이를 속도로 바꿔 역전 가능
  - 조건: 내 고도 > 8.1km
    행동: 급강하로 높이를 공격 기회로 환전
  #  2-3. 그 외의 열세 = 되감기로도 답이 없던 지대 (정답 126개 중 승리 9%)
  #       여기 들어오지 않게 하는 것이 본편 판단 규칙의 역할
  - 행동: 피해 최소화 (상대 원뿔만 계속 피하며 기회 대기)

# ── 3칸. 빠르게 마주 붙는 중 (접근속도 > 시속 151km) ────────────
- 조건: 접근속도 > 시속 151km
  차례검사:
  #  3-1. 크게 이기고 있음(+25.2점 초과): 코를 떼지 않는 것이 전부
  #       근거: 코 유지 시 승률 83% vs 코 풀림 23%.
  #       실화: 점수 +54로 이기다 조준각 130도로 한눈판 2.5초 만에 −54.
  - 조건: 점수차 > +25.2
    행동: 상대를 조준각 44도 안에 계속 담아두기 (접근 허용 금지)
  #  3-2. 상대가 나를 마주보며 옴(상대 조준각 ≤ 71도): 정면승부 허용
  #       근거: 이때의 조준사격 승률 77% / 상대가 옆·뒤를 보이면 14%로 급락
  - 조건: 상대 조준각 ≤ 71도
    행동: 조준사격 돌진
  #  3-3. 기본값: 수평으로 비켜 돌기 (정면 도박 거절)
  #       근거: 수평 계열 214개 승률 90%.
  #       금지 근거: 위로 솟기 43% / 아래로 찍기 57% = 동전던지기 지대
  - 행동: 수평 비켜 돌기 (솟기·찍기 금지)

# ── 4칸. 평상시 ────────────────────────────────────────────────
# 근거: 여기 해당하는 정답 615개 승률 86% — 무엇을 해도 대체로 이기는 지대
- 행동: 본편 조종 규칙에 맡김
```

## 3. 각 칸이 실제로 어떤 판을 구했는가 (대표 사례)

| 칸 | 실제 사례 |
|---|---|
| 1칸 과속 경보 | 과속 상태 판들에서 어떤 개입 실험도 전패 → "개입 이전에 속도부터"라는 순서를 강제 |
| 2-1 되치기 | 끈질긴 추격형(A2 계열)이 물고 늘어질 때 도망만 치면 등을 내줌 — 물림 자체를 신호로 반전 |
| 3-1 코 유지 | +54로 이기다 2.5초에 −54 당한 매복 참사의 일반화. 이 칸 하나가 그 유형의 죽음을 막음 |
| 3-3 수평 비켜 | 두 번째 맞붙음(느려진 상태의 재격돌)에서 솟기/찍기를 고르던 판들이 동전던지기로 죽던 것을 차단 |

## 4. 이 설계도의 현재 상태와 남은 일

- 이 설계도의 실행형(컴퓨터가 읽는 형태)은 이미 만들어져 검증됐습니다
  (`data/rule_tree_12.joblib`, 켜는 스위치 `LG_RULESEL=1`).
- 대회 제출 형식(YAML 행동트리)으로의 완전 번역에 필요한 것은 두 가지뿐:
  ① 점수차·물림시간을 세는 조건 노드 2종(기존 챔피언 제출물의 공유 메모리
  방식 재사용) ② "되치기"·"환전" 행동의 세부 실현(기존 전술 어휘 조합).
- 3-3의 "동전던지기 지대"는 **범용 문장**으로는 이길 수 없음이 데이터로 확인된
  영역입니다(그래서 기본값은 회피). 다만 반복 루프(본편 5부)가 그 지대의 지는
  판들에서 **더 좁은 조건의 귀납 문장 6개**를 만들어 최종 128판 전승을
  완성했습니다 — "넓은 원리(본 문서 12문장) + 좁은 원리(귀납 6문장)"의
  2층 구조가 최종 형태입니다.
