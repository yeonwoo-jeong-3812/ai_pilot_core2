# 16장. 형식 검증과 고받음각 실증

## 학습 목표
이 장을 마치면 다음을 할 수 있다.
- 실측 검증과 형식 검증이 각각 무엇을 보장하고 무엇을 못 하는지 안다.
- Z3로 명령 한계가 모든 입력에서 지켜짐을 기계 증명하는 방법을 안다.
- LQR의 리아푸노프 불변집합(Region of Attraction)을 Z3로 인증하는 방법을 안다.
- 고받음각 영역에서 INDI가 LQR보다 강건함을 실측으로 보이는 절차를 안다.
- 게인 trade-off 곡선으로 강건성을 정량 비교한다.
- 매치 결과를 realistic 16/17·성능 17/17·blind 16/17·oracle 17/17로 정직하게 분리해 검증하고,
  예측이 병목이 아님(진짜 한계는 g-cap)을 validation 스위트로 측정하는 방법을 안다.

이 장은 6부의 마무리다. 앞 장들이 AIPILOT을 만들었다면, 이 장은 그 주장을 형식 증명과 실측으로
뒷받침한다.

---

## 16.1 왜 검증인가

매치를 아무리 많이 돌려도 그것은 유한한 시나리오일 뿐이다. "모든 입력에 대해" 안전하다는 주장은
실측만으로는 못 한다. 그래서 두 층으로 검증한다.

형식 검증(formal verification)은 수학적으로 모든 경우를 보장한다. 명제의 반례가 존재하지 않음을
증명기가 보이면, 그 명제는 전 영역에서 참이다. 우리는 SMT 솔버 Z3를 쓴다.

실측 검증(empirical validation)은 형식으로 다루기 어려운 비선형 고받음각 영역에서, 실제로 어떻게
거동하는지를 측정한다. 우리는 NASA TP-1538 기반 plant로 측정한다.

두 층은 상보적이다. 형식은 다룰 수 있는 범위를 확실히 보장하고, 실측은 형식의 범위 밖을 측정한다.

---

## 16.2 형식 검증 A — 명령 한계 (Z3 선형 산술)

첫째 명제는 제어기가 위험한 명령을 구조적으로 낼 수 없다는 것이다. 우리 외측 루프(7장)는 선회율과
뱅크, 조종면을 모두 포화(clip)로 제한한다. 이 clip 로직을 그대로 Z3에 인코딩하고 "한계를 넘는 입력이
존재하는가"를 묻는다. 답이 만족 불가능(UNSAT)이면 반례가 없으니, 한계는 모든 입력에서 지켜진다.

| 명제 | 결과 |
|---|---|
| 모든 입력에서 선회 명령(q_ref)이 80도/초 이하 | 증명됨 |
| 모든 입력에서 롤 명령(p_ref)이 120도/초 이하 | 증명됨 |
| 모든 입력에서 조종면이 25도 이하 | 증명됨 |

결론은 명확하다. 제어기는 과도한 각속도나 조종면, 곧 이탈(departure)을 유발하는 명령을 구조적으로
낼 수 없다. 이는 정확한 보장이다.

## 16.3 형식 검증 B — LQR 리아푸노프 불변집합 (Z3 비선형 산술)

둘째 명제는 내측 LQR이 안전 영역 안에서 수렴한다는 것이다. 6장에서 폐루프 A 빼기 B 곱하기 K는
Hurwitz(고유값 좌반평면)였다. 그 위에 리아푸노프 함수 V(e) = e 전치 P e 를 세운다. 여기서 P는
리아푸노프 방정식의 해이며 양정치다.

이제 불변 타원 E_c = { e : V(e) ≤ c } 를 잡고 세 가지를 Z3로 증명한다.

| 명제 | 결과 |
|---|---|
| P가 양정치 | 증명됨 |
| 불변 타원 E_c 가 안전 각속도 박스 안에 포함 | 증명됨 |
| V의 시간미분이 음수 (단조 감소, 양의 불변) | 증명됨 |

이 셋을 합치면, E_c 안에서 출발한 모든 추종 오차는 안전 각속도 박스를 절대 벗어나지 않고 0으로
수렴한다. 곧 내측 LQR은 인증된 끌림 영역(Region of Attraction) 안에서 이탈이 불가능함이 기계로
증명된다.

```
        안전 각속도 박스
   ┌───────────────────────┐
   │      ╭─────────╮       │   E_c (불변 타원): V(e) ≤ c
   │     (   ●e0    )       │   - 양의 불변 (V̇ < 0)
   │      ╰─────────╯       │   - 박스 안에 포함
   └───────────────────────┘   ⇒ 안에서 출발하면 못 벗어남
```

정직한 범위. B는 선형화된 오차 동역학에 대한 표준 ROA 인증이다. 완전 비선형 고받음각 도달성
(Cm 역전, 롤요 커플링 포함)은 전용 도달성 도구(Flow*, CORA)의 영역으로 이 형식 층 밖이며, 그 역할을
16.4의 실측 층이 맡는다.

## 16.4 고받음각 실증 — TP-1538

우리 전투 엔진(JSBSim)은 limiter와 외측 루프 때문에 깊은 고받음각으로 잘 들어가지 않는다. 그래서
LQR과 INDI의 차이가 거기서는 잘 드러나지 않는다. 차이를 보려면 제대로 된 고받음각 plant와 내측
격리가 필요하다. 그래서 별도로 NASA TP-1538 공력을 담은 AeroBench 모델 위에서 내측만 LQR과 INDI로
바꿔 비교한다(외측은 동일, 공정 비교).

정상상태 추종 오차로 보면 결과는 다음과 같다. 단순 피치 기동은 LQR과 INDI 모두 0.1도 미만으로
우수하고 사실상 차이가 없다. 즉 단순 영역에서는 내측 선택이 무관하다. 그러나 복합 고기동(롤과 당김
결합)에 모델 불확실성(제어효과 절반)을 주면 갈린다. LQR은 정상상태 오차 2.38도에 정착 7.9초로
둔해지는 반면, INDI는 0.61도에 1.1초를 유지한다. 약 4배 정밀하고 7배 빠르다.

해석은 분명하다. INDI의 가치는 전방위 우월이 아니라 어려운 영역, 곧 복합 기동과 모델 불확실성에서의
강건성이다. INDI는 각가속도를 측정해 모델오차를 흡수하기 때문이다(8장).

## 16.5 게인 trade-off

위 결과가 게인 튜닝의 우연이 아님을 보이려면, 양쪽을 공격성으로 sweep해 추종, 제어활동, 강건성의
3중 균형을 비교해야 한다. 복합 기동에서 LQR과 INDI의 게인을 각각 바꿔가며 정상상태 오차(정상),
제어활동, 그리고 모델오차 하 정상상태 오차(강건성)를 측정한다.

결과의 핵심은 둘이다. LQR은 매끄러운 곡선을 그리지만, 모델오차 하 강건성이 어떤 게인으로도 일정
수준(약 1.07도) 아래로 내려가지 않는 구조적 바닥이 있다. INDI는 한 코너에 모여 있어 게인에 거의
둔감하고, 같은 제어활동 대역에서 LQR보다 강건하며, LQR이 도달할 수 없는 강건성(약 0.60도)을
가진다. 즉 INDI의 강건성 우위는 튜닝과 무관하게 일관된다.

## 16.6 결과 검증 — 채점 모드 분리와 예측-레버 탐색

매치 결과는 단순한 "17/17"이 아니라 *네 가지 정직한 수치*로 분리해 보고한다(CANON §5). 자세한
측정과 종합은 17장에 있다.

| 모드 | 러더 | 결과 | 의미 |
|---|---|---|---|
| realistic (충실) | 교범(수동 최소, `INDI_RUD_MAX_CRUISE=0.2`) + 조건부 high-g | **16/17** | high-g로 A3 격파, 잔여=D2(blind) |
| 성능 | 비교범 대형 수동 러더(nose-skid) | **17/17** | 추가 승은 비교범 러더에서 옴 |
| blind 자가분류 (실전) | 교범 | **16/17** | D2만 무승부 = D2 *분류 정보한계* |
| oracle (상한 벤치마크) | 교범 | **17/17** | 유형 given — D2도 격파(deck-floor) |

수치를 가르는 핵심은 다음과 같다.

첫째, yaw 물리가 결함이 아니라 *충실*함을 F-16 모델 대 실기 데이터로 확인했다. 러더 편향 한계
±30°(±0.524 rad), Cndr(러더 yaw 모멘트)는 NASA TP-1538(Nguyen) 표와 일치, 자동 턴 조정은 FLCS
`yaw-load-pid`(측방가속도 피드백)로 cap과 무관하게 작동한다. INDI 러더는 `fcs/rudder-cmd-norm`을
거쳐 native FLCS를 통과하므로 FLCS 자동 조정이 INDI 명령 위에 ±1.0 권한으로 더해지고, realistic
0.2 cap에 막히지 않는다. 즉 0.2 cap이 제한하는 것은 *수동 겨냥(nose-skid)* 러더뿐이며, 이는 실
F-16 gun 교범(roll+pull, 수동 러더 미세)상 옳다. 교범 러더는 정당한 제약이지 결함이 아니다.

둘째, blind 16/17의 잔여 1승(D2)은 fidelity 결함이 아니라 *분류 정보한계*다. D2의 정의적 행동
(dive-to-deck 강하-도주)이 늦게 발현하므로 그 전에는 다른 미진입 적과 형상이 겹쳐 조기 식별이
불가하다(`iff_early_detect`: 다이브 onset 26.4s, 거짓양성 0). 빠른감지를 구현해도 blind D2는 여전히
무승부(`fastd2_test`)인데, 탐지는 자기가 탐지하는 행동보다 빠를 수 없기 때문이다. 유형을 아는 순간
(oracle) D2는 격파된다(deck-floor 수정, 17장 §17.10) → oracle 17/17.

셋째, "예측을 더 잘하면 이기나"를 5개 레버로 측정한 결과 전부 중립/악화였다(17장 §17.5). gun dwell을
막던 진짜 병목은 예측도 러더도 아니라 *뱅크 g-cap*(근접·미정렬 틱서 4.8g에 포화)이었고, 조건부
high-g(4.8g→8.2g, 9g 구조한계 내)로 A3를 깨 realistic 15→16/17이 됐다. 결론: **예측은 병목이
아니다.**

검증 인프라는 `new_match_engine/validation/`에 추가했다.

| 모듈 | 측정 |
|---|---|
| `guidance_vs_sota.py` | SOTA 유도법 대비(요격 vs gun-dwell) |
| `etm_predictor_bench.py` | 예측기 비교(CT/KF/UKF/IMM) |
| `etm_twosided_bench.py` | ego-aware 조준 |
| `etm_ab_engine.py` | ETM KF 엔진 A/B |
| `iff_early_detect.py` | D2 조기감지 가능성 |
| `dwell_diagnose.py` | 저-dwell 원인 진단(진짜 병목=뱅크 g-cap) |
| `highg_ab.py` | 조건부 high-g A/B(A3 격파) |
| `attitude_lead.py` | 뱅크→ω 선행(0.63s) 실측 |
| `bank_ab.py` | 뱅크-선행 A/B |
| `fastd2_test.py` | D2 빠른감지 A/B |

## 16.7 형식과 실측의 상보

정리하면 검증은 두 기둥이다. 형식 층(16.2, 16.3)은 명령 한계와 LQR 끌림 영역을 전 영역에서 또는
선형화 위에서 기계 증명한다. 실측 층(16.4, 16.5)은 형식이 닿지 못하는 비선형 고받음각에서 INDI의
강건성을 측정한다. 정직한 한계로, 완전 비선형 도달성 증명은 본 검증의 범위 밖이며 전용 도구가
필요하다. 그럼에도 두 층을 합치면, AIPILOT의 제어가 안전 명령만 내고 인증된 영역에서 수렴하며
어려운 영역에서 강건함을 근거와 함께 말할 수 있다.

재현은 다음과 같다.

```
python new_match_engine/validation/formal_verify.py     # 16.2, 16.3 Z3 증명
python new_match_engine/validation/aerobench_testbed.py # 16.4 TP-1538 실증 (aerobench 필요)
python new_match_engine/validation/tradeoff_sweep.py    # 16.5 게인 Pareto
python new_match_engine/validation/dwell_diagnose.py    # 16.6 저-dwell 원인 진단(g-cap)
python new_match_engine/validation/highg_ab.py          # 16.6 조건부 high-g A/B(A3 격파)
python new_match_engine/validation/iff_early_detect.py  # 16.6 D2 조기감지 한계
python new_match_engine/validation/bank_ab.py           # 16.6 뱅크-선행 A/B
```

## 연습문제
1. 형식 검증과 실측 검증이 각각 보장하는 것과 못 하는 것을 한 줄씩 적어라.
2. 명령 한계 증명에서 "한계를 넘는 입력이 존재하는가"의 답이 UNSAT이면 무엇이 보장되나.
3. LQR 끌림 영역 인증의 세 명제(양정치, 포함, 감소)가 합쳐져 무엇을 증명하는가.
4. 단순 피치에서는 LQR과 INDI가 비슷한데 복합 기동에 모델오차를 주면 갈리는 이유는 무엇인가.
5. 게인 trade-off에서 LQR의 "구조적 바닥"이 뜻하는 바를 설명하라.
