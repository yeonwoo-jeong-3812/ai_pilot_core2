# CANON — 이 책의 단일 진실원천 (Single Source of Truth)

> 이 문서의 목적은 **한 가지**입니다. 이 책(`docs/book/`)의 모든 문서가 **현재 최신 상태**와
> **"AI 공중전의 일반해를 찾는다"는 하나의 논지**에 일관되게 정렬되도록, 숫자·용어·프레이밍의
> **정답을 한 곳에 고정**하는 것.
>
> 규칙: 어떤 문서든 아래 표와 충돌하면 **아래 표가 맞다**. 문서를 고칠 때 숫자·상태·용어는
> 여기서 인용하라. 새 실험으로 사실이 바뀌면 **먼저 이 파일을 갱신**하고, 그 다음 각 문서를
> 이 파일에 맞춰라. (거꾸로 하면 또 표류한다.)
>
> 최종 검증: 2026-07-01. 코드 기준: `new_match_engine/control/indi.py`,
> `new_match_engine/bt/exp_e53_integrated_17.py`, `new_match_engine/policy_yaml/ours.yaml`.

## 0. 이 책은 무엇을 주장하는가 (일반해 논지 — North Star)

이 책은 하나의 연구 프로그램이다: **"설명 가능하고, 결정론적이며, 교과서로 인용할 수 있는
방법만으로 F-16 자율 공중전 조종사를 처음부터 끝까지 구현한다."**

"일반해(general solution)"의 뜻을 오해하지 마라. 이 책에서 일반해란:

1. **투명성** — 블랙박스가 없다. 모든 결정은 BFM/EM 이론과 교과서적 제어(LQR·캐스케이드·INDI)로
   추적된다. 학습된 부분(RF 전술분류)조차 관찰 가능한 규칙으로 드러난다.
2. **결정론** — 같은 입력 → 같은 출력. `.yaml`(구조 트리)과 `.py`(정책) 이 **틱-동일**(dual)이라는
   사실이 이를 증명한다.
3. **일반화** — 특정 적 `.yaml` 신원에 과적합하지 **않는다**. 정책은 적을 **관찰된 궤적의 행동
   유형**으로 blind 자가분류하고(적 정보 0), **그 유형에 맞는 독트린**을 적용한다. 따라서 "그렇게
   행동하는 어떤 적"에게도 같은 해가 작동한다. **이것이 일반해의 핵심**이다.

**금지된 프레이밍** (이 책이 아닌 것): "특정 적을 이기려고 튜닝한 트릭 모음", "벤치마크 점수
극대화 자체가 목표", "적 이름표를 미리 알고(oracle) 대응하는 시스템". oracle 은 **상한 벤치마크**로만
등장하며, 배치되는 것은 항상 **blind 자가분류** 정책이다.

> 주의: gbrain 의 `abstract_and_claims`, `novelty_evaluation_and_direction`,
> `thesis_direction_and_abstract` 페이지는 **다른 프로젝트(탄도미사일 V&V)** 다. 그 프레이밍을
> 이 책에 끌어오지 마라.

## 2. 엔진 4계층 (`new_match_engine`)

```
L1 전술선택 (policy/BT → Tactic)      ← .yaml 이 바꾸는 유일한 계층
L2 유도     (Tactic → Setpoint)
L3 오토파일럿 (캐스케이드) + L4 INDI    ← 제어 충실도
        ↓
JSBSim 6-DOF F-16 플랜트
```

`.yaml` 은 **L1만** 바꾼다. L2–L4 는 정책과 무관하게 공통.

## 5. 현재 캐노니컬 점수 — ★문서의 숫자는 이것과 일치해야 한다

both-INDI + 교범러더(0.2) + high-g ON + **300s** 기준:

| 채점 | 점수 | 설명 |
|---|---|---|
| **성능(performance)** | **17/17** | |
| **realistic** | **16/17** | high-g 로 A3 깸(15→16). 잔여 1 = D2(blind) |
| **blind (자가분류, 배치조건)** | **16/17** | D2 만 무승부. D2 의 **늦은 dive-onset → 조기분류 정보한계** 때문 (운동학 벽 아님) |
| **oracle (유형 given — 상한 벤치마크)** | **17/17** | D2 도 판정승(deck-floor 수정 후, ~100:96) |

**base 4** (`anchor_simple`, `anchor_aggressive`, `A1_PurePursuer`, `A2_GunTracker`): 격추 불가지만
**판정승**. 진짜 **동속 rate-parity 운동학 제약**(BSG 시도는 −1 net, 폐기). 판정승이라 17/17 에
무해.

## 6. D2 서사 — ★가장 자주 표류하는 부분. 이대로만 써라

- **옛 프레이밍(폐기됨):** "D2 는 설계된 단일교전 불가 evader, 운동학 벽(Nash), 잡을 수 없다."
  → **틀렸다. 코드가 반증한다.**
- **진짜 병목:** 우리의 **보수적 CLIMB 바닥 상수 2500ft**. D2 운용고도(~1200–1800ft)보다 높아,
  gun 거리로 내려갈 때마다 CLIMB 로 튕겨 에너지 손실 → D2 extend. (궤적 t≈85 확인.)
- **격파 조합 (캐노니컬 정책에 커밋됨, 기본 ON):**
  - `D2_DECK_FT=1500` (exp_e53:77) — D2 추격 시 CLIMB 바닥 하향 (`_floor = D2_DECK_FT if typ=="D2" else 2500.0`, :135)
  - `D2_OS_GUARD` 기본 ON (:79, "robust win") — LAG overshoot 가드
  - `D2_VMAX=540` (:92) — `typ=="D2"` 에만 격리 적용 (그 외 기본 V_MAX)
  - (`SD_SPRINT`: SMART_DIVE turn_in decel off)
- **결과:** **oracle 에서 D2 판정승 → oracle 17/17.** **blind 에서는 D2 여전히 무승부** — 이유는
  운동학이 아니라 **분류 정보한계**(D2 의 dive-onset 이 늦어 50s 창 안에 D2 로 확정 못 함).
- **한 줄:** D2 는 운동학적으로 잡을 수 있다(격파 증명). 배치(blind)에서 무승부인 건 "못 잡아서"가
  아니라 "제때 D2 로 **분류**하지 못해서"다. "운동학 벽"으로 쓰지 마라.

관련 gbrain: `ai-pilot-d2-defeat-base-draw-2026`(최신). `d2-defeat`(구버전, "kinematic wall" 표현은
폐기됨 — 문제기술로만 읽어라).

## 7. 충실도(fidelity) 사실 — 표류 금지

- **prediction 은 병목이 아니다.** 독트린은 **gun-WEZ dwell** 을 최적화한다(intercept 아님).
- **조건부 high-g 는 충실**하다: g-cap 4.8g→8.2g 은 F-16 9g 구조한계 안. 에너지게이트(280kts↑)로만.
- **yaw 물리 충실:** ±30°, NASA TP-1538 Cndr, FLCS 자동조정.
- 따라서 "realistic 15/17 이 정직한 fidelity 천장"이라는 **옛 문장은 폐기** — 천장은 **16/17**이고,
  잔여 1(D2 blind)은 fidelity 가 아니라 **분류 정보한계** 때문이다.

## 8. Wording 규칙 (P3 — 작업 순간 표류를 없애는 규칙)

1. **시점 없는 서술.** "이번에", "방금", "지금 세션에서", "오늘 발견", 날짜 붙은 정정(예:
   "(2026-06-26 정정)")을 본문에 남기지 마라. 정정은 **원문을 고쳐** 하나의 시점 없는 서술로 만든다.
   (변경 이력이 필요하면 이 CANON 상단 "최종 검증" 줄이나 gbrain 에 둔다.)
2. **모순 append 금지.** 위(15/17)에 쓰고 아래(16/17)에 정정 붙이지 마라. **하나의 값**으로 통일.
3. **숫자·상태는 §5·§6 을 인용.** 문서가 독자적으로 점수를 주장하지 않는다.
4. **oracle vs blind 를 항상 구분해서 명시.** 배치 = blind. oracle = 상한 벤치마크.
5. **일반해 프레이밍 유지**(§0): 유형은 행동클래스, 목표는 투명·결정론·일반화. "적 이름 튜닝"으로
   읽히는 표현 제거.
6. **"D2 = 운동학 벽/불가" 금지**(§6). "분류 정보한계로 blind 무승부"로 쓴다.
7. 정답이 검증된 숫자만 단정한다. 안 잰 것은 단정하지 마라(메모리: "천장 조기단정 금지").
