# L3 INDI 논문 연구 하네스 — 인수인계 문서

이 디렉터리는 **F-16 FLCS 위에 얹은 INDI 내부 루프**를 평가하는 논문용 실험 코드다.
배치 코드(`aircombat/`)는 **고치지 않는다**. 여기 있는 하네스가 배치 코드를 그대로 불러다 쓴다.

## 0. 5 분 요약

- **무엇을 재나**: INDI 설정(게인·필터·제어효율 모델 오차 λ)을 바꿨을 때
  ① 각속도 추종 오차(T층) ② 기수 지향·기동 실현 결과(M층)가 어떻게 달라지는지.
- **왜 이렇게 복잡한가**: 사후에 말을 바꾸지 않기 위해 **모든 규칙을 실행 전에 등록**한다.
  규칙 원장은 `docs/PREREGISTRATION_AMENDMENTS.md` (A1~A26). 데이터를 본 뒤 바꾼 것은 ⚠ 로 표시한다.
- **재현성 장치**: 러너가 **커밋 안 된 변경이 있으면 실행을 거부**하고, 결과 폴더 이름이 실행 커밋 해시다.
  같은 입력이면 결과가 비트 단위로 같다(RQ3 에서 48/48 확인).

## 2. 파일 지도

**기반**

| 파일 | 역할 |
|---|---|
| `harness.py` | 한 대의 F-16 을 짓고(`build`) 기동을 먹여 돌린다(`run`). `Condition`(고도·속도), `Params`(INDI 게인·필터), `Uncertainty`(제어효율 모델 오차 λ), `gcmd`(합성 L2 명령) |
| `runner.py` | 병렬 실행 + 출처 기록. **커밋 안 된 변경이 있으면 거부**(`require_clean`). 결과는 `results/paper/<실험>/<커밋10>/` |
| `design.py` | 조건 격자와 기체 능력표(`capability`: 최대 G, 최대 롤율) |
| `maneuvers.py` | 합성 기동 M1(당김)·M2a/M2b(반전)·M3(구르며 당김)·M4(다중사인) + 꼬리 유지 |
| `metrics.py` | 지표 전부 — 추종 오차 `tracking_J`, 진동·이탈 판정, 시간척도 분리 잔차, `transfer_fit`(선형 vs 임계) |
| `evaluate.py` | 한 런 → 한 줄 지표 |

## 3. 돌리는 법

```bash
# 저장소 루트에서. 트리가 깨끗해야(커밋 완료) 실행된다.
python research/l3_indi/rq3.py --pilot --geom results/paper/rq3_geom/<커밋10>/geometries.json   # 파일럿
python research/l3_indi/rq3.py         --geom results/paper/rq3_geom/<커밋10>/geometries.json   # 본실행 (606 런, 약 6 분)
python research/l3_indi/rq3.py --analyze results/paper/rq3/<커밋10>                              # 분석·보고서 생성
```

`--pilot` 은 5% 규모다. **본실행 전에 파일럿을 먼저 돌리고 결과를 확인한다**(A24-10). RQ3 에서는 이 파일럿 덕분에
"개루프 당김은 M층 신호가 0" 이라는 설계 결함을 본실행 전에 잡았다(A25).

## 4. ⚠ 새로 합류한 사람이 반드시 지킬 것

1. **규칙을 먼저 등록하고 실행한다.** 지표·판정 기준·등가 한계 δ 를 바꿀 거면
   `docs/PREREGISTRATION_AMENDMENTS.md` 에 **먼저** 적고 커밋한 뒤 돌린다. 데이터를 본 뒤 바꾼 것은 ⚠ 를 붙이고 무엇을 보고 바꿨는지 쓴다.
2. **배치 코드(`aircombat/`)를 고치지 않는다.** 고치면 그 시점부터 "배치된 시스템을 평가했다" 는 주장이 무너진다.
   필요하면 하네스 쪽에서 주입한다(예: `Uncertainty`, `PursuitScript`).
3. **결과 폴더 이름 = 실행 커밋**이다. 보고서에 인용한 숫자는 그 폴더에서 나온 것이어야 한다.
4. **같은 청군 궤적을 공유하는 런은 독립 표본이 아니다.** 개루프 기동은 적을 보지 않으므로 여러 기하·적기 조합이
   같은 궤적의 복제다. 통계는 **클러스터 부트스트랩**으로 낸다(A26). 새 기동을 추가하면 클러스터 단위를 `rq3_analysis.CLUSTERS` 에 적는다.
5. **"차이 없음" 은 양성 대조(S5)가 그 지표에서 차이를 낸 경우에만** 쓴다. 아니면 "판정 불가" 다.

## 5. 데이터는 왜 저장소에 없나

`results/` 는 `.gitignore` 대상이다(현재 로컬 2.3 GB). 저장소에는 **코드와 마크다운 보고서**(`research/l3_indi/reports/`)만 들어간다.
숫자를 다시 확인하려면 위 명령으로 **다시 돌리면 된다** — 결정론이라 같은 커밋에서 같은 값이 나온다.
원자료(runs.csv)가 필요하면 이 브랜치 작성자에게 요청하거나, `.gitignore` 에 화이트리스트를 추가해 특정 실험 폴더만 반입한다.
