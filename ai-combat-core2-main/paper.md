## 2. 논문 2 — A Comparative Study of Nonlinear MPC and Differential-Flatness-Based Control for Quadrotor Agile Flight

Sun, Romero, Foehn, Kaufmann, Scaramuzza, IEEE T-RO 2022.

- **내용**: 쿼드로터 20 m/s 고기동 궤적 추종. NMPC vs DFBC, 각각 INDI 내곽 유무 교차 비교. 시뮬(76 가능 + 68 불가능 궤적) + 실기(VICON).
- **INDI 구성**: 2차 Butterworth 동기화 필터 **12 Hz**, INDI 300 Hz, KΩ = diag(20, 20, 8), 구동기 30 ms 1차 지연, QP 제어배분(가중 W).
- **결과**: INDI 제거 시 위치 RMSE NMPC +364%, DFBC +705%(추락 발생). INDI 효과 > 항력모델 효과(+122~144%). NMPC+INDI 가 NMPC+PID 대비 −70%.
- **민감도 분석(VI-F)**: 기준(표 I) 대비 파라미터를 **비율**로 변경, RMSE/RMSE_base 로 정규화, **추락은 300% 로 절단**. 게인↑ → 오차↓ 이나 시스템 지연 하에서 불안정; 추정 지연 30 ms 초과 시 결과 역전. 게인을 (ωn, ζ) 로 표현(Kξ = ωn², Kv = 2ζ√Kξ).
- **강건성(VI-E)**: 질량 ±30%, CoG 10/15%, 추력·토크계수 ±30%, 항력 +50/100%, 5 s 외력/외부모멘트, 추정 지연.
  예) CoG 15% 에서 INDI 없는 DFBC 추락률 56%.
- **기여**: 변수 KΩ·자세게인·필터 차단주파수·(ωn,ζ)·W / 실험 = 단일변수 민감도, 강건성, INDI ablation, 한계초과 기준.
- **주의**: 기체·과업 상이 — 수치 이식 불가, 방법론만 차용.

## 3. 논문 3 — A Hierarchical Deep Reinforcement Learning Framework for 6-DOF UCAV Air-to-Air Combat

Chai, Chen, Zhu, Yao, Zhao, 2022 (arXiv).

- **내용**: F-16 6-DOF 1v1 WVR(WEZ 30°·3 km). 외곽(전투 전략: 롤·피치 각속도+스로틀) / 내곽(비행제어기: 목표 롤·피치각 → 조종면) 모두 PPO. 외곽은 fictitious self-play 3세대. 내곽 Tf = 0.04 s.
- **내곽 보상**: r = c1·생존 + c2·추종 + c3·조종량. (c2, c3) 격자 탐색 — c2↑ 추종↑·불안정↑, c3 는 0.05–0.10 에서 최적, 과대 시 성능↓. 최종 (1.5, 0.05). 평균 추종오차 1.1°.
- **핵심 ablation(표 III, 64전)** — 3세대 전략의 제어기만 RL→PID 교체 시 승률:

  | 상대 | RL | PID |
  |---|---|---|
  | 수평직진 | 0.938 | 0.578 |
  | 1세대 | 0.781 | 0.500 |
  | 2세대 | 0.844 | 0.313 |

  패인 = PID 기체의 선회 속도 저하(Fig.12). **"내곽 제어기 품질 → Dogfight 승패"의 직접 선행 근거.**
- **기타 실험**: 시험 신호 3종(사인·코사인/스텝/무작위), 결정 주기 0.1/0.25/1.0/4.0 s, 시나리오 3종(정면대향/등맞댐/평행역방향).
- **한계**: G·AoA 한계 미기술 → 물리 한계 준수 미검증. 비교 PID 가 비스케줄 단일 게인(Kp 0.2/0.65, Ki 0.015/0.08, Kd 12/25).
- **기여**: 변수 (c2,c3) = 추종 대 부드러움 상충 / 실험 = 제어기 교체 → 승률 비교.

## 4. 논문 4 — Parameter Tuning Approach for Incremental Nonlinear Dynamic Inversion-Based Flight Controllers

Henkenjohann, Nolte, Sion, Henke, Trächtler, Actuators 13(5):187, 2024.

- **내용**: 틸트로터 VTOL 의 캐스케이드 INDI. **제어배분(QP) 가중치 자동 튜닝** — 절대 편향 페널티 + 증분(Δu) 페널티(고주파 진동 억제).
- **파이프라인**: 시험 임무 → 시뮬레이션 → 비용 G = g_y + γ·g_x → 최적화 → 파레토 → 4-DOF 시험대 실기 검증.
  - 시험 임무: 롤·피치·요레이트 **더블릿**(스텝은 방향 의존) × 운용점 3개(틸트 0, π/4, π/2)
  - g_y: 출력별 최대범위 정규화 제곱오차의 시간적분 합(정규화 ISE)
  - g_x: 구조 비틀림 토크 제곱 적분 (구조 보호 항)
  - 최적화: GA / PSO / Surrogate 를 "함수 평가 수 대비 최저 비용"으로 비교 → **PSO 최선**, Surrogate 1% 이내, GA 최하
  - 파레토: γ 변화 — g_x 50% 이상 감소에도 g_y 증가 10% 미만
- **구현 발견**: 모든 신호에 동일 PT2 필터(동기화), 각가속도 상보필터, 속도제한 PT1 구동기 모델, **순항 시 공력감쇠로 응답 저하 → 피드포워드 권고**.
- **결과**: 자동 튜닝이 수동 대비 진동·오버슈트 감소, 속도 동일(정성 비교).
- **기여**: 변수 = Δu 페널티, γ / 실험 = 자동 튜닝 방법론(시험임무→PSO→파레토→기준 대비 검증).

## 5. 논문 5 — Stability Analysis for Incremental Nonlinear Dynamic Inversion Control

Wang, van Kampen, Chu, Lu, JGCD 42(5), 2019.

- **내용**: 시간척도 분리 가정 없이 INDI 재유도, 임의 상대차수·내부동역학 일반화. 리아푸노프·섭동이론으로 외란, 정규섭동(모델오차), 특이섭동(구동기·필터 지연) 해석.
- **궁극 경계(ultimate bound) 영향 인자**
  1. **게인 K**↑ → 경계↓, 샘플링 요구 완화. 상한 = 구동기 한계·잡음 증폭
  2. 샘플링↑ → 경계↓. 강체 항공기 100 Hz 충분(유연기 1,000 Hz)
  3. 외란 강도 — INDI 는 증분 Δd 만 남음
  4. **동기화·지연** — 특이섭동 여유 이내의 작은 지연만 허용
  5. 내부 동역학 — INDI 가 직접 제어 못함(샘플링으로 개선 불가)
- **검증**: 돌풍하중완화. K = 8·I, 100 Hz. 기준신호 p: 3211(5°/s), q: 더블릿(1.5°/s), r: 사인(3°/s, 1 rad/s). von Kármán 난류(Lg 762 m, σ 3 m/s).
  B̂ = 1.3B 시 RMS 증가 INDI +15~42% vs NDI +21~158%. 몬테카를로 1,000회(질량 σ10%, 관성 σ25%, 양력기울기 오차), 실패기준 RMS > 50 °/s → **NDI 31 실패 / INDI 0**, IQR 한 자릿수 이상 차이.
- **본 프로젝트 해석**: FLCS 를 사이에 둔 구조 = 정규섭동(G0 오차) + 특이섭동(FLCS PID 적분·명령필터 지연) 동시 존재. 승강타 명령 [−1, 0.44] 포화 = 구동기 비선형 한계 → 포화율 필수 지표.
- **기여**: 변수 K·샘플링·동기화 / 실험 = 표준 시험신호, B̂ ±30%, 난류, 몬테카를로.

## 6. 논문 6 — MCH 11-F16 Vol.5 F-16 Combat Aircraft Fundamentals, 제4장 공대공

USAF ACC/AETC, 1996 (한글 번역본). 본 프로젝트 `doctrine.py` 의 BEM 인용 원전.

- **성격**: 제어 변수 없음. **물리 한계 기준과 제어 품질이 교전에 미치는 지점의 근거.**
- **§4.6.5.1 롤**: 고속·저AoA 에서 롤레이트 최고, 저속·고AoA 에서 저하 — 저속에선 AoA 를 먼저 줄이고 롤.
- **§4.6.5.2 선회**: 최대 AoA/G 선회반경은 170–330 KCAS 에서 거의 일정, 330 이상에선 **최대 G 를 얻는 440 KCAS 까지** 반경 약간 증가, 440 초과 시 급증. FLCS 로 인해 코너속도 대신 **코너 플래토 330–440 KCAS**. 선회율은 330 KCAS 에서 최고. G 한계 선회 = 최대 순간선회율이나 **지속 불가**, 330 KCAS 아래로 떨어지면 G 를 풀 것. 루프 정점 4G ≈ 수평 5G(중력), 최적 루프 = 시작·끝 3–4G, 정점 최대 G.
- **§4.6.5.3 가속**: 최고 가속 300–400 KCAS, 0G 언로드 최고 가속, 0.7–0.9G 절충.
- **§4.8.2 브레이크 턴**: "9G 를 덥석 잡아채기보다 **신속함과 부드러움을 혼합**" → G 오버슈트·G onset 을 지표로.
- **§4.7.5 기총 접근**: 2,000 ft/100 kt·1,500 ft/50 kt 접근율이면 재정렬. 흔한 실수 = 속도 조절, **피퍼 조절**.
- **§4.14 기총**: 사격해는 표적 POM·속도·G 일정 시에만 안정, EEGS 안정화 ≈ 1/4 s, LCOS 1 TOF, 탄 분산 6 mil, 오차 범주에 **조종 오차** 포함. 9G 피퍼 = "최대 7.3G, 코너 350 KCAS" 가정. 해수면 최대 지속선회율 20°/s 가정.
  → **ATA 2°(≈35 mil) 이내 체류 = 기수 추종 정밀도 = INDI 성능**.

### 한계 기준 결정 — 교범 해석 가용 G 봉투

현행 리미터 `_g_aero = 9·(KCAS/330)²` 는 330 KCAS 에서 9G 도달 → 교범(440 KCAS 도달) 대비 330–440 구간에서 관대.
교범 해석 봉투(선회반경 일정 구간 ∝ V², 선회율 일정 구간 ∝ V):

```
G_max(V) = 6.75·(V/330)²    V < 330 KCAS      (6.75 = 9·330/440)
         = 9·V/440          330 ≤ V < 440
         = 9                V ≥ 440
```

교차 검증: 350 KCAS → 7.16G (교범 EEGS 가정 "350 KCAS 에서 7.3G" 와 부합). 음의 한계 −3G, 롤 220°/s 는 유지.

### B. 기준 공력 데이터와의 정합 (f16fix 정당화)
- NASA TP-1538 (Nguyen et al., 1979, [NTRS](https://ntrs.nasa.gov/citations/19800005879)) → Stevens & Lewis (1992) →
  Garza & Morelli NASA TM-2003-212145 의 F-16 공력 모델([DAVE-ML 판](https://daveml.org/examples/F16_aero.html)):
  수직력 계수 **CZ = f(α, β, δe, q)** — 에일러론 항 없음. 에일러론은 Cl·Cn·CY 에만 기여.
- ∴ "에일러론이 대칭 양력을 만들지 않는다"는 f16fix 의 가정은 원전 공력 데이터와 일치.
- 한계(논문 명시): f16fix 도 원본처럼 저속(<250 kt) 후연 플랩 양력이 0 — 코너 플래토(330–440 KCAS) 밖이라 교전 영향 작음.
