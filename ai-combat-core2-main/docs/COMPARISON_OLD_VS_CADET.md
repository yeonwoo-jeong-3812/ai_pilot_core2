# 기존 실험과 새 실험(cadet_research)의 비교 분석

작성 2026-10-19. 대상: 논문을 함께 쓸 팀원 5명.

**이 문서를 읽는 이유**: 우리는 9월부터 10월 중순까지 INDI 파라미터 실험을 해 왔다. 그런데 교수님이
논문 쓰기 좋게 실험을 **재설계**하셨고(`cadet_research` 브랜치), 그 설계로 새 본실험이 끝났다.
두 실험은 **같은 시뮬레이터로 같은 변수를 흔들었지만 묻는 질문이 다르다.** 이 문서는 무엇이 같고
무엇이 다른지, 그리고 **기존 실험 결과를 새 논문에 얼마나 가져다 쓸 수 있는지**를 정리한다.

참고 문서
- 기존 계보 정리: `docs/EXPERIMENT_MASTER_20261001.md` (결과 원본), `docs/LEARNING_L3.md` (제어 법칙),
  `docs/LEARNING_EXPERIMENT.md` (실험 설계 노트)
- 새 계보: `cadet_research/RESEARCH_PLAN.md`, `FEASIBILITY.md`, `PAPER_SKELETON.md`, `kit/`

**용어 규칙**: 코드와 보고서에 쓰는 이름을 그대로 쓰고, 처음 나올 때 괄호로 뜻을 붙인다.

## 0. 한 쪽 요약

| | 기존 실험 (research/l3-indi-paper-v2, YEOP) | 새 실험 (cadet_research) |
|---|---|---|
| **묻는 것** | INDI 파라미터가 도그파이트에 **영향을 주는가** | 피치 추종 오차 하나로 영향의 **크기를 예측할 수 있는가** |
| 질문의 성격 | 효과의 유무 (effect) | 대리 지표의 타당성 (surrogate validity) |
| 주 결과 변수 | 명령 실현 충실도(1순위), 승률·WEZ(관찰) | **D** = 기준 대비 결과가 달라진 경기 비율 |
| 주 예측 변수 | 없음 (변수마다 따로 판정) | **mae** = 교전 중 피치 추종 오차 [°/s] |
| 판정 방식 | 변수마다 등가 판정 (차이 있음/없음/불가) | **곡선으로 예측하고 예측 오차를 판정** |
| 규모 | 약 19,000경기 + 개루프 74,000런 | **약 73,000경기** |
| 결과의 성격 | "명목 조건에서는 전달 안 됨, 지연에서는 붕괴" (조건부) | "추종 오차로 예측된다" (양성 결과) |

**가장 큰 차이 한 줄**: 기존 실험은 **"영향이 있나?"**를 물어 **"조건부로 있다"**는 답을 얻었다.
새 실험은 그 답을 **전제로 깔고** **"그 영향을 싸게 예측할 수 있나?"**를 물어 **"예측된다"**는 답을 얻었다.
**새 질문이 논문으로 쓰기에 훨씬 낫다.** 이유는 §4에 있다.

## 1. 기존 실험 — 무엇을, 왜, 어떻게 했나

### 1.1 원래 주제

> **「INDI 제어 파라미터가 도그파이트 기동 실현도에 미치는 영향」**

연구 질문은 이것이었다.

> 같은 전술 행동트리(BT)라도 INDI 파라미터에 따라 **명령을 따라가는 반응 속도**가 달라지고,
> 그게 승패까지는 아니어도 유의미한 차이를 만드는가.

**비유(수도꼭지)**: 배관(INDI 제어기)이 좋으면 물이 빨리 나오고(상승 시간), 틀어놓은 만큼 나온다
(정상상태 도달). 그 차이가 설거지 결과(승패)까지 가는가.

### 1.2 계보와 규모

| 단계 | 개정 | 규모 | 무엇을 봤나 |
|---|---|---|---|
| RQ1 개루프 추종 | A1–A18 | 56,700런 | 게인·필터가 추종 오차를 어떻게 바꾸나 (교전 없음) |
| RQ2 모델 오차 | A19–A22 | 17,316런 | κ(제어효과 모델 오차)의 안정 경계 κ_s ≈ 0.42, 추종 경계 κ_f ≈ 8.4 |
| RQ3 유도추격 | A23–A30 | 606런 | 유도 루프를 닫으면 조준으로 전달되나 |
| E층 도그파이트 | A31–A33 | 6,560경기 | BT 대전에서 교전 결과가 바뀌나 |
| A35 명령 실현 | A35 | 2,080 + 4,480경기 | 판정 대상을 교전 결과에서 **명령 실현 충실도**로 전환 |
| A36 재실행 | A36 | 4,480경기 | 팀원 계보와 같은 기체·조건으로 재수행 |
| 주엽 계보 | — | 약 12,000경기 | 복합 최적화(PSO), 지연 반응 곡선, 필터 분리 |

### 1.3 탐구하고 싶었던 것과 실제로 나온 것

| 기대 | 실제 결과 |
|---|---|
| 튜닝하면 추종이 좋아지고 승률이 오를 것 | **명목 조건에서는 승률이 안 바뀜** (0.491 → 0.515–0.540, 유의하지 않음) |
| 파라미터마다 교전 영향이 다를 것 | **19/24 설정에서 명령 실현 변화가 조준·승률로 전달 안 됨** |
| 상승 시간으로 반응 속도를 재면 될 것 | **상승 시간은 외란·진동에 속는다** (난류에서 0.142 → 0.108 s로 "빨라짐") |
| — (예상 못 함) | **8–17 ms 센서 지연에서 기준 제어기가 붕괴**, 경기의 73–82 %가 지면 충돌 |
| — (예상 못 함) | **공개 JSBSim F-16 모델의 flaperon 부호 결함** — 약 2 G의 여분 하중 |

### 1.4 기존 실험이 만든 방법론 자산

새 실험에서도 그대로 쓰이는 것들이다.

| 자산 | 내용 | 새 실험에서의 대응 |
|---|---|---|
| **등가 판정** | δ(허용폭)를 미리 정하고 3구간 판정(차이 있음/없음/불가) | 그대로 계승. δ_D = 0.079 |
| **가짜 짝 SHAM** | κ = 1 + 10⁻⁶ — 물리적으로 구별 불가능한 설정. 혼돈이 만드는 잡음 바닥을 잰다 | 그대로 계승. E1이 SHAM으로 δ를 정한다 |
| **대응(짝) 설계** | 같은 시드·시나리오·상대에서 설정만 바꿔 비교 | 그대로 계승 |
| **데이터 분리** | 탐색/확증 시드를 나눠, 기준을 정한 데이터로 판정하지 않는다 | 그대로 계승. `feas*` / `cal-*` / `main-*` / `gen-*` |
| **flaperon 모델 수정** | 공개 F-16 모델의 부호 결함 수정 | 그대로 계승 (`RESEARCH_PLAN.md` §5.1) |
| **종료 사유 분해** | 승패를 격추·지면충돌·시간종료·무접촉·실속으로 나눔 | 그대로 계승. **D의 정의에 들어감** |
| **사전등록** | 실행 전 규칙 등록, 사후 변경은 ⚠로 기록 | 그대로 계승 (`REVIEW_LOG.md`) |

**이것이 중요한 이유**: 새 논문의 Ⅳ장(방법)은 사실상 **기존 계보가 만든 절차**다. 그 절차를
누가 왜 만들었는지는 `EXPERIMENT_MASTER_20261001.md` §4, §6.1에 전부 기록되어 있다.

## 2. 새 실험 — 무엇을, 왜, 어떻게 했나

### 2.1 새 주제

> **「피치 추종 오차를 이용한 공중전 성과 변화 예측: INDI 제어 F-16 시뮬레이션 연구」**

연구 질문은 이것이다.

> 교전 중에 **"명령한 피치 회전과 실제 피치 회전의 차이"(피치 추종 오차) 하나만 재면**,
> 원인이 무엇이든 승패가 얼마나 달라질지 예측할 수 있는가.

**비유(운전대)**: 운전대를 늦게 따라오는 원인은 여러 가지다(바퀴 정렬, 헐거운 운전대, 느린 센서).
원인이 무엇이든 **"운전대를 돌린 만큼 차가 얼마나 빗나가는가"만 재서** 레이스 성적이 얼마나
나빠질지 맞힐 수 있는가.

### 2.2 주제가 바뀐 과정 (`FEASIBILITY.md` §1)

| 단계 | 후보 주제 | 결과 | 버린 이유 |
|---|---|---|---|
| 1 | INDI 설정이 리그 순위에 강건한가 | 2,520경기 | 이 리그에만 해당해 공학적 의의가 좁다 |
| 2 | INDI 안정 여유와 교전 성과의 **임계** 관계 | 7,200경기 | **가설과 반대.** 필터별 곡선이 τ·f_c 축에서 안 겹치고, 교전 결과에 꺾이는 점이 없었다 |
| 3 | **피치 추종 오차로 성과 변화 예측** | 채택 | 단계 2 데이터에서 D와 mae의 순위 상관이 **0.95**였다 (τ·f_c로는 0.69) |

**핵심**: 단계 2에서 **임계 가설이 기각된 것**이 단계 3의 출발점이다. "꺾이는 점은 없지만
**매끄럽게 비례한다**"는 관찰이 곧 "예측 가능하다"는 새 주제가 되었다.

### 2.3 두 변수의 정의

| 변수 | 기호 | 정의 | 코드 |
|---|---|---|---|
| **예측 변수** | mae | 교전 중 피치 각속도 명령과 실제의 차이, 절댓값 평균, **양 기체 평균** [°/s] | `blue_mae_q_dps`, `red_mae_q_dps` |
| **결과 변수 (주)** | D | 같은 시드·대진·시나리오의 기준 경기와 **승자 또는 종료 사유가 다른 경기의 비율** | `predict.py:per_seed` |
| **결과 변수 (보조)** | M | 참가자별 리그 점수 변화 절댓값의 평균 [점/리그 한 바퀴] | 같은 함수 |

**D가 왜 좋은 지표인가**: 승률만 보면 "이긴 쪽이 바뀌었는지"만 본다. D는 **종료 사유까지 본다.**
같은 쪽이 이겼어도 격추로 이기던 것이 시간 종료 승으로 바뀌면 "결과가 달라졌다"로 센다.
기존 실험에서 "승패의 73–82 %가 지면 충돌"이라는 문제를 지적했는데, D는 그 구분을 **정의에 넣어** 해결한다.

### 2.4 네 개의 실험

| 실험 | 시드 | 규모 | 답하는 질문 | 결과 |
|---|---|---|---|---|
| **E1 보정** | `cal-*` 8개 | 2,688경기 | 잡음 바닥은 얼마인가 | SHAM의 D = 0.013–0.048 → **δ_D = 0.079** 등록 |
| **E2 적합** | `main-*` 8개 | 28,224경기 | mae와 D의 관계는 어떤 모양인가 (RQ1) | **D = 0.144 + 0.0531·mae**, 잔차 RMS 0.028 |
| **E3 검증** | `main-*` 8개 | 30,912경기 | 원인이 달라도 같은 곡선인가 (RQ2) | **전 원인 예측 성공** |
| **E4 일반화** | `gen-*` 4개 | 11,088경기 | 다른 전술 12종에서도 되는가 (RQ3) | 6조건 중 5개 성공, **SHAM만 −0.142 빗나감** |

**설계의 핵심**: E2는 **필터 × 비동기 지연**으로만 곡선을 맞춘다. E3는 **E2에 없던 원인**
(κ, k_q, 잡음, 동기 지연, 조합)으로만 검증한다. 곡선을 맞춘 데이터와 검증하는 데이터가 다르다.
이것을 **표본 밖 예측(out-of-sample prediction)**이라 하고, 대리 지표 타당성 검증의 표준 방법이다.

| 동기 지연 | +0.003 [−0.007, +0.011] | 예측 성공 |

## 3. 두 실험의 대응 관계

### 3.1 같은 것

| 항목 | 내용 |
|---|---|
| 시뮬레이터 | JSBSim 1.3.1 F-16, flaperon 부호 수정 모델, 5계층 스택, 120 Hz |
| 흔든 변수 | f_c(필터), 비동기·동기 지연, κ, k_q, σ — **여섯 원인이 거의 같다** |
| 짝 설계 | 같은 시드에서 BASE와 조건을 짝지어 비교 |
| 잡음 바닥 | SHAM(κ = 1 + 10⁻⁶) |
| 허용폭 | δ = max(SHAM 분포의 2배, 실용 바닥) |
| 종료 사유 | 격추·지면충돌·시간종료·무접촉·실속 5종 |

### 3.2 다른 것

| 항목 | 기존 | 새 실험 | 왜 바뀌었나 |
|---|---|---|---|
| **묻는 것** | 영향의 유무 | 영향 크기의 예측 가능성 | 유무만 물으면 "조건부"로 끝나 논문이 약하다 |
| **판정 단위** | 변수 × 지표마다 따로 | 원인 묶음별 예측 오차 하나 | 변수마다 따로 보면 "판정 불가"가 쏟아진다 |
| **1순위 지표** | reach63, ss_ratio, t63, t90, tau_eq (5종) | **mae 하나** | 지표를 하나로 줄여야 "싼 대리 지표"가 된다 |
| **독립 단위** | 짝 (설정당 160짝) | **시드 (리그 한 바퀴)** | 리그 전체를 한 표본으로 봐야 순위·점수를 쓸 수 있다 |
| **상대** | 적군 5종 고정 | **참가자 8종(E1–E3), 12종(E4) 리그 전원 총당** | 전술 다양성이 커져 일반화가 가능해진다 |
| **시나리오** | 4종 | 3종 (headon, perch_offense, neutral) | — |
| **열화 강도** | κ ≤ 25, σ ≤ 1.0 | **κ ≤ 50, σ ≤ 6, 동기 지연 ≤ 16틱** | 추종 오차 범위를 넓혀야 곡선을 채운다 |
| **결과의 방향** | 음성 결과가 중심 | **양성 결과가 중심** | §4 참조 |

### 3.3 지표 대응표 — 기존 지표는 새 실험 어디에 있나

| 기존 지표 | 새 실험에서 | 비고 |
|---|---|---|
| `corr_q` (추종 상관) | 보고서에 **그대로 있음** ("피치 추종 상관" 열) | E2 표에서 0.964 → 0.225까지 변함 |
| `t63_q`, `t90_q` (상승 시간) | **쓰지 않음** | 기존 실험에서 "외란에 속는다"고 밝혀 뺀 것과 같은 판단 |
| `reach63_q` (도달 비율) | **쓰지 않음** | 교차 검증에서 붕괴 시 1.00이 되는 문제 (§5.2) |
| `ss_ratio_q` (정상상태 비) | **직접 대응 없음**. mae가 비슷한 역할 | mae는 전 구간 평균 오차, ss_ratio는 정상상태만 |
| G 실현률 | **쓰지 않음** | 주엽 계보의 지표 |
| 승률, HP 차 | M(점수 변화)에 흡수 | |
| 종료 사유 | **D의 정의에 들어감** | 승자 + 종료 사유가 D의 비교 대상 |

**핵심**: 새 실험의 **mae는 기존 실험의 어느 지표와도 정확히 같지 않다.** 기존 1순위 5지표는
"계단 응답"을 보는 이벤트 기반 지표이고, mae는 **교전 전 구간의 평균 절대 오차**다. 더 단순하고,
그래서 "싼 대리 지표"라는 주제에 더 맞는다.

## 4. 왜 새 주제가 논문으로 더 나은가

### 4.1 기존 주제의 구조적 약점

기존 질문은 "영향을 주는가"였고, 답은 **"명목 조건에서는 안 주고, 지연 조건에서는 크게 준다"**였다.
이것은 사실이고 중요하지만, 논문으로 쓰면 두 문제가 있다.

1. **주 결과가 음성이다.** "대부분의 설정에서 전달되지 않았다"가 결과표의 대부분을 차지한다.
   음성 결과를 등가 판정으로 뒷받침한 것은 방법론적으로 훌륭하지만, 발표장에서 "그래서 뭐"가 된다.
2. **긍정 결과가 설명을 요구한다.** 지연 붕괴는 극적이지만 "기준 제어기가 원래 나쁜 것 아니냐",
   "승패의 대부분이 추락 아니냐"는 반론을 받는다.

### 4.2 새 주제가 그 약점을 흡수하는 방식

| 기존의 문제 | 새 주제에서의 처리 |
|---|---|
| "대부분 전달 안 됨"이 음성 결과 | **곡선의 낮은 구간**이 된다. mae가 작으면 D도 작다는 것은 곡선의 일부일 뿐 음성 결과가 아니다 |
| "지연에서만 크게 바뀜" | **곡선의 높은 구간**이 된다. 지연이 mae를 크게 만들기 때문이라고 설명된다 |
| "승패가 추락 아니냐" | **D의 정의에 종료 사유가 들어가 있다.** 추락으로 끝나는 것도 "결과가 달라진 것"으로 센다 |
| "어느 지표가 맞나" | **지표를 mae 하나로 고정**하고, 그 하나가 예측하는지를 묻는다 |
| 원인별로 다른 결론 | **원인 무관성 자체가 연구 질문**이 된다 (RQ2) |

**즉 새 설계는 기존 실험의 음성 결과와 미해결 쟁점을 "답해야 할 질문"이 아니라
"곡선의 일부"로 바꾼다.** 이것이 재설계의 핵심이다.

### 4.3 공학적 의의가 분명하다

새 주제의 의의는 한 문장으로 말할 수 있다.

> 제어기를 바꿀 때마다 교전을 수천 번 돌리는 대신, **대표 교전 몇 번의 추종 오차만 재서**
> 승패 영향을 미리 가늠할 수 있다.

기존 주제의 의의("INDI 파라미터가 도그파이트에 영향을 준다/안 준다")보다 **쓸 데가 분명하다.**

## 5. 기존 실험을 새 논문에 얼마나 반영할 수 있나

### 5.1 그대로 쓸 수 있는 것 (Ⅲ·Ⅳ장)

| 내용 | 기존 출처 | 새 논문에서의 자리 |
|---|---|---|
| **flaperon 부호 결함과 수정** | 주엽 계보 §2.4, 우리 A36 §10의 2×2 원인 분해 | Ⅲ-A. **독립 기여로 쓸 수 있다** |
| 2×2 원인 분해 (모델 vs 봉투) | `EXPERIMENT_MASTER` §5.7 | Ⅲ-A 또는 부록. 모델 수정이 필요했다는 증거 |
| **등가 판정 틀**과 δ 도출 논리 | `EXPERIMENT_MASTER` §4 | Ⅳ-E. 새 실험이 그대로 쓴다 |
| **가짜 짝(SHAM)의 논리** | A31 §5, A35 §5 | Ⅳ-E |

### 5.2 결과로는 쓸 수 없지만 **논거로** 쓸 수 있는 것 (Ⅱ·Ⅵ장)

새 실험과 **조건이 다르므로 수치를 한 표에 섞으면 안 된다.** 다만 다음은 논의에서 인용할 수 있다.

| 내용 | 왜 수치를 못 섞나 | 어떻게 쓰나 |
|---|---|---|
| **상승 시간이 외란에 속는다** | 기존은 계단 이벤트 지표, 새 실험은 평균 절대 오차 | Ⅳ-B에서 **"왜 mae를 골랐는가"**의 근거. "상승 시간은 진동 시 오히려 짧아진다(별도 실험)" |
| **지연 8–17 ms 붕괴** | 상대·시나리오·지표가 다름 | Ⅵ 논의에서 "같은 스택의 별도 실험에서 관측" |
| **대칭/비대칭 대조** (상대적 우위 vs 절대적 강건성) | 새 실험에는 이 축이 없음 | Ⅵ 논의. **새 실험의 한계를 보완하는 내용** |
| 명목 조건에서 전달 없음 | 지표 정의가 다름 | Ⅰ 서론 ¶3(공백) 또는 Ⅵ |
| `reach63`이 붕괴 시 1.00이 된다 | 새 실험은 이 지표를 안 씀 | Ⅳ-B에서 지표 선택 근거 |

### 5.3 쓸 수 없는 것

| 내용 | 이유 |
|---|---|
| A35·A36의 1순위 판정표 전체 | 지표·상대·시나리오가 다르다. 새 논문의 결과표와 충돌한다 |
| E층 OFAT/결합 설계 결과 | 주 지표가 교전 결과였고 80건 중 58건이 판정 불가 |
| 봉투 게이트 결과 | 새 실험에 봉투 게이트가 없다 |
| RQ1·RQ2·RQ3의 개루프 수치 | 교전이 없는 벤치 결과. 새 실험의 "벤치"와 설계가 다르다 |

### 5.4 반영 비율 — 솔직하게

| 장 | 기존 실험 반영도 | 설명 |
|---|---|---|
| Ⅰ 서론 | **30 %** | 공백 서술에 "제어 연구는 추종을, 공중전 연구는 전술을 본다"가 기존 경험에서 나왔다 |
| Ⅱ 관련 연구 | 10 % | 문헌 목록은 공유하지만 새로 확인해야 한다 |
| **Ⅲ 환경과 제어기** | **80 %** | 모델 수정, 제어 법칙, 주입 경로, 수준 선정 근거가 전부 기존 자산 |
| **Ⅳ 방법** | **70 %** | 등가 판정, SHAM, 짝 설계, 데이터 분리, 종료 사유 분해 |
| Ⅴ 결과 | **0 %** | 전부 새 실험(E1–E4) |
| Ⅵ 논의 | **40 %** | 상승 시간의 함정, 지연 붕괴, 상대적/절대적 구분 |
| Ⅶ 결론 | 0 % | 새 실험 |

**정리**: 기존 실험은 **결과가 아니라 방법과 환경으로 들어간다.** 결과 장은 전부 새 실험이고,
방법·환경 장의 절반 이상이 기존 계보가 만든 것이다. 두 달의 작업이 버려지는 것이 아니라
**논문의 하부 구조가 된다.**

### 6.2 제3자 검토 결과 (2026-10-19 확정)

전체는 `docs/FEEDBACK_FOR_CADET_v1.md`에 있다. **핵심 둘만 옮긴다.**

**(1) RQ2(원인 무관성)는 기각된다.** 등록된 판정은 "원인별 평균 예측 오차"만 보는데,
**기울기**를 재면 전부 다르다. (원자료에서 독립 재계산으로 확인)

| 묶음 | 기울기 | 적합(0.0531) 대비 |
|---|---|---|
| κ | 0.2029 | **3.8배** |
| 조합 | 0.1737 | 3.3배 |
| 동기 지연 | 0.1323 | 2.5배 |
| σ | 0.0988 | 1.9배 |
| k_q | 0.0161 | **1/3.3배** |

구간을 맞춰 비교해도 κ는 3.6배, k_q는 3.1배 차이다. "비선형을 기울기로 오인"이 아니다.

**(2) D는 "성과 변화"가 아니라 "결과 재배열"이다.** 열화를 양 기체에 **대칭**으로 걸기 때문에
총 승수가 구조적으로 고정된다(BASE 1307승, F5_D6 1313승). 보조 지표 M도 168칸 중 "차이 있음"이 2칸뿐이다.

**이것이 기존 실험과의 관계에 주는 함의**: 우리 계보가 쓴 **대칭/비대칭 대조**
(`EXPERIMENT_MASTER_20261001.md` §5.8)가 바로 이 문제를 가르는 장치였다.
새 실험에는 그 축이 없다. **Ⅵ 논의에서 우리 결과를 인용해 한계를 보완할 수 있다** — §5.2의 표 참조.
