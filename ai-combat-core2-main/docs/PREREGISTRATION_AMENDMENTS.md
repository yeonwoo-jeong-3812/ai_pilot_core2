## A1 — 2026-09-14 — §3.2 J_r 수치 서술 정정 (결정 변경 없음)

- **원문**: "J_r = 2.5/1.5 = 1.667 로 파라미터와 무관하게 고정된다."
- **실측 (게이트 G4, M3 롤링 풀 Nz 4, 15000 ft/400 KCAS)**: k 배율 (1,1,0.5) / (1,1,1) / (1,1,2) / (1.5,1.5,1.5)
  에서 J_r = 1.574 / 1.569 / 1.559 / 1.593. 상대 범위 2.2%. RMS(r_sp) = 1.87~1.91 deg/s 로 분모 하한(2 deg/s)
  근처였다.
- **정정**: "파라미터와 무관" 이라는 주장은 확인됐다. 값이 정확히 1.667 이 아닌 이유는 (1) 지령 r_sp 는 스텝 전 r 로,
  기록 r 은 스텝 후 값이라 한 틱 어긋나고, (2) 분모 하한이 일부 걸리기 때문이다. **J_r 을 주 지표에서 빼는 결정은 유지한다.**
- **본 데이터**: 게이트 시험 데이터만. RQ1/RQ2 본실행 데이터 없음.

## A2 — 2026-09-14 — §7.1 부호반전 데드밴드의 한계 (미해결, 결정 필요)

- **원문**: 부호반전 판정에 데드밴드 0.02 를 둔다(잡음 거짓 양성 방지). 무잡음에서는 탐색 단계 판정과 같다.
- **실측 (게이트 G4)**:
  - 무잡음 동치: 탐색 단계 225런(corner_pull 100 + indi_step 125)에서 새 판정과 기존 판정이 **225/225 일치**. 확인됨.
  - 트림 주변 가우시안 명령 채터 1200틱에서 부호반전율 [데드밴드 0.02 / 데드밴드 없음]:
    σ=0.004: 0.00 / 60.8 Hz, σ=0.008: 0.70 / 60.8 Hz, **σ=0.012: 4.90 / 60.8 Hz**, **σ=0.02: 17.71 / 60.8 Hz**
    (게이트 보고서 `research/l3_indi/gate_reports/e78bc3ed82.md`).
- **한계**: 데드밴드 0.02 는 명령 채터 σ ≈ 0.008 까지만 거짓 양성을 판정 임계(1 Hz) 아래로 막고, σ = 0.012 에서 이미 4.9 Hz 로 임계를 넘는다. **RQ1-N 의 높은 잡음 수준
  (σ_g 0.3, 1.0 deg/s)에서 명령 채터가 이보다 크면, 실제 리밋사이클이 없어도 `oscillating = 1` 로 잘못 분류될 수 있다.**
- **처리 (RQ1-N 본실행 전에 결정해야 함, 사용자 결정 대기)**:
  - 안 1: 부호반전 기준은 각속도 p2p 가 0.5 deg/s 이상일 때만 적용 (진동은 조종면만이 아니라 기체 운동으로 나타나야 함).
  - 안 2: 부호반전 판정을 2 Hz 저역통과한 명령에 적용.
  - 안 3: 원문 유지하고, 잡음 조건에서는 부호반전 기준만으로 불안정 판정된 런의 수를 따로 보고.
- **본 데이터**: 게이트 시험 데이터만.
