## A7 — 2026-09-14 — 실전 기동 분류와 합성 기동 대표성 판정 규칙 (궤적 분석 전 고정)

**신호**: L3 틱(120 Hz). 롤은 리미터 통과 p_sp, 당김은 **지령 Nz n_cmd = q_sp·V/g + cosφ·cosθ** (q_sp 는 리미터 통과 지령).
`g_target` 은 쓰지 않는다 — `bfm_guidance.py:349`(stable_track 모드)는 중력항 없이 q·V/g 이고 `:366` 은 중력항을 포함해
모드마다 의미가 달라서다.

**사건**:
- 롤 사건: |p_sp| ≥ **30 deg/s** 연속 구간, 0.25 s 이하 틈은 병합, 길이 ≥ 0.25 s.
- 롤 반전: 롤 사건 중 시작·끝 뱅크가 모두 |φ| ≥ 20° 이고 부호가 반대(뱅크는 [−180°, 180°] 로 감음).
- 당김 사건: n_cmd ≥ **2.5** 연속 구간, 0.25 s 이하 틈 병합, 길이 ≥ 0.5 s.
- 당김 사건 시작 시각 t0 에 대해 [t0 − 0.5 s, t0 + 1.0 s] 와 겹치는 롤 사건이 있고, 그 롤 사건의 |Δφ| ≥ 30° 이면 **롤링 풀**, 아니면 **G 포착**.

**틱 라벨 (우선순위 순)**: roll_reversal > rolling_pull > g_capture > roll_other(반전·롤링 풀이 아닌 롤 사건) > unload(n_cmd < 0.5) > low_g(나머지).
"기동 시간" = low_g 를 뺀 전체.

**보고**: 범주별 시간 비율, 분당 사건 수, 지속시간 p10/p50/p90, 그리고
- 롤 반전: |Δφ|, 피크 |p_sp|, 사건 중 n_cmd 중앙값
- G 포착: n_cmd 중앙값(절대값과 **C_nz 대비 비율** — 사건 시작 시점 고도·KCAS 로 능력표 쌍선형 보간, FLCS on), 사건 중 |φ| 중앙값, 10→90% 상승시간
- 롤링 풀: 롤 |Δφ|, n_cmd 중앙값과 C_nz 대비 비율
- 기동 구간 고도·KCAS 분위수, p_sp·q_sp 의 95% 파워 대역폭
- 민감도: 롤 임계 20/45 deg/s, 당김 임계 2.0/3.0 G 에서 범주별 시간 비율

**대표성 판정 규칙**:
- R1 포괄률: 기동 시간 중 roll_reversal + rolling_pull + g_capture 비율. **roll_other + unload 가 기동 시간의 20% 를 넘으면**
  합성 기동이 포괄하지 못하는 유형이 있다고 판정한다.
- R2 매개변수: 합성 기동의 각 매개변수 값이 실전 분포의 **p10~p90 밖이면 비대표**로 판정한다.
  M1 {C_nz 비율 0.4/0.6/0.8, 유지 5 s, 뱅크 0°}, M2 {|Δφ| 120°, 피크 |p_sp| 180 deg/s, 한쪽 유지 3 s, 60° 에서 n_cmd 2.0},
  M3 {|Δφ| 70°, C_nz 비율 0.6/0.8, 길이 6 s}. 수준이 여럿인 매개변수는 수준마다 판정하고, 실전 사건 중 최저~최고 수준 사이에
  드는 비율도 함께 보고한다.
- R3: 비대표 판정이 나오면 **본실행 전에** 실전 분위수에 맞춘 수정안을 제안하고, 사용자 승인 후 개정 기록을 남긴 뒤 반영한다.
  이 판정 결과를 보고 규칙 자체를 바꾸지 않는다.

## A10 — 2026-09-16 — 지표·조건 추가 (사용자 결정)

### A10-1 시간척도 분리 잔차 ε (관측 전용, 필수)

- **기록 추가**: `harness.run` 에 참 각가속도 `accelerations/[pqr]dot-rad_sec2` 3열. 제어 경로는 바꾸지 않는다(G1·G2 재통과로 확인).
- **정의** (틱 k 와 k−1 이 모두 창 W 안):
  - Δω̇_k = ω̇_k − ω̇_{k−1}
  - Δu_k = u_k − u_{k−1}, u = 플랜트가 실제로 받은 `fcs/{aileron,elevator,rudder}-cmd-norm` (입력 지연 조건에서도 지연 후 값)
  - G_k = (max(q̄_k, q̄_min) / q̄_ref) · **G0_true** (λ 를 주입한 G0_model 이 아님)
  - r_k = Δω̇_k − G_k · Δu_k
  - 런 요약: 축 i 마다 **ε_i = Σ_k |r_{i,k}| / Σ_k |Δω̇_{i,k}|** (틱별 비율 대신 합의 비율 — 분모가 0 근처인 틱의 폭주 방지). 분모 < 1e-9 이면 NaN.
  - 잡음 조건에서도 참 값으로 계산한다(§2.1).
- **해석 규정**: FLCS on 에서 u 는 FLCS 스틱 명령이므로 ε 는 "상태 의존항 F(x − x₀) + FLCS·액추에이터 동특성 + 1틱 증분 모델 오차"의 합이다.
  논문에서 순수 공력 항으로 서술하지 않는다.
- **히트맵**: RQ1 기준 파라미터 런(9조건 × 기동 × FLCS 각각, 무잡음)의 틱을 α 2° × Nz 0.5 G 칸에 모아 칸별 ε_i(합의 비율)를 그린다. 틱 < 120 칸은 비운다.
- **사전 지정 분석** (결정론이라 p값 없음, 블록 수 n 을 함께 보고):
  - (a) 기준 파라미터 블록들에서 ε(주 축)와 주 지표 J 의 Spearman ρ.
  - (b) RQ2 블록마다 λ = 1 런의 ε 와 log λ_f, log λ_s 의 Spearman ρ.
  - H2 판정: 예상 방향은 ρ(ε, log λ_f) < 0, ρ(ε, log λ_s) > 0 (가정 위반이 클수록 경계가 λ = 1 쪽으로 좁아짐).
    두 방향이 모두 맞고 |ρ| ≥ 0.5 이면 "지지", 방향만 맞으면 "약한 지지", 하나라도 반대면 "불지지".

### A10-2 기동 실현도 F_i 와 T→M 전이 (필수)

- **기록 추가**: `velocities/v-{north,east,down}-fps` 3열.
- **대상 기동**: M1, M3 (Nz 목표가 있는 기동). M2a/M2b 는 기존 뱅크 지표(§4)를 쓴다.
- **정의**:
  - 실측 경로 회전율 Ω_act,k = arccos(v̂_k · v̂_{k−1}) / Δt (v̂ = NED 속도 단위벡터)
  - 이상 경로 회전율 Ω_ideal,k = (g / V) · √(n_t² − 2·n_t·cosμ·cosγ + cos²γ). n_t = 그 틱 Nz 목표(`gc_g`), γ = 참 비행경로각,
    μ = 참 속도축 뱅크(동체축 → 속도축 변환, α·β·φ·θ·ψ 사용). 뜻: "명령한 Nz 를 같은 자세에서 즉시 다 냈다면 속도벡터가 돌았을 빠르기".
    (수평 선회 n_t = 1/cosμ, γ = 0 에서 g·tanμ / V 로 줄어드는 것을 G9 에서 확인)
  - **F_i = Σ_W Ω_act / Σ_W Ω_ideal**
- **대체 규칙(사전 고정)**: 게이트 G9 — (i) 트림 수평 협조선회 상태에서 n_t 에 실측 Nz 를 넣은 F_i 가 1 ± 0.05,
  (ii) β ≈ 0 수평 비행에서 μ 와 φ 차이 ≤ 0.5° — 를 통과하지 못하면 M층 지표를 **Nz 실현율(§4)** 로 대체하고 그 사실을 기록한다.
- **T→M 전이** (RQ1·RQ2 의 안정·열화 런, 이탈·검열 제외):
  - D_T = J / J_ref − 1, D_M = 1 − F_i / F_i,ref (ref = §7.1 기준 런, RQ2 는 λ = 1 런)
  - 두 모형을 비교한다. 선형 D_M = a·D_T / 힌지 D_M = a·max(0, D_T − x₀) (x₀ 는 D_T 의 1~99% 분위 격자에서 탐색).
    **BIC 차 ≥ 10** 이면 "임계형"으로 판정하고 x₀ 를 보고, 아니면 "선형"으로 판정한다. 기동(M1, M3)과 FLCS 설정별로 따로 적합한다.
- **기동 경계 λ_M**: RQ2 에서 F_i / F_i(λ = 1) < **0.90** 이 처음 되는 λ (λ > 1 쪽, λ < 1 쪽 각각. 민감도 0.80 / 0.95).
  보고: |log λ_M − log λ_f| ("추종 저하가 기동 저하로 번지기까지의 간격"). 보간·불확도 표기는 §7.2 와 같다.

     블록별 주 지표 비율(같은 블록의 (a) 런 대비: M1 J_q, M2a J_p, M3 J_p 와 J_q 둘 다)의 **기하평균이 최소**인 설정.
     동률(차 < 1e-6)이면 (a)에서 log 배율 L1 거리가 작은 쪽. 조건을 만족하는 설정이 (a)뿐이면 (b) = (a) 로 보고한다.
   - 두 번째 대조축은 기존 FLCS on/off.
3. **RQ2 범위**: "공력·관성 불확실성"이 아니라 **제어기가 쓰는 제어효과 모델의 오차 λ**. 질량·관성·공력 섭동과 난류·바람은 수행하지 않고 한계로 보고한다.

5. **RQ2 조건과 대표 설정** (§9 에서 선택 규칙이 없던 부분):
   - 조건 3개 = 14 kft × KCAS {250, 350, 400} (P2 고도 p50 격자점. 동압 차이로 H2 를 본다).

   14 kft / 350 KCAS, M1 0.8 과 M3 0.9, FLCS on, 무잡음 = 288 런. 열화 구간의 폭을 보고한다.
