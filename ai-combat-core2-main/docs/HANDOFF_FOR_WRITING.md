## 1. 논문에 바로 쓸 문장

세 문장이다. 그대로 써도 되고 다듬어도 되지만, **괄호 안의 조건을 빼면 안 된다.**

> **수치 갱신 (2026-09-30).** 아래 문장의 수치는 모두 수정 모델 f16fix · 교범 봉투 · 자이로 잡음 σ 0.1 에서
> 다시 돌린 실행의 값이다. 이전에 전달한 숫자와 다르면 **이 쪽이 맞다.** 무엇이 왜 바뀌었는지는 §3의 표마다 적었다.

### 문장 1 — 결과 절 첫머리 (4장 1절 후보)

> INDI 파라미터는 명령 실현 충실도를 바꾼다. 제어 효과 모델 오차 κ, 피치 게인 배율 k_q, 측정 지연은 등가 한계 δ를
> 넘어 충실도를 바꾸었다. 반면 **동기화 필터 차단주파수(10~50 Hz)와 자이로 잡음(명목 σ = 0.1 °/s의 3배까지)은
> δ 안에서 바꾸지 않았다.**

- **근거**: 표 3 (4,480경기). 필터 4수준 + 잡음 0.03·0.3 = 6설정이 도달 비율·정상상태 도달 비·실효 응답 지연
  세 지표 전부에서 "차이 없음". 잡음은 명목의 10배(σ = 1.0)에서 비로소 정상상태 도달 비가 벗어난다.
- **반드시 함께 쓸 것 (중요)**: 이 판정은 **명목 자이로 잡음이 있는 조건에서 얻은 것**이다. 잡음이 없으면
  동기화 필터가 걸러 낼 것이 없어 차단주파수가 명목 성능을 바꾸지 않는 것이 자명하다. 잡음 조건을 밝히지 않으면
  이 결과는 무의미해 보인다.
- **또 함께 쓸 것**: "차이 없음"은 등가 판정이지 측정 실패가 아니다.
- **약한 고리**: 상승시간 63 %는 검정력이 부족하다(§7 한계 3). 이 지표의 "차이 없음"은 근거로 쓰지 말 것.

### 문장 2 — 방법론적 기여 (3장 지표 절 또는 5장 고찰 후보)

> 명령 실현 충실도의 차이는 기존의 추종 상관(corr_q)이 포착하지 못하는 성분을 포함한다. 비동기 2틱 지연은 추종
> 상관을 0.938에서 0.692로 떨어뜨리지만 계단 응답은 기준과 구별되지 않는다. 반대로 대기 난류(강)는 추종 상관을
> 0.471까지 떨어뜨리면서 상승 시간은 오히려 단축시키고(0.142 s → 0.108 s) 도달 비율을 1.000까지 높이며, 이때
> 저하가 나타나는 지표는 정상상태 도달 비뿐이다(0.979 → 0.870). 따라서 상승 시간만으로 반응 속도를 평가하면
> 외란에 오도되며, 정상상태 도달 비를 함께 보아야 한다.

- **근거**: 표 5. 설정 단위 상관은 상승시간 63 % −0.320, 도달 비율 +0.464, 실효 응답 지연 −0.542,
  정상상태 도달 비 +0.787.
- **이 문장이 이 논문의 방법론적 기여다.** 지표 두 개를 함께 써야 하는 이유를 데이터로 보였다.
- **주의**: 난류가 상승 시간을 빠르게 하는 **기전은 검증하지 않았다**(§7 한계 2).
  "임계선을 우연히 일찍 통과한 것으로 보인다" 정도로만 쓴다.

### 문장 3 — 결론 (5장 고찰 또는 6장 결론 후보)

> 명령 실현 충실도의 차이가 교전 결과로 전달되는지는 조건부였다. 제어 효과 모델 오차에서는 역방향으로 전달되어,
> 충실도를 희생하는 대신 조준과 승률이 개선되었다. 그러나 적군에도 동일한 모델 오차를 주입한 대칭 조건에서
> **조준 이득과 승률 이득이 모두 소멸하였다**(승률 +18.3 %p → +3.1 %p, 차이 −15.2 %p, 95 % CI [−25.0, −5.0];
> 조준 +0.070 → +0.036, 차이 −0.035 [−0.062, −0.008]). 반면 명령 실현 충실도의 저하는 대칭 조건에서도 그대로였다.
> 즉 모델 오차가 만드는 것은 청군의 명령 실현 저하뿐이고, 조준과 승률의 이득은 모두 적군과의 차이에서 오는
> 상대적 우위다. 대기 난류에서는 정방향으로 전달되어 충실도와 승률이 함께 저하되었다. 나머지 19개 설정에서는
> 전달되지 않았다.

- **근거**: 표 4(사슬), 표 6(대칭 조건), 그림 1(`chain.pdf`).
- **⚠ 이전에 전달한 문장과 다르다.** 이전에는 "조준 이득은 유지되었다"였다. 수정 모델에서는 조준 이득도
  소멸하므로 결론이 한 갈래로 단순해졌다. **이전 문장을 쓰면 안 된다.**
- **선행 근거**: 이 역방향은 우리 RQ3에서 이미 관측했다(`docs/RQ3_SUMMARY.md` H11·H31). 내부 루프가 명령 추종을
  잃으면서 기수가 우연히 빨리 지향되는 현상이다.
- **함께 쓰지 말 것**: "제어 파라미터가 F-16 성능 봉투를 넘게 만든다"는 문장. 수정 모델에서는 어느 설정도
  봉투를 넘지 않는다(표 7).
- **미승인 항목**: "상대적 우위" 해석은 지도교수 승인 대기 중이다.

## 2. 쉬운 말 사전

### 2.1 비유 — 수도꼭지

이 연구에서 계속 쓴 비유다. 발표나 서론에 써도 좋다.

- **수도꼭지 손잡이를 돌리는 것** = 상위 AI(전술·유도)가 "이만큼 회전해라"고 명령하는 것
- **배관** = INDI 제어기
- **실제로 나오는 물** = 기체가 실제로 내는 회전 속도
- **물이 얼마나 빨리 나오나** = 상승 시간 (`t63_q`, `t90_q`)
- **틀어놓은 만큼 나오나** = 정상상태 도달 비 (`ss_ratio_q`)
- **10번 틀어서 몇 번이나 원하는 양이 나왔나** = 도달 비율 (`reach63_q`)
- **손잡이를 돌리고 물이 반응할 때까지의 시차** = 등가 지연 (`tau_eq_q`)
- **그 물로 설거지를 다 했는가** = 교전 승패

**핵심 메시지**: 배관을 평가하려면 "물이 빨리 나오나"와 "틀어놓은 만큼 나오나"를 **둘 다** 봐야 한다. 설거지 결과는 부엌 사정(상위 전술)이 더 크게 좌우한다.

### 2.2 파라미터

| 이름 | 쉬운 설명 | 시험한 값 |
|---|---|---|
| **λ_q (제어 효과 모델 오차)** | 제어기가 "조종면을 이만큼 움직이면 기체가 이만큼 돈다"고 **믿는 정도**와 실제의 비. λ > 1이면 "잘 듣는다"고 과신해서 조종면을 덜 움직이고, 결과적으로 굼떠진다. **배관이 실제보다 굵다고 착각하는 것** | 0.5, 4, 8, 16, 25 (기준 1) |
| **k_q (피치 게인 배율)** | 오차를 보고 얼마나 세게 되받아칠지. 크면 빠르지만 진동하기 쉽다. **손잡이를 얼마나 급하게 돌리는가** | 0.5, 0.75, 1.5, 2 (기준 1) |
| **filt_hz (동기화 필터)** | 각속도를 미분해 각가속도를 얻을 때 먼저 잡음을 깎는 필터의 차단주파수. 낮으면 잡음은 잘 깎이지만 느려진다 | 10, 15, 35, 50 Hz (기준 25) |
| **측정 지연 (동기/비동기)** | 센서 값을 몇 틱 늦게 읽는가. 1틱 = 1/120초 = 8.33 ms. **동기**는 제어기 되먹임도 같이 늦춰 시각을 맞춘 것, **비동기**는 센서만 늦어 시각이 어긋난 것 | 동기 2·4·8틱, 비동기 1·2틱 (기준 0) |
| **σ_g (자이로 잡음)** | 각속도 센서에 섞이는 백색잡음의 크기 | 0.03, 0.3, 1.0 deg/s (**기준 0.1**) |
| **난류** | 대기 외란. 제어기 설정이 아니라 **바깥 환경**이다 | 약·중·강 (기준 없음) |
| **대칭 칸** | 적군에도 청군과 같은 설정을 넣은 조건. **"우리만 나빠진 것"과 "우리가 상대보다 나빠진 것"을 가르기 위한 장치** | λ 8, λ 25 |

**σ_g 서술 주의**: 기준값 0.1 deg/s는 비행시험에서 보고된 자이로 잡음을 120 Hz로 환산한 값의 약 2배다.
시험 수준 0.3과 1.0은 **문헌 근거가 없는 가상 수준**이므로, 논문에는 반드시 "명목의 3배 / 10배"라는 **상대 척도로** 쓴다.
전투기 기체 장착 상태의 실측 잡음은 원문을 확보하지 못했다.

> **[격자] 수준이 바뀐 이유**: 기준을 0.1로 올리면서 이전 수준 {0.01, 0.03, 0.1}의 최고값이 기준과 같아져
> 빈 칸이 된다. 그래서 {0.03, 0.3, 1.0}으로 올렸다. 0.3과 1.0은 선행 실험이 이미 쓴 값이다.

### 2.3 지표

| 이름 | 쉬운 설명 | 좋은 값 |
|---|---|---|
| **도달 비율 `reach63_q`** | 명령이 계단처럼 바뀐 뒤 0.5초 안에 목표의 63%까지 실제로 간 비율. 경기마다 계단이 중앙값 24개 있다(등가 한계를 정할 때 참조한 값은 32개 — 표 2 참조) | 1에 가까울수록 |
| **정상상태 비 `ss_ratio_q`** | 자리를 잡은 뒤 실제 회전 속도 ÷ 명령한 회전 속도. 0.8이면 시킨 것의 80%만 냈다는 뜻 | 1에 가까울수록 |
| **상승시간 `t63_q`, `t90_q`** | 목표의 63% / 90%에 처음 닿는 시각. 0.5초 안에 못 닿으면 0.5초로 **끊어서 기록**한다(검열) | 작을수록 |
| **등가 지연 `tau_eq_q`** | 명령과 응답을 겹쳤을 때 가장 잘 맞는 시간 밀기. 0.5초까지 찾는다 | 작을수록 |
| **추종 상관 `corr_q`** | 경기 내내 명령 파형과 응답 파형이 얼마나 닮았나 | 1에 가까울수록 |
| **조준 `frac_ata30_blue`** | 청군 기수가 적을 30° 안으로 겨눈 시간의 비율 | 클수록 |
| **순 WEZ `net_wez`** | 청군이 사격 가능 구역에 있던 시간 − 적군이 그랬던 시간 | 클수록 |
| **승률 [%p]** | 평균 승점차 ÷ 3 × 100 | 클수록 |

**등가 지연 이름 주의**: RQ1에도 "등가 지연"이 있는데 **다른 양이다.** RQ1은 같은 추종 오차를 내는 순수 지연을 역산한 값이고, 여기 `tau_eq_q`는 교차상관이 최대가 되는 시간 밀기다. 기준 조건에서 값이 우연히 비슷하지만(0.058 s 대 0.058~0.067 s) 같은 기호로 쓰면 안 된다.

**승률 환산 주의**: 엔진은 "접촉 없는 무승부"에 0점을 준다(승패 무승부는 1점). 설정마다 접촉 없는 경기 비율이 다르면 승점 차의 일부는 승패가 아니라 접촉 여부에서 온다. **논문에 각주로 밝힌다.**

## 3. 논문 표 초안

> **⚠ 2026-09-30 전면 갱신.** 아래 표는 모두 **수정 모델 f16fix · 교범 봉투 · 자이로 잡음 σ 0.1**에서
> 다시 돌린 실행(`b3c448ab85`, 4,480경기)의 값이다. 그 이전에 전달한 숫자는 **원본 공개 모델**에서 나온 것이라
> 지금은 쓰면 안 된다. 바뀐 표마다 아래에 **왜 바뀌었는지 한 단어**로 적었다.

### 표 1. 실험 설계

**캡션 초안**: 표 1. 확증 실험의 설계. 짝은 동일한 초기 조건(시나리오, 적군, 난수 솔트)에서 설정만 다른 경기를 뜻한다.

| 항목 | 값 |
|---|---|
| 기체 모델 | **f16fix** (flaperon 부호 수정) |
| G 봉투 | **교범 해석** G_max(V) |
| 명목 자이로 잡음 | **σ = 0.1 °/s** |
| 청군 전술 트리 | `config/tactics.yaml` 고정 |
| 적군 | 5종 |
| 시나리오 | 4종 (정면, 유리, 불리, 중립) |

| 설정당 경기 | 160 (= 5 × 4 × 8) |
| 설정 | 28 (기준 1, 가짜 짝 1, 단일변수 24, 대칭 2) |

| 경기 길이 | 300 s, 물리 120 Hz |
| 통계량 | 짝 차이 평균, 부트스트랩 95 % CI (짝 단위 복원추출 10,000회) |

### 표 2. 등가 한계 δ의 도출

**캡션 초안**: 표 2. 등가 한계 δ. 잡음 바닥은 물리적으로 구별 불가능한 두 설정(κ = 1 대 1 + 10⁻⁶)의 짝 차이 분포에서,
실용 바닥은 지표의 정의에서 나온다. δ는 둘 중 큰 값이다.

| 지표 | 잡음 바닥 | 실용 바닥 | **δ** | 실용 바닥의 근거 |
|---|---|---|---|---|
| 도달 비율 | 0.018 | **0.031** | **0.031** | 경기당 계단 32개 중 1개 |
| 정상상태 도달 비 | 0.001 | **0.010** | **0.010** | 지령의 1 % |
| 상승시간 63 % [s] | 0.000 | **0.008** | **0.008** | 1틱 (1/120 s) |
| 상승시간 90 % [s] | **0.020** | 0.008 | **0.020** | 1틱 |
| 실효 응답 지연 [s] | 0.000 | **0.008** | **0.008** | 1틱 |

> 1/24 = 0.042로 올리지 않았으므로 등록된 δ가 실측 기준보다 **좁고**, "차이 없음" 판정에 더 엄격하다.

## 7. 한계 — 한 줄씩

한계 절에 그대로 옮겨 쓸 수 있는 형태다.

1. **모델 오차 수준에 따라 대칭 조건에서 소멸하는 항목이 다른 이유를 설명하지 못한다.** κ = 25에서는 조준과
   승률이 모두 소멸하고 κ = 8에서는 어느 것도 유의하지 않다. 원본 모델에서는 반대 양상이었으므로 이 비대칭
   자체가 기체 모델에 의존한다.
2. **대기 난류가 상승 시간을 단축시키는 기전은 검증하지 않았다.** 외란이 응답을 흔들어 임계선을 우연히 일찍
   통과시킨 것으로 보이나, 확인하려면 별도 실험이 필요하다.
3. **상승시간 63 %는 κ ≥ 4에서 검열 상한에 포화하여 효과 크기를 측정하지 못한다.** 보고한 값은 하한이다.
   등가 한계가 신뢰구간 반폭보다 작아 등가 판정의 검정력도 부족하다.
4. **지령 계단이 없는 경기가 4.2 % 있으며(4,480경기 중 187경기), 이 결측이 특정 시나리오나 적군에 편중되었는지
   확인하지 않았다.**
5. **안정 경계는 자이로 잡음의 주입 경로에 의존한다.** 같은 조건에서 경로만 바꾸면 1.41배 차이가 난다.
   따라서 이 값은 본 연구의 주입 경로에서만 유효하며 다른 계보의 값과 비교하지 않는다.
   추종 경계는 경로에 둔감하다(1.12배).
6. **명목 잡음 조건에서 저속(250 KCAS 이하)의 일부 기동에 롤 축 4 Hz 떨림이 나타난다**(저속 블록의 33 %,
   350 KCAS 이상에서는 0 %). 피치 추종은 9 % 안에서 유지되므로 판정에는 쓰이지 않으나, 롤 보조 지표와 교전
   결과의 차이를 해석할 때 후보로 남긴다.
7. **자이로 잡음 수준 0.3과 1.0 °/s는 문헌 근거가 없다.** 명목(0.1 °/s)의 3배와 10배라는 상대 척도로만 해석한다.
   전투기 기체 장착 상태의 실측 잡음은 원문을 확보하지 못하였다.
8. **청군 전술 트리를 하나로 고정하였다.** 결론은 해당 전술 트리에 한정된다.
