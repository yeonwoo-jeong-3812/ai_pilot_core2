## 1. 제목과 주제

### 1.1 제목 (확정)

> **「피치 추종 오차를 이용한 공중전 성과 변화 예측: INDI 제어 F-16 시뮬레이션 연구」**
>
> Predicting Changes in Air-Combat Outcomes from Pitch Tracking Error:
> A Simulation Study of an INDI-Controlled F-16

**"시뮬레이션 연구"가 범위를 한정한다** — 실기 일반화를 주장하지 않는다는 뜻이고,
`REVIEW_LOG.md` S4가 W-01 규칙으로 확인한 사항이다.

### ⚠ 제목을 바꿔야 한다 (2026-10-19 정정)

이 문서의 첫 판은 "현행 제목 유지"라고 썼다. **그 판단을 철회한다.** 근거는 둘이다.

1. **"성과 변화"가 데이터로 뒷받침되지 않는다.** 열화를 양 기체에 **대칭으로** 걸기 때문에
   총 승수가 구조적으로 고정된다(BASE 1307승 대 F5_D6 1313승). D가 재는 것은
   **"결과 재배열"**이지 성과 저하가 아니다 (`FEEDBACK_FOR_CADET_v1.md` §2.2).
2. **RQ2가 기각된다.** 원인별 기울기가 적합 기울기 0.0531을 전부 벗어난다
   (κ 0.203, k_q 0.016). 뼈대 §10의 **대체 제목 조항이 발동되는 상황**이다 (같은 문서 §2.1).

**대체 제목 후보**

| 안 | 제목 | 비고 |
|---|---|---|
| A | 피치 추종 오차와 공중전 **결과 불안정성**의 관계: INDI 제어 F-16 시뮬레이션 연구 | "성과"를 "결과 불안정성"으로. 가장 안전 |
| B | 피치 추종 오차를 이용한 공중전 **결과 변화율** 예측과 그 **조건**: INDI 제어 F-16 시뮬레이션 연구 | 예측을 유지하되 "조건"을 제목에 넣음 |
| C | 제어기 열화가 공중전 결과에 미치는 영향의 **대리 지표 탐색**: 피치 추종 오차의 가능성과 한계 | 탐색적 성격을 앞세움 |

**팀에서 정할 것.** A가 가장 방어하기 쉽고, B가 기여를 가장 잘 보여준다.

### 1.2 한 문단 주제

> 전투기 비행제어기는 센서 지연, 모델 오차, 게인 오설정, 잡음 등 여러 이유로 나빠진다.
> 그 변화가 공중전 결과에 얼마나 영향을 주는지 알려면 지금은 교전을 수천 번 돌려야 한다.
> 이 연구는 **교전 중 피치 추종 오차 하나**를 재서 그 영향을 미리 가늠할 수 있는지 묻는다.
> JSBSim F-16과 INDI 각속도 제어기 위에서 전술 8종의 리그를 구성하고, 제어기를 여섯 가지 원인으로
> 열화시킨 조건들을 대응 설계로 비교하였다. **필터와 측정 지연으로 맞춘 관계식이, 곡선을 맞출 때
> 보지 못한 네 가지 원인과 그 조합의 결과 변화를 허용폭 안에서 예측하였다.**

### 1.3 기여 세 가지 (뼈대 §2)

| 기여 | 내용 | 근거 |
|---|---|---|
| **K1** | 교전 중 추종 오차와 결과 변화의 **정량 관계** (D = 0.144 + 0.0531·mae) | Ⅴ-B 그림 3 |
| **K2** | 그 관계의 **원인 무관성**과 **표본 밖 예측 정확도** 검증 | Ⅴ-C 표 6, 그림 4 |
| **K3** | 제어기 열화에 **민감한 전술의 식별** | Ⅴ-E 표 7 |

**K2의 동사는 결과에 맞춘다** (뼈대 지시). **검토 결과 전 원인 성공이 아니므로
"보인다"가 아니라 "조건을 밝힌다"로 쓴다.** K2의 내용도 "원인 무관성 검증"이 아니라
**"원인 의존성의 정량화"**로 바꾼다 (`FEEDBACK_FOR_CADET_v1.md` §2.1, §6).

## 3. 5인 역할 분배

### 3.1 역할 배정

| 역할 | 인원 | 담당 장 | 주요 산출물 |
|---|---|---|---|
| **집필A** (선행연구·집필) | 1명 | 초록, Ⅰ 서론, Ⅵ 논의(주도), Ⅶ 결론 | 논문의 서사. 전체 일관성 책임 |
| **집필B** (선행연구·집필) | 1명 | Ⅱ 관련 연구, 참고문헌 전체 | 문헌 원문 확인과 인용 관리 |
| **코딩1** | 1명 | Ⅲ 환경·제어기, Ⅴ-B(RQ1), Ⅴ-E(RQ4) | 그림 1, 3 / 표 1, 2, 3, 7 |

### 3.2 배정 근거

**집필 2명을 서론·관련연구·논의·결론에 둔 이유**
- 이 논문의 핵심은 **"왜 이 질문이 새로운가"**다. 선행연구를 읽은 사람이 Ⅰ·Ⅱ를 써야
  공백 서술(¶3)이 설득력을 갖는다.
- Ⅵ 논의도 문헌과 맞물린다. 다만 수치 해석이 필요하므로 **코딩2와 공동**으로 쓴다.

**코딩 3명을 환경·방법·결과에 나눈 이유**
- **코딩1**은 "무엇을 어떻게 바꿨나"(Ⅲ)와 "그래서 어떤 관계가 나왔나"(Ⅴ-B)를 연결한다.
  열화 주입 코드(`run.py:apply_knobs`)와 E2 결과를 같은 사람이 쓰면 표 1과 그림 3이 어긋나지 않는다.
- **코딩2**는 "어떻게 재고 판정하나"(Ⅳ)와 "잡음 바닥은 얼마인가"(Ⅴ-A)를 맡는다.
  δ 정의와 E1 결과는 한 사람이 써야 한다.
- **코딩3**은 "예측이 맞았나"(Ⅴ-C, Ⅴ-D)와 부록을 맡는다. **논문의 주 결과**이므로
  가장 꼼꼼한 사람이 맡는 것이 좋다.

### 3.3 공동 작업 구간

| 구간 | 참여 | 왜 |
|---|---|---|
| **용어·기호 확정** | 전원, 작성 시작 전 | 같은 양을 다르게 부르면 심사에서 바로 걸린다 (§5.1) |
| **Ⅳ-B 순환 논리 문단** | 코딩2 초안 → 전원 검토 | 가장 받을 확률이 높은 반론. 한 문단에 승부가 걸린다 |
| **Ⅵ 논의** | 집필A + 코딩2 | 수치 해석과 문헌 맥락이 둘 다 필요 |
| **한계 절** | 전원 | §6의 쟁점을 누가 어디에 쓸지 합의해야 한다 |
| **최종 수치 대조** | 전원, 제출 2일 전 | 보고서 원본과 논문 표를 한 줄씩 맞춘다 |

**초록은 반드시 마지막**이다.

## 5. 전원이 지킬 규칙

### 5.1 기호·용어 고정 (작성 시작 전 합의)

| 기호 | 뜻 | 쓰지 말 것 |
|---|---|---|
| **mae** | 교전 중 피치 추종 오차 [°/s] | "추종 오차"만 쓰면 어느 축인지 모호 |
| **D** | 결과 변화율 (승자 또는 종료 사유가 다른 비율) | "승률 변화"로 쓰면 틀림 |
| **M** | 리그 점수 변화 [점/바퀴] | |
| **κ** | 제어효과 모델 오차 G_model/G_true | λ로 쓰지 말 것 (기존 계보 혼동) |
| **k_q** | 피치 각속도 게인 배율 | |
| **f_c** | 동기화 필터 차단주파수 [Hz] | |
| **σ** | 자이로 잡음 표준편차 [°/s] | |
| **δ** | 허용폭 (δ_D = 0.079, δ_M = 5.21점) | |
| **틱** | 1/120 s ≈ 8.33 ms | ms와 틱을 섞어 쓰면 표가 어긋난다. **표에는 틱, 본문에는 ms 병기** |

### 5.2 수치 출처

모든 표와 본문 수치에 출처를 단다. 초고에서는 각주로, 투고본에서는 지운다.

| 수치 | 출처 |
|---|---|
| δ_D, δ_M | `kit/out/cal/tolerance.json` |
| 곡선 계수, LOO 비교 | `kit/out/main/report_predict_E2.md` |
| 조건별 mae·D·종료 사유 | `kit/out/main/report_E2.md`, `report_E3.md` |
| 원인별 예측 오차·판정 | `kit/out/main/report_predict_E3.md` |
| 일반화 | `kit/out/gen/report_E4.md`, `report_predict_E4.md` |
| 참가자별 점수 (RQ4) | 각 `report_E*.md` §2 |
| 순위 안정성 | 각 `report_E*.md` §3 |

### 5.3 사전 실험 수치는 결과에 쓰지 않는다

`feas`, `feas2`, `feas3` 시드 데이터는 **주제를 고른 탐색 데이터**다.
본문 Ⅴ(결과)에 넣으면 안 된다. 필요하면 Ⅳ-D(모양 선택 근거)나 한계에서만 언급한다.

### 5.4 기존 계보 자료의 사용

`docs/COMPARISON_OLD_VS_CADET.md` §5를 따른다. 요약하면,
- **Ⅲ·Ⅳ장**: 모델 수정, 제어 법칙, 등가 판정 틀, SHAM 논리 — **적극 활용**
- **Ⅵ 논의**: 상승 시간의 함정, 지연 붕괴, 상대적/절대적 구분 — **논거로만**
- **Ⅴ 결과**: 기존 수치를 **절대 섞지 않는다**. 조건이 다르다
