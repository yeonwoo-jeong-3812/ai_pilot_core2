# 논문 실험 계획 (2026-09-14 작성, 마감 2026-10-08)

논문: "F-16 AI 도그파이트 조건에서 INDI 파라미터의 기동 실현 충실도와 모델 불확실성 강건성에 미치는 영향"

- RQ1: INDI 내루프 파라미터(k_rate, filt_hz) 중 기동 실현도를 지배하는 인자와 인자 간 상호작용
- RQ2: 모델 불확실성이 커질 때 실현도가 어떻게 저하되며 그 임계 수준은 어디인가

이 문서는 **지금까지의 스윕을 탐색 연구(pilot study)로 동결**하고, 논문 표·그림에 들어갈 데이터를
처음부터 다시 뽑기 위한 설계다. 근거가 되는 실측은 전부 §0 에 적었다.

## 1. 원칙

1. **시험 대상 시스템(SUT)을 배치 코드 그 자체로 고정한다.** 실험 스크립트가 제어 루프를 다시 구현하지 않는다.
   `Pilot` 객체를 그대로 만들고, L2 출력(`GuidanceCommand`)만 합성 기동으로 바꿔 끼운다. 그러면 shim 설정,
   요축 감쇠, 리미터(교리 공유), INDI 초기화가 배치와 **코드 수준에서** 동일하다.
   지금까지의 스윕은 이 루프를 각자 복사해서 shim 이득(4.0 vs 4.5), rate_limit, 스로틀이 스크립트마다 달랐다.
2. **바꾸는 것은 연구 인자뿐.** RQ1 = k_rate(축별), filt_hz. RQ2 = 제어기가 쓰는 G0 에 주입한 오차 등.
   그 외의 변경(요축 법칙, FLCS off)은 명시적 절제 조건으로만 쓴다.
3. **측정 수정은 예외 없이 전부 적용한다.** Nz 는 `accelerations/Nz`, heading 은 unwrap, 포화는 명령과 실제 타면을 둘 다 기록.
4. **지표와 판정 기준을 데이터를 보기 전에 고정한다(§4).** 3구간 임계 1.5 는 기존 30조합에서 교정한 값이므로 민감도 분석을 같이 보고한다.
5. **모든 산출물에 출처를 박는다.** git 커밋 해시, 설정 해시, 실행 시각, 조합 수를 CSV 옆 `manifest.json` 에 쓴다. 커밋 안 된 코드로는 본실행을 막는다.
6. **결정론을 이용한다.** 반복 분산은 0 이다(`repeat_variance.csv`). 따라서 p값 기반 ANOVA 는 쓰지 않는다(오차항이 없다). 변동 분해(functional ANOVA)로 인자·상호작용의 기여 비율을 보고한다.

## 3. 실험 구조

### 3.1 공통 하네스 (`research/l3_indi/` 신설 제안)

```
harness.py      build(cond, params, uncertainty) -> Pilot (배치 코드로 조립)
                run(pilot, maneuver) -> 시계열 dict
maneuvers.py    합성 L2 명령 생성기 (GuidanceCommand 를 틱마다 공급)
uncertainty.py  G0 오차 / 지연 / 센서 잡음 주입 (전부 외부 래핑, 원본 무수정)
conditions.py   비행조건 격자 + 조건별 기체 능력표(개루프 최대 Nz)
metrics.py      사전 등록 지표 (§4)
runner.py       multiprocessing 8프로세스, 재개 가능, manifest.json
analysis/       fanova.py, dose_response.py, figures.py
tests/          하네스 검증 (§3.6)
```

주입 방식(원본 코드 무수정):

- **G0 오차**: `pilot.setup()` 후 `pilot.indi.G0 = G0_true * Λ` — 플랜트는 그대로, 제어기가 믿는 모델만 바뀐다.
- **센서 잡음**: `F16Plant` 를 감싼 프록시가 `velocities/[pqr]` 와 `accelerations/[pqr]dot` 읽기에만 잡음을 더한다.
- **입력 지연**: 프록시의 `set_input` 에 FIFO 지연.
- **L2 대체**: `pilot._gc` 를 합성 `GuidanceCommand(dphi_cmd, q_cmd, thrust_cmd)` 로 매 틱 교체하고 `control_step` 을 호출.
  `dphi_cmd = φ_target − φ`, `q_cmd = (Nz_target − cosφcosθ)·g/V` 는 `bfm_guidance.py:339, 366` 과 같은 식이다.

### 3.2 비행조건 격자와 능력표

1. 실전 궤적 수집(§3.4) 후 KCAS·고도 분포의 5~95% 범위를 확인해 격자를 확정한다. 1경기 기준 잠정안: 고도 {12k, 16k, 20k}ft × KCAS {250, 350, 450}.
2. 각 조건에서 **개루프 최대 Nz**(풀애프트 3초, FLCS on/off 각각)를 먼저 측정해 능력표를 만든다.
3. G 목표는 절대값이 아니라 **능력 대비 비율**(40/60/80/95%)로 정한다. 이렇게 하면 기존 corner_pull 의 7G/9G 처럼 도달 불가 목표 때문에 50행이 검열되는 일이 구조적으로 없어진다.

### 3.3 기동 원형 (T1)

진폭과 속도는 실전 분포(F7~F9)에서 가져온다.

| ID | 기동 | 주 관측 축 | 비고 |
|---|---|---|---|
| M1 | Nz 포착 — 수평에서 능력 대비 40/60/80/95% 당김 후 유지 | q, Nz | 기존 g_onset 의 정식판 |
| M2 | 롤 반전 — ±60° ↔ ∓60° | p | F8: 실전 손실이 큰데 기존 스윕에 없음 |
| M3 | 롤링 풀 — 뱅크 진입과 동시에 능력 대비 60/80% 당김 | p, q, r | 기존 corner_pull 의 정식판 |
| M4 | 소진폭 multisine (0.1~5Hz, 트림 주변) | p, q | 폐루프 주파수응답 → 대역폭·1Hz 위상지연. 기존 상호상관 lag 의 피크 호핑 문제를 대체 |

### 3.4 실전 궤적 재생 (T2)

1. 시나리오 5종 × 시드 10 × 진영 2, 180초 자가대전 → L3 틱마다 `omega_sp`(리미터 후), 상태, Nz, α, 명령·타면 기록.
2. 10초 구간으로 자르고, 각 구간 시작 상태를 `restore_state` 로 복원한 격리 플랜트에 **기록된 omega_sp 를 그대로** 넣어 파라미터만 바꿔 재생한다.
3. 궤적이 갈라지므로 **판정은 각속도 추종 충실도만** 쓴다(위치·기하 지표는 쓰지 않는다). 복원 직후 1초는 버린다.
4. 선행 검증: 기준 파라미터 재생이 원 경기의 각속도를 얼마나 재현하는지 먼저 확인한다. 재현 오차가 크면 T2 는 보조 자료로 격하한다.

### 3.5 RQ1 설계

| 인자 | 수준 |
|---|---|
| k_p 배율 | 0.5, 0.75, 1.0, 1.5, 2.0 |
| k_q 배율 | 0.5, 0.75, 1.0, 1.5, 2.0 |
| k_r 배율 | 0.5, 1.0, 2.0 |
| filt_hz | 10, 15, 20, 25, 35, 50 |
| 블록: 조건 × 기동(M1~M3) × 잡음 | 5 × 3 × 2 (잠정) |

= 450 파라미터 조합 × 30 블록 = 13,500 런. 12초 기동 0.22s 기준 직렬 50분, 8프로세스 약 7분.

분석:
1. **안정 영역 지도** — 3구간 분류로 k × filt 경계를 조건·기동별로 그린다. 불안정 런은 충실도 통계에서 제외하고 경계 자체를 결과로 보고한다.
2. **변동 분해** — 안정 영역의 충실도 지표 J 를 완전요인 격자 위에서 주효과 + 2원 + 3원 상호작용으로 분해하고 각 항의 분산 기여율을 보고한다. "지배 인자" = 주효과+그 인자를 포함한 상호작용의 합(총효과)이 큰 인자.
3. **부호 반전 재검증** — 기존 3G/5G 반전은 overshoot 차이가 0.04G 로, 기구학 G 오차(3G +0.05, 5G +0.21)와 같은 크기다. Nz 기준으로 다시 확인하기 전까지는 **가설**로 둔다.
4. **25Hz 절벽** — 경계 근처(k 1.4~1.8, 0.05 간격 × filt 20~35Hz 1Hz 간격)만 추가로 촘촘히 돌려 열화 구간 폭이 실제로 0인지 해상도 문제인지 확정한다.

### 3.6 RQ2 설계

주 실험 — **G0 스케일 오차 용량-반응**:

λ = G_model / G_true (축별), 로그 간격 {0.25, 0.35, 0.5, 0.7, 1, 1.4, 2, 4, 10, 25}

- λ < 1: 모델이 효과를 과소추정 → 증분 과대 → 진동·불안정 쪽. **안정 임계**를 찾는다.
- λ > 1: 과대추정 → 증분 과소 → 둔해짐. **충실도 임계**를 찾는다. 상한 25 는 F10 의 실측 불일치(10~25배)를 덮기 위함.
- 주입 축: p만 / q만 / r만 / 전 축 동시 = 4
- 교차: RQ1 에서 대표 (k, filt) 20조합, 조건 3, 기동 3
- = 10 × 4 × 20 × 9 = 7,200 런, 8프로세스 약 4분

가설(검증 대상, 사실로 쓰지 말 것): 단순 증분 모델에서는 G_true·G_model⁻¹ 이 (0, 2) 안에 있을 때 수렴하므로 안정 임계는 λ ≈ 0.5 근처일 것이다. 필터·액추에이터 지연이 있으면 이 값이 k_rate·filt_hz 에 따라 이동할 것이다. **이 이동량이 RQ1 과 RQ2 를 잇는 핵심 그림**이 된다.

임계 수준의 사전 정의:
- 안정 임계 λ_s: 3구간 분류가 처음 "불안정" 이 되는 λ (λ<1 쪽)
- 충실도 임계 λ_f: J 가 λ=1 대비 2배를 처음 넘는 λ (λ>1 쪽). 2배는 사전 등록값이며 1.5/3배 민감도를 함께 보고한다.
- 로그 격자 사이의 임계는 선형보간으로 추정하고 격자 간격을 불확도로 명시한다.

보조 실험 (시간이 허락하는 순서):
1. **구조적 불일치 분리** — 같은 설계를 FLCS on/off 에서 모두 돌린다. FLCS on 에는 α 의존 불일치(F10)가 이미 들어 있으므로, 둘의 차이가 "실제 기체에 존재하는 모델 불확실성의 효과" 추정치가 된다.
2. **비대각 항 오차** — G0 의 강한 연성(러더→롤 3.49, 에일러론→요 2.81 rad/s²)을 0으로 두거나 ±50% 왜곡.
3. **식별 절차 불확실성** — `identify_G0(settle=1,2,3,5,10)`. 실측으로 피치 대각이 −6.985 → −3.714 까지 움직인다(1.9배).
4. 입력 지연 0/10/25/50ms, 센서 잡음 수준(D3 확정 후).

### 3.7 검증 게이트 — 본실행 전에 전부 통과해야 함

| 게이트 | 통과 기준 |
|---|---|
| G1 결정론 | 동일 설정 3회 실행 시 시계열 비트 동일 |
| G2 배치 동일성 | 하네스로 조립한 Pilot 의 shim/limiter/INDI 속성이 `factory.make_pilot` 산출물과 동일 |
| G3 L2 대체 정합 | 실전 경기에서 기록한 `GuidanceCommand` 를 하네스에 재주입했을 때 원 경기와 같은 시계열 (복원 없이 처음부터 재생) |
| G4 측정 단위시험 | psi unwrap, Nz, 3구간 분류, 주파수응답 추정기가 알려진 입력에 대해 정답 |
| G5 기존 결과 재현 | 기존 `stability_filter_map` 조건을 하네스로 재실행해 경계 위치(k 1.5~1.7)가 같은 패턴인지 — **다르면 원인을 먼저 규명** |
| G6 출처 | 커밋 안 된 변경이 있으면 runner 가 실행을 거부 |

## 4. 사전 등록 지표

L3 충실도(INDI 가 직접 책임지는 것)와 기동 실현도(L2 환산까지 포함한 결과)를 분리한다(F6).

| 구분 | 지표 | 정의 |
|---|---|---|
| 1차 | 축별 추종 충실도 J_i | RMS(ω_sp,i − ω_i) / max(RMS(ω_sp,i), 2dps), 기동 창 전체 |
| 1차 | 안정 구간 | 3구간 분류(임계 1.5, 민감도 1.3/2.0 병기) |
| 2차 | Nz 실현 | 유지 창 평균 Nz / 목표, 10~90% 상승시간, Nz 오버슈트 |
| 2차 | 뱅크 실현 | 목표 도달시간, 오버슈트, 정착시간 |
| 2차 | 폐루프 대역폭·위상지연 | M4 에서 −3dB 주파수, 1Hz 위상 |
| 진단 | 포화 | 명령 포화율과 실제 타면 편각(명령≠타면), 리미터 작동률 |
| 진단 | 검열 플래그 | 목표가 능력표 초과, 기동 창 내 미정착 |
