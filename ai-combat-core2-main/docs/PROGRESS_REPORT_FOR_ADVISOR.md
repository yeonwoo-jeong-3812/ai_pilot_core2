## 1. 한 페이지 요약

**연구 질문**: F-16 FLCS 위에 얹은 INDI 각속도 내부 루프에서, 제어 파라미터(게인·필터·제어효과 모델 오차 λ)가
추종 충실도와 도그파이트 기동 실현도에 어떤 영향을 주는가.

**현재 결론**

1. 추종 오차 변동의 **89~99%** 를 해당 축의 게인 하나가 설명한다. 필터 기여는 1~3%, 게인 간 상호작용은 1% 이하다(무잡음).
2. 제어효과 모델 오차의 안정 경계는 **λ_s ≈ 0.42** 로 이산 INDI 수렴 조건(λ > 0.5)과 근접하며, **FLCS 유무와 무관**하다.
   게인을 올리면 이 경계가 0.42 → 0.59 로 좁아진다 — 추종 성능과 모델 오차 강건성이 맞교환된다.
3. 내부 루프 차이가 기동 결과로 나타나려면 **외부 유도 루프가 명령을 갱신해야 한다**. 개루프 고정 기동에서는 설정 간 M층 차이가 정확히 0 이고,
   같은 설정이 유도 폐루프에서는 뚜렷한 차이를 냈다.
4. λ 를 촘촘히 훑으면 곡선이 **두 구간**으로 갈린다. λ < 16 에서는 명령 추종을 유지하면서 조준이 개선되고(λ = 11 에서 ATA 최소 −5.5°),
   λ ≥ 16 에서는 명령·응답 상관이 0.7 아래로 떨어지고 진동 비율이 42 → 69% 로 뛴다. **경계에서 두 현상이 동시에 시작한다.**

## 2. 연구 질문의 변천

계획서 원안에서 바뀐 것을 전부 적는다. 변경은 모두 `docs/PREREGISTRATION_AMENDMENTS.md` 에 개정 번호로 등록되어 있다.

### 2.1 RQ2 범위 축소: "공력·관성 불확실성" → "제어효과 모델 오차 λ"

- **원안**: 공력계수·관성 모멘트의 불확실성이 INDI 성능에 주는 영향.
- **변경**: 제어효과 행렬 G 의 모델 오차 λ = G_model / G_true (행 단위 주입) 하나로 좁혔다.
- **사유**: 이 구현의 INDI 는 매 틱 각가속도 측정으로 증분을 만들므로, 공력·관성 오차는 **측정을 통해 이미 상쇄된다**.
  모델로 들어가는 것은 G 뿐이다(`aircombat/control/indi.py`, `identify_G0`). 따라서 원안의 인자는 이 구조에서 주입할 지점이 없다.
- **근거 실험**: RQ2 본실행 17,316 런(`results/paper/rq2/37bfd99735`) — λ 격자 10 점 × 주입 축 4 × 설정 13 × 조건 3 × 기동 6 × FLCS on/off.
- **등록**: 개정 A19.

### 2.2 교전 층위(H3)를 뺐다가 RQ3 로 되살린 경위

- **원안**: 제어 파라미터가 교전 승패에 주는 영향(H3).
- **1 차 판단(제외)**: 승패는 전술 결정·초기 기하·상대 에이전트에 지배되어 내부 루프 차이를 가리는 잡음이 크다고 보고 논문 범위에서 뺐다.
- **2 차 판단(부분 복원)**: 승패가 아니라 **기하·기동 실현 지표(M층)** 로 되살렸다. ATA 최소, T_ATA30, 기동 유형 실현 충실도.
  승패는 여전히 주 결과가 아니다.
- **사유**: "제어 파라미터가 기동 실현도에 미치는 영향" 이라는 논문 주제에 M층이 필요했고, M층은 승패보다 잡음이 작다.
- **등록**: 개정 A24(RQ3 사전등록), A25(설계 수정).

## 4. 주요 결과

결과마다 (a) 수치 (b) 뜻 (c) 한계를 함께 적는다. 상세는 각 요약 문서로 넘긴다.

### 4.1 RQ1 — 축 게인 지배 (`docs/RQ1_SUMMARY.md`, C1~C34)

**(a)** 기능적 ANOVA 총효과: M3 기동에서 J_p 는 k_p 가 **97.8%**, J_q 는 k_q 가 **89.0%** 를 설명한다(FLCS on, 12/12 블록).
필터 총효과는 **1.1~1.5%**, 게인 간 상호작용은 1% 이하다.
**(b)** 각 축의 추종 오차는 그 축의 게인이 거의 전부 정한다. 무잡음 조건에서 필터 대역은 성능 인자가 아니다.
**(c)** 기여율은 "변동 중 몇 %" 이므로 변동 자체가 작으면 99% 여도 실제 차이는 작다(`RQ1_SUMMARY.md` §3.2 단서).
필터 결론은 **무잡음 한정**이며, 잡음을 넣으면 달라진다(RQ1-N).

**롤 바닥**: 게인을 기준 → 튜닝으로 바꿔도 M2a 반전의 J_p 는 0.419 → 0.418 (**−0.2%**) 로 사실상 변하지 않는다.
같은 교체에서 피치 M1 은 0.091 → 0.079 (−13%). 원인은 §5.1.

### 4.2 RQ2 — 제어효과 모델 오차 (`docs/RQ2_SUMMARY.md`, D1~D13)

| 항목 | 값 | 뜻 |
|---|---|---|

**비대칭**: 과소추정 쪽은 1/0.42 = **2.4 배** 여유, 과대추정 쪽은 **12.3 배** 여유 → 여유 비 **약 5 배**, 안정 구간 전체 폭은 0.42~12.25 로 **약 29 배**.
**[정정]** 중간 논의에서 "약 20 배" 로 언급된 적이 있으나 그 수치의 근거를 찾지 못했다. 위 값이 실제 측정치다.

**(c) 한계**: FLCS off 는 모델 오차가 없어도(λ = 1) 41% 가 불안정하고 이탈 런이 844 개라 off 쪽 결론은 약하다.
λ_f 는 대부분 검열(롤 J_p 는 2 배 전에 불안정이 먼저 온다). λ 격자가 조건 차이(KCAS 250/350/400)를 가를 만큼 촘촘하지 않다 — 세 조건의 λ_s 가 모두 0.418 로 같게 나왔다.

**(b)** λ < 16 구간에서는 **명령 추종을 유지한 채**(상관 0.79~0.99, 진동은 기준 수준) 조준이 등가 한계 2.0° 를 넘어 개선된다.
λ ≥ 16 에서는 상관이 0.7 아래로 내려가고 진동이 급증한다. **추종 상실과 진동 급증이 같은 λ 에서 시작한다.**
메커니즘은 λ > 1 이 피치 루프의 실효 이득을 올리는 것과 같다는 것이다(명령 대비 응답 크기 1.02 → 1.47).

**(c) 한계 세 가지**
1. **유도 법칙이 기준 INDI 에 맞춰 조정된 시스템**에서의 결과다. λ 8~11 의 개선이 이 조정 때문인지 분리하지 못했다 → Q1.
2. 에너지는 **짝 비교에서 −0.0~−0.1 kt 로 사실상 0** 이다. "에너지를 대가로 조준을 산다" 는 서술은 이 과제에서 근거가 없다(§7.4).
3. WEZ 체류 시간은 전 설정 0 이다. 대표 기하의 최근접 거리(3,816~4,185 ft)가 WEZ 사거리창(500~3,000 ft) 밖이기 때문이다.
   이 실험은 **사격 기회가 아니라 기수 지향까지만** 잰다.

### 4.4 롤 축 (`docs/ROLL_LIMIT_FINDING.md`)

**(a)** 에일러론 명령이 ±1 에 포화한 시간 20~30%, FLCS 출력 포화 22~27%. 마하 보상 계수는 0.18~0.52(중앙 0.35)로
실효 편각이 전타의 **0.40**(21.5° 기준 약 8.6°)을 넘지 못한다. shim 상한을 180 → 220 °/s 로 22% 풀어도 최대 롤율은 124.1 → 125.4 °/s(**+1.0%**).
FLCS on/off 짝 비교에서 최대 롤율 124.1 vs 124.2 °/s.
**(b)** 롤 축의 병목은 제어기가 아니라 **조종면 권한**이다. 이상 응답 대비 분해에서 롤 기동 오차의 **84~88%** 가 물리 한계 몫이고
제어기 몫은 12~16% 다. 같은 계산에서 피치(M1)의 물리 몫은 31~41% 다.
**(c)** 이는 **JSBSim F-16 모델의 성질**이며 실기와의 일치는 검증하지 않았다. 확증 실험(마하 보상 평탄화 기체)은 9/27 예정.

## 5. 시스템에 대한 관찰

연구 과정에서 관측한 이 코드베이스의 성질이다. 평가가 아니라 **관측과 근거**만 적는다.
모든 항목에 **"실기와의 일치는 검증하지 않았다"** 가 붙는다.

### 5.1 롤 축이 마하 보상으로 포화되어 INDI 파라미터에 둔감하다
`fcs/aileron-speed-compensated` 는 `velocities/mach` 를 독립변수로 하는 `scheduled_gain`(마하 0 → 1.0, 마하 1 → 0.15)이며
에일러론 위치 뒤, 플래퍼론 합산 앞에 놓인다(`jsbsim_data/aircraft/f16/f16.xml:421`).
진단 구간(마하 0.56~0.97)에서 계수는 0.18~0.52 였고, 그 결과가 §4.4 다.
→ **연구상 함의**: 롤 축은 "제어 파라미터가 영향을 줄 수 없는 축" 이라는 내부 대조군을 제공한다.

### 5.2 CombinedLimiter 는 명령을 클램프하며 결과를 사후 검증하지 않는다
`limit_omega_sp` 는 `np.clip(omega_sp, lo, hi)` 로 지령을 제한하고 어떤 한계가 걸렸는지 플래그로 반환한다
(`aircombat/control/limiter.py:103-118`). 클램프 후 **실제 달성값이 한계 안에 들어왔는지 확인하는 경로는 없다.**
이는 설계 의도일 수 있다(리미터는 지령 성형이고 달성 검증은 상위 감사의 몫). 다만 연구상 함의가 있어 적는다:
우리 하네스는 리미터 통과 지령 ω_sp 를 따로 기록해 J 의 분모로 쓴다. 즉 **"명령을 얼마나 따랐는가" 의 명령은 리미터 이후 값**이다.

### 5.3 요축 법칙이 협조 선회를 하지 않는다
배치 파일럿은 `shim.rate_setpoint(...)` 결과의 `omega_sp[2]` 를 덮어쓰지 않으며, 실효 요축 법칙은 **r_sp = −1.5·r**(요 감쇠)다
(`aircombat/engine/pilot.py`, `docs/EXPERIMENT_PLAN.md` F1).
실측(14 kft / 350 KCAS, 뱅크 45°·Nz √2 선회, 창 [8,12) s): 평균 **β = 2.55°**, **Ny = −0.312 G**, γ = 4.83°.
이 때문에 우리가 준비한 M층 지표 F_i(속도벡터 회전 일치도)가 기준 1 ± 0.05 를 통과하지 못했고(F_i = 0.804),
사전등록 대체 규칙에 따라 **Nz 실현율**로 바꿨다(개정 A12-1).
좌표 변환이 JSBSim α·β 와 일치함을 확인해 계산 오류가 아님을 배제했다.

### 5.4 이 모델의 달성 가능 Nz 는 약 7 G 다
15,000 ft / 400 KCAS 3 초 풀애프트: FLCS on 에서 **Nz 6.68 / α 13.3°**, FLCS off 에서 **Nz 19.75 / α 40.8°**
(`docs/EXPERIMENT_PLAN.md` F4). 즉 7 G 천장은 기체 한계가 아니라 **FLCS 의 산물**이며, FLCS 를 끄면 리미터(9 G)가 실제로 일한다.
→ 연구상 함의: G 목표를 절대값(7G/9G)으로 주면 도달 불가로 검열이 대량 발생한다. 우리는 **능력 대비 비율**(0.7·C_nz 등)로 바꿨다.

### 5.5 기구학 하중배수 식이 급기동에서 과대평가한다
`n_act = q·V/g + cos φ·cos θ` 는 γ̇ = q − α̇ 인 정상 선회에서만 성립한다. 3 초 급당김은 α̇ 가 큰 구간이 대부분이다.
JSBSim `accelerations/Nz` 와 대조(15,000 ft / 400 KCAS):

| 목표 | 기구학 n_act 피크 | 실제 Nz 피크 | 오차 |
|---|---|---|---|
| 3 G | 2.994 | 2.949 | +0.05 |
| 7 G | 6.939 | 6.468 | +0.47 |
| **9 G** | **8.854** | **7.035** | **+1.82 (26%)** |

(`docs/FINDINGS_2026-09-14.md` §"G 계산식이 과대평가하고 있었다")
→ 우리는 모든 판정을 **`accelerations/Nz` 기준**으로 바꿨고, 이 식에 기반했던 탐색 단계 결과를 무효화했다(§7.5).

## 6. 방법론

교수님이 타당성을 판단하실 핵심이므로 상세히 적는다.

### 6.1 사전등록과 개정 이력

- **원칙**: 지표·판정 기준·등가 한계·제외 규칙을 **데이터를 보기 전에** 고정하고 커밋한다. 실행 커밋이 등록 커밋보다 뒤에 오는지 git 로그로 확인 가능하다.
- **강제 장치**: 실행 러너가 **커밋 안 된 변경이 있으면 실행을 거부**한다(`research/l3_indi/runner.py:require_clean`).
  결과 폴더 이름이 실행 커밋 해시이므로, 보고서의 숫자와 코드 상태가 일대일로 묶인다.
- **개정**: 현재 **A1~A30**. 데이터를 본 뒤의 변경은 **⚠** 로 표시하고, 무엇을 보고 무엇을 바꿨는지 적는다.
  예: A15 ⚠(꼬리 유지 추가 — 진동 검출기가 정상 구간을 가정하는데 기동이 끝나지 않아 생긴 오판을 고침),
  A25 ⚠(파일럿에서 개루프 기동의 M층 신호가 0 임을 보고 설계 변경), A28·A30 ⚠(해석 정정, §7).

### 6.2 등가성 한계 δ — 엔진 규칙과 실측 분포에서 도출

통계적 관례가 아니라 시뮬레이터 규칙에서 끌어왔다.

| 지표 | δ | 도출 |
|---|---|---|
| 시간 (T_ATA30 등) | **0.25 s** | WEZ 데미지 50 HP/s × ATA ≤ 10° 계수 0.75 → 0.25 s = **9.4 HP**. 배터리 440 경기 종료 시 체력차 중앙값 31.8 HP, 체력차가 0 이 아닌 323 경기 중 9.4 HP 이하는 13.3% — 승패를 가른 전형적 격차의 1/3 미만. 또 0.25 s = 물리 30 틱 = 전술층(20 Hz) 결정 5 회 |
| ATA 최소 | **2.0°** | 엔진의 가장 좁은 WEZ 등급 경계가 ATA 2° — 이보다 작은 차이는 사격 판정 등급을 못 바꾼다 |
| 헤딩 편차 | 1.0° | 위의 절반 |
| 위치 편차 | 50 ft | WEZ 최소 사거리 500 ft 의 10% |

모든 표에 δ/2 와 2δ 판정을 **민감도 열**로 같이 싣는다. 결론이 δ 선택에 얼마나 의존하는지 독자가 직접 본다.

### 6.3 양성 대조로 지표 민감도를 같은 실험 안에서 증명한다

일부러 크게 틀린 설정(S5, λ = 25)을 넣는다. 규칙: **S5 가 "차이 있음" 을 내지 못한 지표는 "둔감 지표" 로 표시하고,
그 지표에서 나온 다른 설정의 "차이 없음" 을 전부 "판정 불가" 로 강등한다.**
즉 "차이 없음" 이라는 결론은 그 지표가 차이를 감지할 수 있음을 증명했을 때만 허용된다(`docs/EQUIVALENCE_ARGUMENT.md`).

### 6.4 3 구간 판정

짝 차이 중앙값의 부트스트랩 95% CI 를 δ 와 비교한다.
CI ⊂ [−δ, +δ] → **차이 없음** / CI ∩ [−δ, +δ] = ∅ → **차이 있음** / 그 외 → **판정 불가**.
"유의하지 않음" 을 "차이 없음" 으로 쓰지 않기 위한 장치다.

### 6.5 결정론 시뮬레이션이므로 p 값 대신 변동 분해와 짝 비교를 쓴다

이 시뮬레이터는 완전 결정론이다(같은 입력 → 비트 동일 결과, `rq3_geom.py --selfcheck` 4 경기 확인, RQ3 재실행 6 런 × 8 지표 48/48 일치).
표본 추출 오차가 없으므로 p 값의 표준적 해석이 성립하지 않는다. 대신
- **변동 분해**(기능적 ANOVA)로 어느 인자가 변동을 설명하는지 보고,
- **짝 비교**(같은 조건·기하·적에서 설정만 다른 런)로 조건 효과를 제거하며,
- 부트스트랩 CI 는 **"조건 모집단을 다시 뽑았을 때의 불확실성"** 으로만 해석한다.
- 같은 청군 궤적을 공유하는 런은 독립이 아니므로 **클러스터 부트스트랩**으로 궤적 단위 재표집한다(개정 A26).
  이 수정은 개루프 팔에서 짝 차이 SD 가 정확히 0 으로 나온 것을 보고 발견했다.

### 6.6 가짜 짝(sham pair)으로 카오스 바닥을 잰다 — 9/26 예정

전 계층 폐루프(BT 대전)를 켜면 결정론이더라도 **설정을 조금만 바꿔도 궤적이 갈라진다.**
그래서 **물리적으로 무의미한 교란**(λ = 1 vs λ = 1 + 10⁻⁶)으로 배터리 40 경기씩 = 80 경기를 돌려
순수 수치 발산의 크기를 먼저 잰다. 승패 뒤집힘 비율·체력차 p95·WEZ 체류 차 p95 를 측정하고,
**실제 설정 효과는 이 분포를 넘어야만 효과로 인정**한다. 채택 기준은 실행 전에 고정했다(개정 A27 §6).

### 6.7 하네스가 배치 경로와 같음을 검증한다 (게이트 G2)

연구 하네스는 `factory.make_pilot` → `Pilot.setup()` 으로 배치 경로를 그대로 조립하고, 연구 인자만 주입한다.
게이트 G2 에서 **원시 배치 루프 vs 하네스 전 경로를 840 틱 × 18 열로 대조해 최대차 0.0 (비트 동일)** 을 확인했다
(`research/l3_indi/gate_reports/3e8500ef36.md`). shim·리미터·INDI 설정값 일치도 항목별로 PASS.

## 7. 분석 과정에서 정정한 해석

스스로 발견해 고친 것을 전부 적는다. 모두 개정 이력에 등록되어 있다.

### 7.1 탐색 단계의 "25 Hz 절벽" 과 "게인 부호 반전" — 재현 실패
- 탐색 단계 주장: filt 25~30 Hz 에서 열화 없이 바로 불안정해지는 "절벽" 이 있고, 3G/5G 에서 k_q 에 따른 오버슈트 기울기 부호가 반전한다.
- 본실험: 정밀 격자(k 1.40~1.80 × filt 20~35 Hz)에서 M1_0.8 은 filt ≤ 27 에서 k 1.8 까지 안정 — **절벽 재현 안 됨**.
  부호 반전은 **18 조건 중 0 개**에서 관측, 기울기 −0.03~0 G/배율 — **지지 안 됨**.
- 조치: 두 주장 철회. 옛 12 s 코너 당김에 고유한 현상으로 판단(`docs/RQ1_SUMMARY.md` C24·C25).
- **이 사례를 방법론 절에 싣는다** — 사전등록이 실제로 무엇을 걸러냈는지 보이는 예다.

### 7.2 "과응답" → "추종 상실" (개정 A28, 2026-09-21)
- 기존 기록: "λ 가 큰 설정은 명령보다 세게 반응한다(q_gain 1.40)."
- 발견 경위: 논문용 파형 그림을 실제로 열어 보니 **고정 계단 명령에서는 같은 λ 가 반대로 크게 뒤처졌다**(명령 0 일 때 −8.7 °/s).
  확인 측정: 유도 폐루프에서 λ = 25 의 명령·응답 상관이 전반 **0.33**, 후반 **0.46**(λ = 1 은 둘 다 1.00),
  후반 10 s 평균 명령 2.26 °/s 에 실제 15.71 °/s(**명령의 7 배**). 진동 판정 60% vs 24%.
- 정정: "세게 반응" 이 아니라 **증분 루프의 실효 이득이 낮아져 응답이 느려지고, 명령이 계속 바뀌는 폐루프에서는 추종을 잃는다.**
- 조치: 주장 H11 폐기·교체, H31 신설, 영향 문장 2 곳 수정.

### 7.3 "조준 이득은 전부 실패의 부산물" → λ < 16 에서는 실용 구간 (개정 A30, 같은 날)
- A28 은 λ = 25 **한 점**에서 관측한 것을 일반화했다. λ 13 점을 재 보니 **λ ≥ 16 에서만** 맞다.
- λ 8~11 에서는 상관 0.79~0.92, 진동 27%(기준 24%)로 추종을 유지하면서 ATA 최소가 −3.96 ~ −5.50° 개선된다.
- 조치: A28 의 적용 범위를 λ ≥ 16 으로 축소. 논문 서술 규칙을 구간별로 다시 씀.

### 7.4 "에너지를 대가로 조준을 산다" → 짝 비교에서 사실상 0
- 첫 보고서에서 집단 중앙값으로 "ΔKCAS +90 → +65 kt" 라고 적었다.
- 짝 비교(사전등록 방법, A24-9)로 다시 내니 **전 λ 에서 −0.0 ~ −0.1 kt**. 집단 중앙값 차이는 소수 셀에 끌린 값이었다.
- 조치: 보고서 생성기를 짝 비교로 교체. "대가" 라는 표현을 쓰지 않기로 함(A30 §4).

### 7.5 n_act 과대평가로 무효화된 포락선 위반 결과
- §5.5 의 식 오차 때문에 탐색 단계의 "9 G 포락선 위반" 계열 결과가 무효가 되었다(실제로는 이 플랜트가 9 G 를 낼 수 없다).

## 8. 교수님 판단을 구하는 항목

### Q1. λ 를 "모델 오차" 가 아니라 **설계 변수**로 해석해도 되는가

- **관측**: λ 8~11 에서 명령 추종을 유지한 채 조준이 −3.96 ~ −5.50° 개선된다(등가 한계 2.0° 초과). 에너지 대가는 짝 비교에서 0 이다.
- **우리 판단**: λ > 1 은 "제어효과를 보수적으로 추정한다" 와 수학적으로 같고, 그 효과는 피치 루프 실효 이득 상승이다.
  따라서 **"의도적 보수 추정" 이라는 설계 변수로 읽을 수 있다**고 본다.
- **부족한 것**: 이 개선이 **유도 법칙이 기준 INDI 에 맞춰 조정되어 있기 때문**일 가능성을 배제하지 못했다.
  배제하려면 유도 게인(`BFMGuidance.lead_time_s` 등)을 함께 흔드는 2×2 가 필요하다. 합성 팔 기준 180 런 ≈ 1 분이면 가능하다.
- **여쭙는 것**: 이 실험을 9/23 에 끼워 넣을 가치가 있다고 보시는지. 없다면 논문에는 "이 조합에서" 라는 단서만 달고 한계로 남기겠다.

### Q2. 롤 축을 주 결과에서 빼고 대조군으로만 쓰는 판단

- **근거**: §4.4·§5.1. 롤 오차의 84~88% 가 물리 한계 몫이고, shim 상한을 22% 풀어도 성능은 1% 안쪽으로만 변한다.
- **우리 판단**: 롤 축은 "제어 파라미터로 조절 불가능한 축" 이므로 주 결과에서 빼고 **음성 대조군**으로 쓴다.
- **여쭙는 것**: 이 판단이 타당한지, 그리고 9/27 의 확증 실험(마하 보상 평탄화 변형 기체)을 **배치 자산을 수정하지 않는 방식**
  (`jsbsim_data/aircraft/` 아래 새 모델 추가 + 런타임 모델 교체)으로 하려는데 더 나은 접근이 있으신지.
  (프로퍼티 덮어쓰기는 `scheduled_gain` 이 매 스텝 재계산하므로 불가능함을 확인했다.)

### Q3. 교전 승패(E층) 제외 판단

- **근거**: 승패는 전술 결정·초기 기하·상대에 지배된다고 보았다. 다만 이는 **아직 정량 측정으로 뒷받침되지 않았다** — [미확정].
- **계획**: 9/26 가짜 짝 측정(§6.6)으로 승패의 카오스 바닥을 잰다. 뒤집힘 비율이 10% 를 넘으면 승패를 주 지표에서 제외하고,
  그 사실 자체를 결과로 보고한다("이 시뮬레이터에서 승패는 내부 루프 차이를 재는 도구로 쓸 수 없다").
- **여쭙는 것**: 이 접근으로 충분한지, 아니면 승패를 아예 다루지 않는 편이 나은지.

### Q4. 추종 상실 기준 r < 0.7 을 양 끝점을 본 뒤 정한 것

- **사실**: 기준을 정할 때 λ = 1(r = 1.00)과 λ = 25(r = 0.33/0.46)는 이미 본 상태였다. 중간 λ 들은 보지 않았고, 알고 싶은 양은 그 경계였다.
- **기준의 근거**: r² 는 명령이 응답 분산을 설명하는 비율이다. r = 0.7 → r² = 0.49 로 **명령이 응답의 절반도 설명하지 못하는 지점**이며 자의적 수치가 아니다.
  민감도 r = 0.5 / 0.9 를 같이 보고하며, 경계 λ 는 22 / 16 / 11 로 이동한다.
- **우리 판단**: 개정 A29 에 "양 끝점을 본 상태에서 정한 사전 기준" 으로 명시했고 논문에도 같은 문구를 쓸 계획이다.
- **여쭙는 것**: 이 표기로 충분한지, 아니면 경계를 **결과로만 제시**하고(예: 상관 곡선을 그대로 보여주고) 임계값 자체를 정의하지 않는 편이 나은지.

### Q5. 이 모델의 7 G 제약을 어느 수위로 다룰지

- **사실**: 15,000 ft / 400 KCAS 에서 FLCS on Nz 6.68, off 19.75 (§5.4). 7 G 천장은 FLCS 의 산물이다.
- **현재 처리**: 기동 목표를 절대 G 가 아니라 능력 대비 비율로 정의해 검열을 구조적으로 없앴다. 결과 해석에는 반영하지 않았다.
- **여쭙는 것**: 논문 방법 절에 사실로 기재하는 수준이면 충분한지, 아니면 결과의 일반화 가능성을 제한하는 요인으로 **한계 절에서 따로** 다뤄야 하는지.

## 10. 부록

### 10.1 우리가 새로 정의한 지표

| 지표 | 정의 | 왜 필요했나 |
|---|---|---|
| **J** (추종 오차) | RMS(ω_sp − ω) / max(RMS(ω_sp), 2 deg/s) | 명령 크기로 정규화. 분모 하한 2 deg/s 는 명령이 거의 0 인 구간에서 값이 발산하는 것을 막는다 |
| **λ** | G_model / G_true (행 단위 주입) | 제어효과 모델 오차의 단일 스칼라 표현 |
| **λ_s / λ_f / λ_M** | 안정 경계 / J 가 2 배 되는 λ / Nz 실현율이 10% 떨어지는 λ | 제어 경계와 기동 경계의 간격을 정량화 |
| **ε** | Σ\|Δω̇ − G·Δu\| / Σ\|Δω̇\| | INDI 시간척도 분리 가정의 위반 정도 |
| **ATA 최소 / 평균 지향오차** | 창 안 최소·평균 ATA | 첫 도달 시간은 시작 기하가 이미 조건을 만족하면 0 이 되어 판별력이 없다 |
| **명령·응답 상관 r** | 창 안 q_sp 와 q 의 피어슨 상관 (전반 [1,15) s / 후반 [15,25] s) | "못 따라감" 과 "명령을 놓침" 을 구분하기 위해 신설(개정 A29) |
| **물리 한계 몫** | J_ideal / J_actual. 이상 응답 = 같은 명령을 그 조건의 개루프 최대 각가속도로만 제한해 따라간 응답 | 제어기가 손댈 수 있는 몫과 없는 몫을 분리 |
| **flow 전환 지연** | 명령 전환 시각부터 실현 flow 가 의도 flow 와 0.5 s 연속 같아질 때까지 | 배치 코드의 `one_circle`/`two_circle` 판정 함수를 그대로 사용 |
