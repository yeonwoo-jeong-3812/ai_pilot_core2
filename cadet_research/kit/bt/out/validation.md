재현 확인: r0 의 기준 θ 48경기 중 **48경기**가 bt-cal 기준 θ 와 모든 열이 같다 (stage·wall_s·host·새 열 제외).

(a) 의도 노드 Δnode_frac 95% CI 하한 > 0.3. (b) 승률·wez 차 모두 Δ < 0, CI 상한 < 0, |Δ| > 잡음 범위.

기준 θ 의 노드 비율 (r0, 48경기 평균): break_defense 0.085, energy_recover 0.111, gun_track 0.011, press_offense 0.038, pure_default 0.281, recover_altitude 0.172, yoyo_dive_cut 0.152, yoyo_pull_up 0.149

- **R0-1 은 작동 원리상 나빠야 했지만 상대 실속 유도로 나빠지지 않은 사례다.** 의도 노드(recover_altitude)는 거의 항상 실행됐으나 (a 통과), 청 승리 10경기 중 7경기가 상대 실속이었고 wez 차는 오히려 기준보다 컸다 (b 불통과). 판정 기준은 바꾸지 않았고, 결과는 지우지 않고 남긴다. 판정은 R0-2 와 원리가 다른 R0-3 으로 대신했다.
- R0-3 노드 확인 (bt-smoke-0 6경기, node_frac 만 봄): break_defense 기준 0.080 → R0-3 0.822 (첫 값으로 확인, 수정 없음).

- 변경 전 규칙 (R0-2, R0-3 모두 (a)(b) 통과): **불통과**
- **변경 후 규칙: 민감도 O (R0-2 (fight_kcas=1000)), 특이도 O (미세 θ 두 지표 모두 잡음 범위 안) → 통과**

### 판정 규칙 변경 기록

- **언제:** R0-1, R0-2, R0-3 의 bt-cal 결과를 **본 뒤에** 바꿨다. 사전등록 규칙이 아니다.
- **변경 전:** 모든 R0 후보 (R0-1 을 사례로 돌린 뒤에는 R0-2, R0-3) 가 (a) 와 (b) 를 통과.
- **변경 후:** R0 는 측정 도구 점검이다. 두 가지가 성립하면 통과로 본다.
  - 민감도: 노드로 작동이 확인된 악화 설정 중 하나 이상이 두 지표 모두에서 (b) 를 통과 (R0-2).
  - 특이도: 미세 변경 θ 가 두 지표 모두 잡음 범위 안 (미세 θ).
- **이유:** R0-1, R0-3 은 노드가 의도대로 작동했으므로 (a 통과) 지표 실패가 아니라 "예상한 악화가 실제로는 작거나 상대 약점으로 상쇄된 사례" 다. 후보를 더 바꾸거나 시드를 늘리면 통과할 때까지 시도하는 것이 되므로 하지 않는다.
- R0-1, R0-3 결과는 위 표에 그대로 둔다.

## 6. 검정력 계산 (bt-cal 짝 차이, 계산만)

n = ((z₀.₉₇₅ + z₀.₈) · sd / Δ)² = (2.802 · sd / Δ)², 정규 근사, 짝 차이 (같은 셀끼리) 기준. sd 는 θ − 기준 짝 차이의 표준편차 (θ 당 48쌍).

| θ | sd(Δ승률) | sd(Δwez 차) [s] |
|---|---|---|
| R0-1 (floor_ft=40000) | 0.595 | 3.46 |
| R0-2 (fight_kcas=1000) | 0.476 | 1.78 |
| R0-3 (threat_aspect_deg=-1, merge_range_ft=200000) | 0.704 | 2.41 |
| A | 0.565 | 1.63 |
| B | 0.325 | 0.95 |
| 미세 | 0.289 | 1.17 |
| **합동 (RMS)** | **0.514** | **2.08** |
| 최대 | 0.704 | 3.46 |

| 잡을 차이 Δ | 필요 경기 수 / θ (합동 sd) | 48경기 묶음 | 필요 경기 수 / θ (최대 sd) | 48경기 묶음 |
|---|---|---|---|---|
| 승률 0.1 | 208 | 4.3 | 390 | 8.1 |
| 승률 0.15 | 93 | 1.9 | 174 | 3.6 |
| wez 차 0.3 s | 377 | 7.9 | 1047 | 21.8 |
| wez 차 0.5 s | 136 | 2.8 | 377 | 7.9 |

짝 차이 sd 는 θ 마다 다르다 (차이가 큰 θ 일수록 큼). 합동 sd 는 평균적인 θ, 최대 sd 는 보수적인 값이다. 경기 수는 같은 셀끼리 짝지은 비교를 가정한다.
