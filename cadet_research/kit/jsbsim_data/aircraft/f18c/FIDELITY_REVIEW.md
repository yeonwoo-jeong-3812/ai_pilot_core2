# F/A-18 제어기와 충실도 검토

2026-09-27. 코드와 공개 문헌에 근거한 검토다. 새 제어기 구현이나 성능 보정 실험은 실행하지 않았다.

## 현재 구현

`f18c.xml`은 정규화 입력을 조종면 각도로 환산하는 직결 모델이다. 피치 트림 합산과 입력 제한만 있고, PID·INDI·실기 FLCS는 없다. 구동기 지연과 속도 제한도 없다. 시각화의 조종면 리깅은 비행 제어기와 별개다.

공력 계수, 관성, 추력의 고도 변화 등은 교육용 가정이다. 수평 트림과 10초 적분 검사는 수치 동작 검사이며 실기 충실도 검증이 아니다. 현 모델은 학생용 실기 성능 비교에 사용하기에 부족하다. 외부 무장 8개는 표시만 복원했고 질량·항력에는 반영하지 않았다.

기존 F-16 제품 경로는 `aircombat/engine/pilot.py`의 피치·롤 2축 INDI와 XML 내장 요 제어를 사용한다. `aircombat/aircraft.py`는 F-16 두 변형만 허용한다. F/A-18은 이 제어 경로에 연결되지 않았다.

## 공개 문헌으로 확보할 수 있는 기반

Buttrill, Arbuckle, Hoffler의 [NASA TM-107601, Simulation Model of a Twin-Tail, High Performance Airplane (1992)](https://ntrs.nasa.gov/citations/19920024293)은 F/A-18의 비선형 6자유도 모델을 기술한다. 풍동 기반 공력표, 엔진 모델, 위치·속도 제한이 있는 구동기, 간략화한 디지털 제어법칙 version 8.3.3의 공중 비행 내부 루프를 포함한다. 현재의 임의 선형 계수보다 근거가 있는 모델을 구성할 후보 문헌이다. 다만 표·프로그램의 확보 범위와 대상 기체 구성을 원문에서 확인해야 하며, 양산 F/A-18C 전체 재현으로 취급하지 않는다.

Messina 등의 [NASA TM-110216 (1996)](https://ntrs.nasa.gov/api/citations/19960027892/downloads/19960027892.pdf)은 위 기본 모델을 HARV로 확장한 문헌이다. HARV는 추력편향과 전방 스트레이크 등을 갖춘 연구 기체다. 공력·엔진·제어 구성의 차이를 구분하지 않고 C형에 옮겨서는 안 된다.

[Determination of the Stability and Control Derivatives of the NASA F/A-18 HARV Using Flight Data](https://ntrs.nasa.gov/citations/19940020331)는 동특성 비교 자료의 후보로 검토한다. HARV 결과라는 범위를 유지해야 한다. 이번 검토에서 엔진·중량·장착물이 일치하는 양산 C형 EM 기준 데이터는 확보하지 못했다.

## 권장 접근

먼저 공개 문헌의 기체 구성과 비교 가능한 비행영역을 정한다. C형 자료가 충분하지 않다면 모델 이름도 F/A-18 계열 공개 연구모델로 구분한다. C형 외형을 쓴다는 이유로 물리 모델까지 C형이라고 주장하지 않는다.

공력·추진 모델과 기본 안정화 제어를 분리해 검증한다. 공개 문헌의 간략화 제어법칙을 기준선 후보로 삼고, 학생 알고리즘용 공통 제어기가 필요하면 이를 별도 실험 구성으로 둔다. INDI의 재사용 가능성과 실기 FLCS의 재현 여부는 서로 다른 문제다.

| 검증 층 | 확인할 항목 | 현재 상태 |
|---|---|---|
| 기체 구성 | 변형, 엔진, 총중량, 연료, 무게중심, 장착물, 대기 조건 | 일부 제원만 출처 있음 |
| 정상 성능 | 트림 받음각, 수평 가감속, 상승률, 추력·항력 | 트림 수치 검사만 수행 |
| EM | 지속·순간 선회, 비잉여동력과 속도 감소 | 실기 대조 미실행 |
| 동특성 | 입력 응답, 감쇠, 축간 결합, 구동기 제한 | 입력 반응 부호만 확인 |
| 폐루프 | 명령 추종, 포화, 제한기 개입, 영역 밖 처리 | F/A-18용 미구현 |

EM 비교에서는 고도·중량·엔진 설정·장착물·대기를 맞춘다. 속도 축의 TAS/CAS/Mach와 가감속 단위를 명시하고, 지속 선회와 에너지 감소를 허용한 순간 선회를 구분한다. 성능 자료를 중량·대기 조건에 맞춰 정규화하는 공개 사례는 [NASA의 F-111 성능 평가, Appendix B](https://ntrs.nasa.gov/api/citations/19790004885/downloads/19790004885.pdf)에 있다. 이는 검증 방법의 참고이며 F/A-18 목표값은 아니다.

EM 곡선만으로 공력·추력·제어기 각각이 맞다고 판단하지 않는다. 서로 다른 추력·항력 오차가 상쇄될 수 있고, 정상 성능이 같아도 과도응답은 다를 수 있다. 정상 성능과 동특성을 함께 비교해야 한다.

보정에 쓰는 조건과 검증에 남겨 두는 조건을 분리한다. 허용 오차는 원문 해상도·측정 불확실성·교육 목적을 보고 사전에 정한다. 현 단계에서 근거 없이 일괄 5%나 10%를 실기 충실도 합격선으로 선언하지 않는다. 자료가 없는 영역은 검증 범위에서 제외한다.

## 기존 도구의 재사용 범위

`scripts/fit_em_fidelity.py`와 `scripts/plot_em_fidelity.py`는 F-16 전용 경로·중량·면적·참조표를 포함한다. 실행 이름만 F/A-18로 바꿔 사용하지 않는다. `docs/fidelity-analysis/README.md`는 기존 F-16 보정에도 단위 해석과 독립 검증의 한계가 있음을 기록한다. 그 결과를 F/A-18의 합격 근거로 사용할 수 없다.

Graphify 관계 조회와 기존 Archify 제어 구조도를 실제 코드와 대조해 F-16 제어 경로를 확인했다. 이번 검토의 다음 산출물은 C형 또는 공개 연구모델의 대상 구성을 명시한 출처·조건·검증량 목록이다. 모델 교체와 제어기 선정은 그 자료 범위에 맞춰 결정한다.
