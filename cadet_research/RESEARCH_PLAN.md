## 1. 한 문단 요약

전투기 제어기는 여러 이유로 나빠진다. 센서가 늦게 반응할 수도 있고, 제어기가 믿는 기체 모델이 틀릴 수도 있으며, 게인이 잘못 잡힐 수도 있다. 지금은 제어기를 바꿀 때마다 공중전을 수천 번 돌려 봐야 승패가 얼마나 달라지는지 안다. 이 연구는 더 싼 방법이 있는지 묻는다. 교전 중에 "명령한 피치 회전과 실제 피치 회전의 차이"(피치 추종 오차) 하나만 재면, 원인이 무엇이든 승패가 얼마나 달라질지 예측할 수 있는가.

---

## 2. 쉬운 설명

자동차에 비유하면 이렇다. 운전대를 늦게 따라오는 원인은 여러 가지다(바퀴 정렬, 헐거운 운전대, 느린 센서). 원인이 무엇이든 "운전대를 돌린 만큼 차가 얼마나 빗나가는가"만 재서 레이스 성적이 얼마나 나빠질지 맞힐 수 있는지 묻는 것과 같다.

| 비유 | 이 연구 |
|---|---|
| 운전대 | 피치 각속도 명령 (상위 유도 계층이 INDI에 주는 값) |
| 빗나간 정도 | 피치 추종 오차 [°/s] = 명령과 실제 피치 각속도 차이의 절댓값 평균 |
| 레이스 성적 변화 | 결과 변화율 D = 같은 조건의 기준 경기와 승자나 종료 사유가 달라진 경기의 비율 |
| 나빠지는 원인 | 필터 대역, 측정 지연(비동기·동기), 제어효과 모델 오차 κ, 피치 게인 k_q, 자이로 잡음 |

## 3. 연구 질문과 가설

| 번호 | 질문 | 가설 | 답하는 실험 |
|---|---|---|---|
| RQ1 | 추종 오차가 커질수록 교전 결과 변화가 커지는가. 그 관계는 어떤 모양인가 | 결과 변화율 D는 추종 오차에 대해 단조 증가하며, 필터·지연 범위에서는 직선 D = a + b·mae로 근사된다 | E2 |
| RQ2 | 열화 원인이 달라도 같은 추종 오차면 같은 결과 변화가 나오는가 | E2 곡선으로 E3(다른 원인과 그 조합)를 예측하면, 원인별 평균 예측 오차가 허용폭 δ 안에 든다 | E3 |
| RQ3 | 그 관계가 다른 전술 집합에서도 유지되는가 | E2 곡선이 다른 참가자 12종의 결과 변화도 허용폭 안에서 예측한다 | E4 |
| RQ4 (보조) | 같은 추종 오차에서 어떤 전술이 더 손해 보는가 | 정밀 조준 전술이 단순 추적 전술보다 점수를 더 잃는다 | E2, E3 참가자별 Δ점수 |

가설은 실험 전에 고정한다. 곡선(E2)은 검증(E3)을 보기 전에 등록하고, 분석기도 그 순서로만 돈다.

## 4. 의의

공학적 의의. 제어기를 바꿀 때 교전 대량 실험 대신 대표 교전 몇 번의 추종 오차로 승패 영향을 미리 가늠할 근거가 생긴다. 반대로 원인에 따라 예측이 빗나간다면, 추종 오차만으로 제어기를 평가하면 안 된다는 경고가 된다. 어느 쪽이든 제어기 검증 절차에 쓸 수 있는 결과다.

과학적 의의. 하위 제어 루프의 품질과 상위 임무 성과 사이의 관계를 원인을 바꿔 가며 통제 실험으로 잰다. 대리 지표(surrogate)의 타당성을 원인 무관성과 표본 밖 예측 두 가지로 검증하는 설계다.

새로움. INDI의 지연 여유와 동기화 필터의 관계는 이미 연구되어 있다(근거 대기 목록 §9). 이 연구의 새로움은 제어 품질을 공중전 결과와 통제 비교로 직접 잇는 데 있다. 모의 심사(`FEASIBILITY.md` §4)에서 같은 시도를 한 선행연구는 찾지 못했다. 투고 전에 Scopus 등으로 다시 확인해야 한다.

## 5. 설계

### 5.1 시뮬레이션

JSBSim 1.3.1 F-16 6자유도 모델(flaperon 혼합 부호 수정)과 5계층 조종 구조를 쓴다. 전술 행동트리(20 Hz) → 기본전투기동 유도(60 Hz) → 자세 shim과 G·받음각 리미터 → 롤·피치 2축 INDI 각속도 제어기(120 Hz, 게인 9, 2차 Butterworth 동기화 필터 25 Hz) → 승강타·에일러론 명령 클립과 구동기 속도 제한 → JSBSim. F-16 모델(`f16.xml`)에 내장된 FLCS의 피치·롤 제어 법칙은 `fcs/fbw-override=1`로 우회하고(INDI와 레이트 루프가 겹치지 않게), 받음각 보호는 G·받음각 리미터가 대신한다. 요 축만 내장 FLCS(요 댐퍼)가 맡는다(`kit/aircombat/fdm/plant.py`의 `trim()`). 300초 1:1 기총 교전이고 모든 난수는 시드로 고정된다. 엔진은 `kit/`의 스냅샷이며 해시는 `kit/ENGINE_VERSION.txt`에 있다.

### 5.2 변수

| 구분 | 변수 | 값 |
|---|---|---|
| 조작 (원인 × 강도) | 필터 f_c × 비동기 지연 | f_c 25, 12, 5 Hz × 지연 0, 0.5, 1, 2, 3, 4, 6틱 (1틱 = 1/120 s) |
| | 제어효과 모델 오차 κ | 2, 4, 8, 16, 25, 50 |
| | 피치 게인 배율 k_q | 0.25, 0.5, 1.5, 2 |
| | 자이로 잡음 σ | 0.3, 1, 3, 6 °/s |
| | 동기 지연 | 2, 4, 8, 16틱 |
| | 조합 | κ8+비동기 1틱, σ1+k_q 0.5, κ4+동기 4틱, f_c 12 Hz+σ3 |
| 예측 변수 | 피치 추종 오차 mae [°/s] | 교전 중 측정, 양 기체 평균 |
| 결과 변수 | D (주) | 기준 경기와 승자 또는 종료 사유가 다른 경기의 비율 |
| | M (보조) | 참가자별 리그 점수 변화 절댓값의 평균 [점/리그 한 바퀴] |
| 고정 | 엔진, 참가자, 시나리오(headon, perch_offense, neutral), 시드, 리그 규칙(승 3·무 1·무접촉 0) | |

모든 조건은 모든 기체에 같이 건다(대칭). 같은 시드에서 기준 조건(BASE)과 짝을 지어 비교한다.

### 5.3 데이터 분리와 판정

| 시드 | 실험 | 쓰임 |
|---|---|---|
| `feas*` | 사전 실험 | 주제와 가설을 정한 탐색 데이터. 판정에 쓰지 않는다 |
| `cal-*` 8개 | E1 | 허용폭 δ를 정하는 데만 쓴다 |
| `main-*` 8개 | E2, E3 | E2로 곡선을 맞추고, E3로 예측을 검증한다 |
| `gen-*` 4개 | E4 | 일반화 |
| `smoke-*` | 실행 점검 | 결과로 쓰지 않는다 |

허용폭 δ_D = max(2 × 가짜 변형(κ = 1 + 10⁻⁶)의 시드별 D 95 백분위수, 0.05)이다. 0.05는 경기 20판 중 1판에 해당하는 실용 바닥이다. M도 같은 방식이며 실용 바닥은 3점(1승)이다.

독립 단위는 시드(리그 한 바퀴)다. 신뢰구간은 시드 부트스트랩(2,000회)으로 구하고, 표본마다 곡선을 다시 맞춰 예측한다. 원인별 평균 예측 오차의 95 % CI가 [−δ, +δ] 안이면 예측 성공, δ를 완전히 벗어나면 예측 실패, 그 밖은 판정 불가로 본다.

## 6. 실험

| 실험 | 목적 | 규모 | 보여야 할 것 | 실패하면 |
|---|---|---|---|---|
| E0 자가점검 | 장치 확인 | 13경기, 1분 | 결정론, 설정마다 추종 변화, SHAM 무변화 | 다른 실험을 하지 않는다 |
| 벤치 | 교전 없이 제어기 단독 특성 기록 | 594회, 1분 | 필터별 지연 여유 (Ⅲ장 제어기 특성 설명용) | 결과에 쓰지 않는다 |
| E1 보정 | 잡음 바닥과 δ | 2,688경기 | SHAM의 D, M 분포, δ 등록 | δ가 실용 바닥보다 크면 그대로 쓰고 보고 |
| E2 적합 | RQ1 | 28,224경기 | 추종 오차 대 D 곡선, 모양, 잔차 | 단조 관계가 없으면 RQ2·RQ3를 하지 않고 그 결과를 보고 |
| E3 검증 | RQ2 | 약 29,600경기 (BASE는 E2와 공유) | 원인별 예측 오차와 판정 | 예측 실패한 원인이 있으면 그 원인이 추종 오차 외의 경로로 결과를 바꾼다는 결과로 보고 |
| E4 일반화 | RQ3 | 11,088경기 | 다른 참가자에서의 예측 오차 | 결론의 범위를 E2 참가자로 한정 |

전체 약 7만 2천 경기, 20 프로세스로 6–8시간이다. 시간이 부족하면 E2·E3의 시드를 8개에서 6개로 줄인다(`--salts 6`).

## 7. 결과별 해석

| 결과 | 의미 | 논문의 결론 |
|---|---|---|
| RQ1 성립, RQ2 전 원인 예측 성공 | 추종 오차는 원인과 무관한 대리 지표다 | 제어기 변경의 교전 영향을 추종 오차로 미리 평가할 수 있다 |
| RQ2 일부 원인만 실패 | 그 원인은 추종 오차에 안 잡히는 경로로 결과를 바꾼다 | 추종 오차는 조건부 대리 지표다. 실패한 원인을 명시한다 |
| RQ2 대부분 실패 | 추종 오차는 대리 지표가 아니다 | 추종 오차만으로 제어기를 평가하면 안 된다 |
| RQ3 실패 | 관계가 전술 집합에 의존한다 | 범위를 E2 참가자로 한정한다 |

## 8. 한계와 위험

| 항목 | 영향 | 대응 |
|---|---|---|
| D는 개별 경기의 혼돈 증폭 때문에 약 0.6에서 포화된다 | 큰 열화끼리 구별이 약하다 | 보조 지표 M을 함께 보고, 포화 구간을 명시 |
| 추종 오차가 작은 구간(0.2–0.8 °/s)에서 D가 가파르게 오른다 | 직선 모델이 낮은 구간에서 덜 맞는다 | E2에서 직선과 다른 모양을 비교하고, 모양을 정한 뒤 E3에 적용 |
| 일부 원인(κ, 잡음, 동기 지연)은 추종 오차를 크게 만들지 못한다 | 높은 추종 오차 구간의 원인 무관성 검증이 약하다 | E3 수준을 넓혔다(κ 50, σ 6, 동기 16틱). 그래도 부족하면 한계로 적는다 |
| 상대가 행동트리 전술뿐이다 | 학습 정책으로 일반화할 수 없다 | 결론을 이 전술 집합으로 한정. 확장본에서 RL 정책 추가 |
| 시뮬레이션만이다. 피치·롤은 내장 FLCS 제어 법칙을 우회하고 명령 클립·구동기 속도 제한만 거치며, 요 축은 내장 FLCS가 맡는다 (2026-10-19 바로잡음: 이전 판은 "INDI 출력이 내장 FLCS를 거친다"고 잘못 적었다) | 실기 일반화 불가 | 한계로 명시 |
| 교전 중 추종 오차는 상대 전술에도 의존한다 | 예측 변수가 결과와 같은 교전에서 나온다 | 예측 변수는 기준 조건이 아니라 해당 조건 교전에서 잰다는 점을 방법에 명시. 결과 변화 D와는 정의가 다르다 |
