**규칙 네 가지**
1. 논문의 숫자는 **반드시 파일에서** 가져온다(§6의 "파일" 열, §12). 기억이나 이 문서에서 옮겨 적지 않는다. 이 문서의 숫자도 파일과 대조해 고친 것이지만, 논문에 넣을 때는 파일을 다시 연다.
2. 사전 등록 결과와 사후 분석을 **문장마다 구분**한다(§7.3).
3. §8.2의 "쓰면 안 되는 표현"을 쓰지 않는다.
4. 다른 PC에서 **경기를 다시 돌리지 않는다**(§9.2). 보조 스크립트는 **플래그 없이 또는 `--smoke`로 실행하면 경기를 돈다.** 분석은 복사본 폴더에서 `--report`로만 돌리고, 등록 파일을 다시 쓰는 명령(§9.2)은 돌리지 않는다.

## 1. 한 장 요약

**제목**: 같은 추종 오차, 다른 교전 결과: 비행제어 열화의 오차 유형과 공중전 결과 변화 — INDI 제어 F-16 시뮬레이션의 사전 등록 검증

**한 문장 결론**: 같은 크기의 추종 오차라도, 명령을 늦게 따라가는 제어기(둔한 형)가 빠르게 떠는 제어기(진동형)보다 공중전 결과를 더 크게 바꾼다.

**실험 상태**: **모두 끝났다**(마지막 실행 2026-10-23 04:54 종료). 더 돌릴 실험은 없다. 기록된 경기 합계 약 14만(본실험 71,568 + 추가 실험). 남은 계산은 없다(그림 5와 부록 C의 시드 t 재계산은 10/24 완료). 부록 C는 표 작성만 남았다(§9.5, §10.2).

| 연구 질문 (RQ) | 답 | 근거 실험 |
|---|---|---|
| RQ1. 교전 중 추종 오차로 결과 변화의 **크기**를 예측할 수 있나 | 한 제어기 구성 안에서는 된다. 처음 보는 원인 22조건에서, 추종 오차를 안 쓰는 상수 예측보다 오차가 **44 %** 작았다(기술 점수 0.44, **사후 분석**) | E2·E3, P0 |
| RQ2. 예측은 어디서, 왜 틀리나 | 오차 **유형**이 다를 때. 같은 크기에서 둔한 오차가 진동형 오차보다 결과를 더 바꾼다. 세 원인(κ, 명령 전달 지연, 낮은 k_q)에서 사전 등록으로 확인 | E3X, P3, P4, P7, P8 |
| RQ3. 제어기 구성(센서·구동기)이 바뀌면 | 비례 상수(기울기)가 0.053 → 0.022로 바뀐다. 그래도 오차 유형 효과는 남는다 | P7 |
| RQ4. 결과의 **방향**(좋아짐/나빠짐)도 아나 | 원래 구성에서는 모른다(한 기체만 열화하면 점수가 U자). U자는 원래 제어기의 자체 진동과 함께 나타났고(진동 기체의 공세 비율 15배), 자체 진동이 없는 실제형 구성에서는 열화가 클수록 점수가 조금씩 준다. "진동이 위치 관계를 바꿨다"는 해석이다(직접 시험 P9-b는 판정 불가) | ASYM, P2, P4, P9 |

## 3. 예전 실험과 지금 실험을 논문에 어떻게 쓰나

### 3.1 원칙

- 논문의 **결과(Ⅴ장)에는 본실험과 사전 등록한 추가 실험만** 쓴다.
- 예전 실험(선행 실험, 주제 1·2, 사전 실험)은 **방법·환경의 근거와 논의의 논거**로만 쓴다. 그 수치를 우리 결과표와 섞지 않는다(상대·시나리오·지표가 다르다).
- 선행 실험은 **발표되지 않은 팀 내부 연구**다. 그래서 [문헌]처럼 인용할 수 없고, 인용 방식은 연구 책임자가 학회 규정을 보고 정한다(§10.1 결정 2). 기본안: 본문에 "본 연구진의 선행 실험(미발표)"으로 쓰고, 각주에 저장소 브랜치 이름을 적는다.
- 선행 실험과 이번 연구의 대응 관계를 정리한 문서는 **팀 저장소의 다른 브랜치**에 있다: 브랜치 `research/l3-indi-paper-v2`, 파일 `ai-combat-core2-main/docs/COMPARISON_OLD_VS_CADET.md`(커밋 c82deb4, 2026-10-19). 이 폴더에는 없다. 이 문서의 §5(반영 규칙)는 지금도 유효하지만, 그 뒤의 P0–P9로 바뀐 서술은 이 문서 §8이 우선한다.

## 4. 시뮬레이션은 어떻게 생겼나

### 4.1 5계층 구조 (위에서 아래로 명령이 내려간다)

| 계층 | 주기 | 하는 일 |
|---|---|---|
| 전술(행동트리, BT) | 20 Hz | "추격하라", "회피하라", "사격하라" 같은 행동을 고른다 |
| 기본 전투 기동(BFM) 유도 | 60 Hz | 행동을 "기수를 이만큼 돌려라"(각속도 명령)로 바꾼다 |
| G·받음각 리미터 | — | 명령이 기체 한계를 넘지 않게 자른다: 하중 **+9 G / −3 G**, 받음각 15°까지 9 G 허용 → 25°에서 1 G로 줄임, 롤율 220 °/s, 요율 30 °/s (`kit/aircombat/control/limiter.py`) |
| **INDI 각속도 제어기** | 120 Hz | 각속도 명령을 따라가도록 조종면(승강타·에일러론)을 움직인다. **열화는 여기에만 넣는다** |
| JSBSim F-16 | 120 Hz | 비행 물리(엔진 F100-PW-220) |

- 피치·롤만 INDI가 맡는다. F-16 모델 안의 원래 비행제어 법칙(FLCS)은 피치·롤에서 우회했다(`fcs/fbw-override = 1`; 겹치면 달성 G가 4.5–7.2 G에 묶였다). 요 축만 FLCS가 맡는다.
- 유도와 리미터 사이에 자세→각속도 변환층(shim)이 있다. 유도가 정한 **롤** 목표를 쿼터니언으로 롤·요 각속도 명령으로 바꾼다. **피치 명령은 shim을 거치지 않고** 유도의 q_cmd를 그대로 쓴다(`kit/aircombat/engine/pilot.py` 186–196행, `kit/aircombat/control/attitude.py`). 그다음 리미터가 세 축 명령을 자르고 INDI에 넘긴다. 열화와는 무관하다.

### 4.2 INDI 제어 법칙 (증분 비선형 동적 역변환)

| 식 | 쉬운 뜻 |
|---|---|
| ν = K(ω_cmd − ω_f) | 명령 각속도와 실제(필터 거친) 각속도의 차이에 비례해 "이만큼 가속하자"를 정한다 |
| Δu = G⁻¹(ν − ω̇_f) | 원하는 가속과 지금 가속의 차이를 조종면 효과 G로 나눠, 조종면을 얼마나 **더** 움직일지 정한다 |
| u = u_f + Δu | 지금 조종면 위치에 증분을 더한다(그래서 "증분") |

- 기준값: K = 9 s⁻¹, 동기화 필터 25 Hz(2차), 120 Hz.
- G₀(제어효과)는 경기 시작 때 트림 상태에서 조종면을 ±0.02 움직여 생긴 각가속도로 잰다(중앙 차분, `kit/aircombat/control/indi.py` `identify_G0`). 비행 중에는 동압에 비례해 키운다.

### 4.3 두 제어기 구성

| | 원래 구성 | 실제형 구성 |
|---|---|---|
| 쓰는 실험 | 본실험 E0–E4, ASYM, E3X, P1–P6, **P9-a·P9-b** | **P7, P8, P9-c** |
| ① 구동기 | 속도 제한만(전 행정 0.3 s) | 1차 지연(20.2 rad/s, 시상수 약 0.05 s) + 속도 제한(승강타 60 °/s, 에일러론 80 °/s) |
| ② 각가속도 | 시뮬레이터 정답값 | 자이로 각속도를 차분해서 구함 |
| ③ 조종면 위치 측정 | 직전 명령 | 2틱 전 실제 구동기 위치(차분 각가속도와 시간 맞춤) |

| 동기 지연 | 측정값과 조종면 위치 기록이 **함께** n틱 늦게 들어오는 지연. 시간이 어긋나지 않아 진동이 덜하다 |
| 명령 전달 지연 | 유도 계층의 명령이 n틱 늦게 제어기에 들어가는 지연(P8). 제어 루프 밖이라 자체 진동을 만들지 않는다 |
| 한계 순환 (limit cycle) | 입력이 없어도 제어기가 스스로 일정한 진폭으로 계속 떠는 상태. 원래 구성은 측정이 1틱만 늦어도 생긴다 |
| 틱 | 제어 한 번의 시간 Δt = 1/120 s = 8.3 ms |
| 시상수 (τ) | 응답이 목표의 63 %까지 따라오는 데 걸리는 시간. κ는 τ ≈ κ·Δt를 만든다(κ 25 → 0.21 s) |
| 대역폭 | 제어기가 따라갈 수 있는 명령의 빠르기 상한. 낮으면 "둔하다" |
| 위상 지연 | 사인파 명령에 대해 응답이 늦는 정도(각도) |
| 등가 시간 지연 | 복잡한 응답 지연을 "순수한 시간 지연 몇 초"로 바꿔 나타낸 값. 비행성 규격이 상한을 정한다 |
| 비행성 (handling qualities) | 조종사가 기체를 얼마나 쉽고 정확하게 다룰 수 있는가. 규격 MIL-STD-1797이 대역폭·위상 지연·등가 시간 지연으로 평가한다 |
| 민첩성 (agility) | 기체가 기동 상태를 얼마나 빨리 바꾸는가. AGARD(NATO 항공연구자문단) 보고서가 지표를 정리했다 |
| 이득 여유 / 위상 여유 | 제어 루프가 불안정해지기까지 남은 이득(dB)과 위상(°)의 여유. 일반 기준 6 dB, 45° 이상 |
| 개루프 시험 | 교전 없이 정해진 시험 입력(이중펄스, 사인파)만 넣어 응답을 보는 시험. 원고에서는 "교전 없는 시험 비행" |
| 이중펄스 (doublet) | +, − 두 번 연속 넣는 계단 모양 시험 입력 |
| 둔한 형 오차 (sluggish) | 응답이 늦어 생긴 오차. 시간 이동이 크고(0.14 s 이상) 승강타 포화가 거의 없다. 원인: κ, 낮은 k_q, 명령 전달 지연 |
| 진동형 오차 (oscillatory) | 빠른 떨림으로 생긴 오차. 오차의 대부분이 1 Hz 이상(약 2–3 Hz)이고 승강타가 속도 한계에 자주 붙는다. 원인: 비동기 지연, 높은 k_q, 큰 σ |
| 시간 이동 (lag) | 명령과 응답의 상관이 가장 커지는 시간 차이. 응답이 몇 초 늦나 |
| 파워 / 빠른 몫 | 신호를 주파수로 나눴을 때 각 주파수의 세기(파워). "1 Hz 이상 몫" = 1 Hz 이상 성분의 파워 비율 |
| 중앙 주파수 | 파워를 절반씩 나누는 주파수. 교전 명령은 0.14 Hz |
| 각주파수 | ω = 2π·f [rad/s]. "자세 오차 ≈ 각속도 오차 ÷ 각주파수"에 쓰인다 |
| 승강타 포화 | 승강타가 움직일 수 있는 최대 속도(속도 한계)에 붙어 있는 상태의 시간 비율 |
| 잔차 | 실제 D − 곡선 예측 D. 양수면 곡선보다 결과를 더 바꿨다 |
| RMS | 제곱 평균의 제곱근. 예측 오차들의 대표 크기 |
| 표본 밖 예측 | 곡선을 맞출 때 쓰지 않은 조건(처음 보는 원인)을 예측하는 것 |
| LOO (하나 빼기 교차 검증) | 조건을 하나씩 빼고 나머지로 곡선을 맞춰 뺀 조건을 예측해 보는 방법. 곡선 모양(직선·제곱근·로그)을 고를 때 썼다 |
| OFAT | 한 번에 한 요인만 바꾸는 실험 설계(선행 실험) |
| 흔들림 바닥 (혼돈) | 열화가 있기만 하면 궤적이 조금 달라져 결과가 바뀌는 최소 수준(§7.1) |
| 공세 비율 | 내 기수가 상대를 30° 안에 두고, 상대의 기수는 나를 90° 이상 벗어난 시간의 비율(P9-a) |
| 정조준 체류 | 사거리 안에서 조준각 2–5° 안에 머문 시간의 비율 |
| 반등 | 한 기체만 열화할 때, 2틱에서 떨어졌던 점수가 6틱에서 다시 오르는 것. 반등 C = Δ점수(6틱) − Δ점수(2틱) |
| flaperon | 플랩과 에일러론을 겸하는 F-16의 날개 뒷전 조종면 |

### 7.2 구간과 검정

| 개념 | 설명 |
|---|---|
| 신뢰구간 (CI) | "참값이 이 범위에 있을 것"이라는 범위. 95 % CI는 같은 실험을 많이 반복하면 95 %가 참값을 포함하도록 만든 범위 |
| 독립 단위 = 시드 | 경기가 아니라 시드가 독립 반복이다. 같은 시드의 경기들은 서로 닮았다. 8개(gen·P6은 4개) |
| 퍼센타일 부트스트랩 | 시드 8개에서 중복을 허락해 8개를 다시 뽑아 2,000번 계산한 값의 2.5–97.5 % 범위. 시드가 4–8개로 적으면 뽑을 수 있는 조합이 적어 범위가 실제보다 **좁게** 나온다 |
| 시드 단위 t 구간 | 시드별 값의 평균 ± t × 표준오차(자유도 = 시드 수 − 1). 시드가 적을 때 더 보수적. **P5 이후 사전 등록은 두 방식이 같을 때만 결론**. E4의 시드 t는 결과를 본 뒤 계산했다(사후) |
| 98.33 % 구간 | 한 실험에서 대상 3명을 함께 검정해(ASYM, P2-b, P4 T-B, P9) 우연한 통과를 막으려고 1 − 0.05/3로 넓힌 구간(Bonferroni 보정) |
| 기술 점수 | 1 − RMS(곡선) ÷ RMS(상수). 기준 상수를 무엇으로 하느냐에 따라 0.44(E2 절편) / 0.40(E2 약한 열화 평균) / 0.30(검증 조건 평균, 결과를 본 뒤에만 아는 값). 본문은 0.44를 쓰고 셋을 모두 보고 |
| 다중성 | 검정이 많으면(약 30건) 우연히 통과하는 것도 는다. 그래서 핵심 결과를 새 시드에서 다시 확인했고 부록 C에 모든 검정을 공개한다 |

### 9.5 부록 C(전체 검정 일람표)에 필요한 계산

**2026-10-24 계산 완료** (`kit/supplementary/appc_tinterval.py` → `appc_tinterval_output.md`, 사후). 시드 t 구간이 없던 ASYM A1·A2, E3X 묶음, P2-b, P4 T-A·T-B·T-C·T-D를 계산했다. 퍼센타일 구간은 같은 난수로 다시 계산해 등록 보고서 값과 같음을 확인했다(E3X만 등록 값을 옮겨 적음). 곡선을 맞춘 시드와 검증 시드가 같은 E3X는 E3의 D-9와 같은 잭나이프 t를 주로 쓴다.
- 두 방식의 판정이 같음: 새 시드 재현 5건(T-A 동기 24·κ, T-B 두 대상, T-C), T-D 유형 대비, 반등 대비(원래 시드 +46.5·+36.1, 새 시드, P2-b 정밀 조준 기총), ASYM 기울기 b(반대 방향), E3X 동기 24 실패·k_q·σ 성공.
- t 구간에서 판정 불가로 바뀜: 원래 시드의 E3X κ 묶음(잭나이프 t 하한 +0.072 < 0.079. 곡선을 고정하면 +0.081로 실패. 새 시드에서는 두 방식 모두 실패), ASYM 개별 칸 30개 중 8개(GunTracker 2틱 하락 −19.5 포함, 반등 대비는 유지).
