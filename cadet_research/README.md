# 사용법

연구 주제: 피치 추종 오차를 이용한 공중전 성과 변화 예측: INDI 제어 F-16 시뮬레이션 연구

이 폴더 하나에 연구계획, 사전 실험 결과, 논문 뼈대, 실험 키트가 모두 들어 있다. 다른 저장소나 파일은 필요 없다.

## 1. 읽는 순서

| 순서 | 문서 | 무엇을 얻나 |
|---|---|---|
| 1 | `RESEARCH_PLAN.md` | 무엇을, 왜 하는지. 연구 질문, 실험 E0–E4, 결과별 해석 |
| 2 | `FEASIBILITY.md` | 주제를 고른 과정과 사전 실험 결과. 이 주제가 해 볼 만하다는 근거 |
| 3 | `PAPER_SKELETON.md` | 논문 뼈대. 제목부터 절별 분량까지. 본실험 결과를 넣을 자리가 비어 있다 |
| 4 | `kit/README.md` | 실험 키트의 설치, 실행 명령, 파일 설명 |
| 참고 | `REVIEW_LOG.md` | 작성 가이드(`논문작성법_과학적글쓰기.pdf`)에 맞춰 점검한 기록 |
| 참고 | `archive/` | 버린 주제의 문서. 읽지 않아도 된다 |

## 2. 처음 할 일

Python 3.12 이상이 필요하다.

```bash
cd kit
python -m pip install -r requirements.txt
python run.py --selfcheck
```

마지막 줄에 `E0 통과`가 나오면 준비가 끝난 것이다. 1분쯤 걸린다.

사전 실험 결과를 직접 확인하려면 이미 들어 있는 원자료로 분석만 다시 돌린다. 경기를 새로 돌리지 않으므로 몇 초면 끝난다.

```bash
python predict.py SIG
```

화면의 표가 `FEASIBILITY.md` §3.4와 같으면 된다.

## 3. 본실험

`kit/README.md` §2의 순서(E1 → E2 → E3 → E4)대로 돌린다. 앞 단계가 남긴 등록 파일이 없으면 다음 단계 분석기가 멈추므로 순서를 건너뛸 수 없다. 20 프로세스 기준으로 모두 합쳐 6.5–10시간이다. CPU 코어가 적으면 `--procs`를 줄이고 시간이 그만큼 늘어난다.

지킬 규칙은 세 가지다.

1. 본실험 시드(`main-*`, `cal-*`, `gen-*`)로 미리 돌려 보지 않는다. 연습은 `kit/README.md` §3의 `smoke` 방식으로 한다.
2. 엔진 폴더(`kit/aircombat/`, `kit/jsbsim_data/`, `kit/config/`)와 참가자 파일(`kit/agents/`)은 고치지 않는다.
3. 판정 기준은 결과를 보기 전에 정해져 있다(`RESEARCH_PLAN.md`). 결과를 본 뒤 기준을 바꾸지 않는다.

## 4. 결과가 나온 뒤

`PAPER_SKELETON.md`의 빈자리를 본실험 결과로 채운다. 결과에 따라 쓸 문장이 갈리는 곳은 [분기]로 표시되어 있다. 사전 실험 수치는 논문 본문에 넣지 않는다. 사전 실험은 주제를 고른 근거일 뿐이고, 논문의 결과는 본실험 결과다.

## 5. 아직 정하지 않은 것

사전 실험에서 나온 두 가지가 키트에 아직 반영되지 않았다. 본실험 전에 지도교수와 정한다.

| 항목 | 현재 키트 | 바꾼다면 |
|---|---|---|
| E3 열화 수준의 폭 | κ ≤ 50, 잡음 ≤ 6 °/s, 동기 지연 ≤ 16틱. 추종 오차가 0.75 °/s 근처까지만 나온다 | `FEASIBILITY.md` §3.4 수준(κ 100·400, 잡음 10·20, k_q 3, 동기 지연 24)을 `kit/experiments.py`의 `TEST`에 넣는다 |
| 적합 범위 밖의 판정 | 범위 구분 없이 모든 조건을 판정한다 | E2에서 나온 추종 오차 범위 안에서만 예측 성공·실패를 판정하고, 범위 밖 조건은 외삽으로 따로 보고한다 |

두 항목 모두 E2를 돌리기 전에 정해야 한다. 결과를 본 뒤 바꾸면 사후 선택이 된다.

결정 (2026-10-15, E1 실행 중, E2 분석 전): 두 항목 모두 현재 키트대로 한다. E3 수준은 κ ≤ 50, σ ≤ 6 °/s, 동기 지연 ≤ 16틱이고, 모든 E3 조건을 범위 구분 없이 판정한다. E2·E3 시드는 계획서대로 8개다.
