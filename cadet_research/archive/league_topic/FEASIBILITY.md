## 2. 결과

### 2.1 승·무·패와 추종

승·무·패는 360판에 걸친 전 참가자 합계다(한 판에 두 기록). 무접촉 판은 규칙상 두 참가자 모두 패로 센다.

| 조건 | 승 / 무 / 패 | 무접촉 판 | 피치 추종 상관 corr_q | 피치 추종 오차 [°/s] |
|---|---|---|---|---|
| BASE | 342 / 2 / 376 | 17 | 0.972 | 0.23 |
| SHAM | 341 / 2 / 377 | 18 | 0.972 | 0.23 |
| FILT10 | 338 / 2 / 380 | 21 | 0.973 | 0.21 |
| NOISE0.3 | 343 / 0 / 377 | 17 | 0.972 | 0.24 |
| ASYNC2 | 348 / 0 / 372 | 12 | 0.536 | 4.90 |
| KAPPA8 | 338 / 2 / 380 | 21 | 0.955 | 0.34 |
| KAPPA25 | 340 / 0 / 380 | 20 | 0.915 | 0.65 |

추종 지표는 선행 실험과 같은 방향으로 움직였다. 필터와 잡음은 추종을 바꾸지 않았고, κ와 비동기 지연은 추종을 떨어뜨렸다. 크기는 다르다. core2에서는 비동기 2틱의 영향이 훨씬 크고(선행 실험 corr_q 0.938 → 0.692, 여기서는 0.972 → 0.536), κ = 25의 영향은 작다. 두 엔진의 INDI 구현이 다르기 때문이다(README §6.3). 숫자를 직접 비교하지 말고 방향만 비교해야 한다.

### 2.2 판 일치율과 순위

판 일치율은 같은 (대진, 시나리오, 시드)에서 승자와 판정 사유가 BASE와 같은 판의 비율이다. 95 % CI는 판 단위 부트스트랩(2,000회)이다. τ는 4개 시드를 합친 리그 점수의 Kendall τ이며, CI는 시드 단위 부트스트랩이다.

| 조건 | 판 일치율 [95 % CI] | τ (합산) | τ 95 % CI | 1위 | 순위 (리그 점수) |
|---|---|---|---|---|---|
| BASE | 1.000 | +1.00 | | RedPrime | RedPrime 270 > EnergyFighter 210 > GunTracker 181 > LagAngler 156 > PurePursuer 148 > Extender 63 |
| SHAM | 0.983 [0.969, 0.994] | +1.00 | [+0.97, +1.00] | RedPrime | 같음 (LagAngler 153) |
| NOISE0.3 | 0.906 [0.875, 0.936] | +0.93 | [+0.83, +1.00] | RedPrime | EnergyFighter와 GunTracker 189 동점 |
| FILT10 | 0.892 [0.861, 0.922] | +0.87 | [+0.73, +1.00] | RedPrime | LagAngler ↔ PurePursuer 교환 |
| KAPPA8 | 0.861 [0.825, 0.897] | +0.87 | [+0.60, +1.00] | RedPrime | LagAngler ↔ PurePursuer 교환 |
| KAPPA25 | 0.800 [0.758, 0.842] | +1.00 | [+0.60, +1.00] | RedPrime | 같음. Extender 63 → 39로 격차 확대 |
| ASYNC2 | 0.633 [0.583, 0.683] | +0.69 | [+0.55, +1.00] | RedPrime | GunTracker 3위 → 5위, EnergyFighter 210 → 276 |

시드별 τ(같은 시드끼리 BASE와 비교)의 평균은 SHAM 0.98, NOISE0.3 0.94, FILT10 0.90, KAPPA8 0.86, ASYNC2 0.74, KAPPA25 0.68이다. KAPPA25는 합산 τ가 1.00인데 시드별 τ는 0.55–1.00으로 흔들린다. 시드 하나(90판)의 순위는 믿을 수 없다는 뜻이다.

## 3. 무엇을 알게 됐나

1. 실험 장치가 작동한다. 같은 시드를 다시 돌리면 결과가 완전히 같고(`--selfcheck`), 주입한 설정이 추종 지표를 예상한 방향으로 바꾼다. 판당 평균 4.7초(중앙값 3.2초)이므로 README §5.2의 22,000판은 20 프로세스로 1.5시간 안팎이다.
2. 잡음 바닥이 좁다. 가짜 변형에서 98.3 %의 판이 BASE와 같은 결과를 냈다. 그래서 다른 변형이 만드는 작은 변화도 구별된다. 나머지 5개 변형 조건은 판 일치율 CI가 모두 SHAM의 CI와 겹치지 않는다.
3. 신호에 크기 순서가 있다. 판 일치율은 SHAM > 잡음 ≈ 필터 > κ 8 > κ 25 > 비동기 지연 순이다. 추종을 많이 바꾸는 설정일수록 판도 많이 바뀐다.
4. 예상하지 못한 관측이 하나 있다. 필터 10 Hz와 잡음 0.3 °/s는 추종 상관을 전혀 바꾸지 않았는데도(0.972 → 0.973, 0.972) 판의 약 10 %를 뒤집었다. 혼돈계에서는 추종 지표로 보이지 않는 작은 차이도 300초 동안 커진다. 그래서 "추종이 같으면 판도 같다"는 성립하지 않는다. 남는 질문은 "추종이 같으면 순위는 같은가"이며, 연구의 핵심 질문(RQ1)은 판이 아니라 순위 수준에서 물어야 한다.
5. 순위 교환은 점수 간격과 관계가 있어 보인다. 필터와 κ 8에서는 BASE 점수 차가 8점으로 가장 작은 LagAngler–PurePursuer만 자리를 바꿨다. 추종을 가장 크게 바꾼 비동기 지연에서는 GunTracker가 25–33점 차를 넘어 3위에서 5위로 내려갔다. 1위 RedPrime과 6위 Extender는 일곱 조건 모두에서 그대로였다. 따라서 순위 강건성은 참가자 사이의 점수 간격과 함께 보고해야 한다.
6. 시드 4개로는 순위 판정을 할 수 없다. τ의 CI 하한이 0.55–0.83으로 넓다. 본 실험의 판정(README §6.2)을 하려면 시드를 늘려야 한다.

## 4. 본 실험 설계에 반영할 것

| 항목 | Feasibility에서 본 것 | 본 실험 설계 |
|---|---|---|
| 시드 수 | 4개로는 τ CI 하한이 0.55–0.83 | 16개 이상. 조건당 1,440판, 20 프로세스로 약 6분 |
| 참가자 | 6종, 이웃 순위 간 점수 차가 8–85점으로 고르지 않다 | 8–12종. 점수 간격이 고른 집합과 촘촘한 집합을 따로 둔다 |
| 주 지표 | 판 일치율은 예민하고 τ는 거칠다 | 판 일치율(1차, 민감)과 τ·1위 유지(2차, 대회 관점)를 함께 쓴다 |
| 해석 보조 | 순위 교환이 점수가 가까운 쌍에서만 일어났다 | 쌍별 점수 차와 교환 확률의 관계를 그린다 |
| 엔진 차이 | 비동기 지연 영향이 선행 실험보다 크다 | 선행 실험 수치와 직접 비교하지 않는다. 방향 비교만 한다 |
| 비대칭 조건 (E3) | 이번에는 돌리지 않았다 | `run_feas.py`의 `CFG["side"] = "blue"` 경로가 있다. 조건 정의만 추가하면 된다 |

## 5. 재현

저장소 루트에서 실행한다.

```bash
python cadet_research/feasibility/run_feas.py --selfcheck            # 약 15초
python cadet_research/feasibility/run_feas.py --procs 20 --salts 4   # 약 10분, out/games.csv
python cadet_research/feasibility/analyze.py cadet_research/feasibility/out/games.csv
```

원자료는 `feasibility/out/games.csv`(2,520행)이다. 열은 조건, 청군, 적군, 시나리오, 시드, 승자, 판정 사유, 양측 HP, 청군 피치 추종 상관과 오차, 실행 시간이다.
