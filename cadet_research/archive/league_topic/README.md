## 1. 요약

선행 실험은 INDI 제어기 설정이 명령 추종을 바꾸지만 승패는 거의 바꾸지 않는다는 결과를 얻었다. 이 연구는 그 결과를 실패로 보지 않는다. 제어기를 바꿔도 시뮬레이션 리그의 평가가 유지되는지 묻는 근거로 쓴다.

핵심 질문은 하나다. 모든 참가자가 같은 제어기를 쓰는 리그에서 INDI 설정을 바꾸면 참가자별 점수와 순위가 바뀌는가. 그리고 선행 실험이 "추종에 차이 없음"으로 판정한 설정은 리그 점수에서도 차이가 없는가.

사전 실험(2,520경기)에서 두 가지를 이미 관찰했다. 추종 지표를 전혀 바꾸지 않은 필터 변경도 개별 경기의 약 11 %를 뒤집었다. 비동기 측정 지연은 전술마다 점수를 반대 방향으로 바꿨다(EnergyFighter 증가, GunTracker 감소). 따라서 "추종 등가이면 평가도 등가"라는 가정은 검증해야 할 대상이다.

## 2. 배경: 선행 실험이 보인 것

### 2.1 시뮬레이션과 INDI

교전 환경은 JSBSim F-16 6자유도 모델 위에 5계층 조종 구조를 얹은 것이다. 전술 행동트리(L1, 20 Hz)가 추격 방식과 G 사용 수준을 고르면, 기본전투기동 유도(L2, 60 Hz)가 이를 G·뱅크·추력 명령으로 바꾼다. 제어 계층(L3, 120 Hz)은 자세 명령을 각속도 명령으로 바꾸고, INDI가 그 각속도를 내는 조종 입력을 계산한다.

INDI(Incremental Nonlinear Dynamic Inversion)는 지금 측정한 각가속도와 직전 조종 입력을 기준으로, 원하는 각가속도를 내는 데 필요한 조종 입력의 증분만 계산한다. 그래서 기체 모델 전체가 아니라 "조종 입력이 각가속도를 얼마나 바꾸는가"(제어효과 G)만 알면 된다.

### 2.2 선행 실험이 바꾼 설정

| 기호 | 뜻 | 쉽게 말하면 |
|---|---|---|
| κ (카파) | 제어효과 모델 오차 G_model / G_true (피치 행) | κ = 4면 제어기가 기체를 실제보다 4배 잘 돈다고 믿고 조종면을 덜 움직인다. 반응이 굼떠진다 |
| k_q | 피치 각속도 게인 배율 | 명령과 응답의 차이에 얼마나 세게 반응하나 |
| f_c | 동기화 필터 차단주파수 [Hz] | 센서 신호를 얼마나 부드럽게 거르나 |
| 동기 지연 | 측정과 조종 입력 기록을 함께 N틱 늦춤 (1틱 = 1/120 s) | 두 신호의 시각은 맞는다 |
| 비동기 지연 | 측정만 N틱 늦춤 | 두 신호의 시각이 어긋나 증분 계산이 틀어진다 |
| σ | 자이로 백색잡음 [°/s] | 각속도 센서의 떨림 |

### 2.3 선행 실험의 결과

출처는 모두 `EXPERIMENT_MASTER_20261001.md`이고, 수치는 수정 모델 재실행(A36, 4,480경기, 설정당 160 대응 쌍)이다.

| ID | 선행 실험의 주장 | 근거 위치 |
|---|---|---|
| P-01 | κ, k_q 감소, 동기 지연은 명령 추종을 판정 기준선 δ 이상 바꾼다. κ = 25에서 명령 계단 63 % 도달 비율이 0.794 떨어진다 | §5.8 판정표 |
| P-02 | 필터 10–50 Hz와 잡음 0.03–0.3 °/s는 도달 비율, 정상상태 비, 등가 지연 세 지표 모두에서 "차이 없음"이다. 측정 실패가 아니라 등가 판정이다 | §5.8, §7 문장 1 |
| P-03 | 추종 차이의 교전 결과 전달은 조건부다. κ에서는 역방향(추종은 나빠지고 조준·승률은 좋아짐), 대기 난류에서는 정방향으로 전달되고, 나머지 19개 설정에서는 전달되지 않는다 | §7 문장 3 |
| P-04 | κ = 25를 청군에만 주면 승률이 +18.3 %p다. 적군에도 같은 κ를 주면 +3.1 %p로 줄어든다(차이 −15.2 %p, 95 % CI [−25.0, −5.0]). 이득은 적과 달라서 생긴 상대적 우위다 | §5.8 대칭 조건 표 |
| P-05 | 교전 결과를 주 지표로 쓴 이전 판(A31, 수정 전 모델)에서는 판정 80건 중 58건이 "판정 불가"였다 | §1.5 |

### 2.4 다르게 읽기

선행 실험은 한 기체의 시선으로 "내 제어기를 바꾸면 내가 이기나"를 물었다. P-03과 P-05가 그 답이 대부분 "알 수 없거나 아니다"임을 보였다. 같은 결과를 대회 운영자의 시선으로 읽으면 질문이 바뀐다. 시뮬레이터의 제어기를 바꾸면 대회 순위가 바뀌는가. P-04는 모든 기체가 같은 설정을 쓰면 제어기 효과가 상쇄될 수 있음을 시사한다. P-02는 어떤 설정은 추종조차 바꾸지 않으므로 평가에도 영향이 없을 것이라는 예측을 준다.

## 3. 연구 공백과 질문

### 3.1 공백

시뮬레이션 리그는 전술 행동트리나 학습 정책을 평가하는 데 쓰인다. 이 저장소(core2)의 리그도 고정된 INDI 설정 하나로 순위를 매긴다. 이 순위가 제어기 설정 하나에 얼마나 의존하는지는 이 저장소에서 측정된 적이 없다. 선행 실험은 제어기 설정이 한 기체의 추종과 승률에 미치는 영향을 쟀지만, 참가자 여럿의 점수와 순위는 재지 않았다.

이 공백이 중요한 이유는 평가 결과를 어디까지 믿을 수 있느냐가 걸려 있어서다. 순위가 제어기 설정에 따라 바뀐다면 그 순위는 전술의 우열과 시뮬레이터의 특성을 함께 잰 것이다. 바뀌지 않는다면 제어기 설정은 평가에서 고정하지 않아도 되는 세부가 된다.

다른 연구에서 같은 질문을 다뤘는지는 아직 확인하지 않았다. §11의 근거 대기 목록에 찾을 문헌의 범위를 적었다.

### 3.2 연구 질문

| 번호 | 질문 | 답의 형태 | 주 지표 |
|---|---|---|---|
| RQ1 | 모든 기체에 같은 INDI 설정 변화를 걸 때, 참가자별 리그 점수가 δ 이상 바뀌는가 | 설정 × 참가자별 등가 판정 (차이 없음 / 판정 불가 / 차이 있음) | 참가자별 점수 변화 Δ점수 |
| RQ2 | 선행 실험의 추종 판정(P-01, P-02)과 RQ1의 점수 판정이 일치하는가 | 일치표. 추종 "차이 없음" 설정이 점수에서도 "차이 없음"인 비율 | RQ1 판정 + 선행 판정 |
| RQ3 | 점수 변화의 방향이 전술마다 다른가. 그 결과 순위가 바뀌는가 | 참가자 × 설정 점수 변화표, 순위 상관 τ, 1위 유지 | Δ점수의 부호, τ |
| RQ4 | 한 참가자에게만 설정 변화를 주면 그 참가자의 점수와 순위가 얼마나 움직이는가 | 대상 참가자별 등가 판정과 순위 이동 | 대상의 Δ점수 |

### 3.3 가설과 그 출처

가설은 실험 전에 고정한다. Feasibility에서 세운 가설(H3, H4)은 Feasibility 데이터로 확인할 수 없다. 시드가 겹치지 않는 확증 실행(E2, E3)에서만 판정한다.

| 가설 | 내용 | 출처 | 판정 실험 |
|---|---|---|---|
| H1 | 필터(10, 50 Hz)와 잡음(0.3 °/s)은 모든 참가자의 점수를 바꾸지 않는다(차이 없음) | P-02 | E2 |
| H2 | 비동기 지연 2틱과 κ = 25는 적어도 한 참가자의 점수를 바꾼다(차이 있음) | P-01, Feasibility | E2 |
| H3 | 비동기 지연 2틱에서 GunTracker의 점수는 줄고 EnergyFighter의 점수는 는다 | Feasibility(탐색) | E2 |
| H4 | κ = 25를 한 참가자에게만 주면 그 참가자의 점수가 오른다 | P-04 | E3 |

H1이 기각되어도 연구는 성립한다. "추종 지표로 보이지 않는 차이도 리그 점수를 바꾼다"는 결과가 되고, 이는 선행 실험의 "차이 없음" 판정을 평가 설계에 그대로 옮기면 안 된다는 경고가 된다.

### 3.4 기여와 근거

| 기여 | 무엇을 새로 알게 되나 | 근거가 될 결과 |
|---|---|---|
| K-1 | 이 리그에서 고정하지 않아도 되는 INDI 설정과 반드시 고정해야 하는 설정의 목록 | E2 판정표 (RQ1) |
| K-2 | 추종 등가 판정이 평가 등가로 이어지는지에 대한 직접 검증 | E2 판정표 + P-01·P-02 일치표 (RQ2) |
| K-3 | 제어기 설정 변화가 전술별로 다르게 작용한다는 증거와 그 크기 | E2 참가자 × 설정 표, 순위 표 (RQ3) |
| K-4 | 한 기체만 다른 제어기를 쓸 때 생기는 점수 이동의 크기 | E3 표 (RQ4) |

## 5. 문제 정의와 가정

### 5.1 시스템 경계

| 항목 | 정의 |
|---|---|
| 입력(바꾸는 것) | INDI 설정 하나. 대칭(모든 기체) 또는 비대칭(참가자 하나) |
| 고정하는 것 | 엔진 스냅샷(`kit/ENGINE_VERSION.txt`), 참가자 행동트리, 시나리오, 시드, 리그 규칙 |
| 출력(재는 것) | 경기별 승자와 판정 사유, 참가자별 리그 점수, 순위, 기체별 피치 추종 지표 |
| 독립 단위 | 시드 하나 = 리그 한 바퀴(모든 대진 × 시나리오 × 진영 교대). 같은 시드의 경기들은 초기 조건을 공유하므로 독립 표본이 아니다 |

### 5.2 가정과 그 영향

| 가정 | 영향받는 주장 | 점검 | 남는 한계 |
|---|---|---|---|
| A-1 core2 INDI는 선행 실험의 INDI와 같은 법칙을 따른다 | RQ2 (선행 판정과 비교) | 다르다. core2는 롤·피치 2축만 풀고, 정칙화 μ와 명령 피드포워드가 없으며, 각가속도를 JSBSim 값으로 직접 읽는다. 기준 잡음도 0이다(선행 실험 0.1 °/s) | RQ2는 판정의 방향만 비교한다. 수치를 직접 비교하지 않는다 |
| A-2 주입한 설정이 의도한 물리적 의미를 갖는다 | 전부 | E0 자가점검이 각 설정의 추종 효과를 확인한다 | 구동기 동특성과 센서 대역폭은 모델에 없다 |
| A-3 참가자 8종이 리그 점수 분포를 대표한다 | RQ3, RQ4 | E4에서 다른 12종으로 반복한다 | 행동트리 외의 정책(학습 정책)은 범위 밖 |
| A-4 무접촉 경기를 양쪽 패로 세는 규칙이 결론을 바꾸지 않는다 | RQ1, RQ3 | 승·무·패와 무접촉 경기 수를 조건마다 함께 보고한다 | 규칙을 바꾼 재분석은 계획에 없다 |

## 6. 실험 설계

### 6.1 공통 조건

| 항목 | 값 |
|---|---|
| 엔진 | `kit/` 의 core2 스냅샷 (flaperon 결함 수정 F-16, 2축 INDI, JSBSim 1.3.1) |
| 참가자 | E1–E3: 8종 (PurePursuer, GunTracker, LagAngler, EnergyFighter, Extender, TwoCircle, Reactive, RedPrime). E4: 다른 12종 |
| 대진 | 전원 총당(round-robin), 진영을 바꿔 2경기 |
| 시나리오 | headon, perch_offense, neutral (E4는 neutral_duel 추가) |
| 점수 | 승 3, 무 1, 무접촉 0(양쪽 모두 패) |
| 대응 설계 | 모든 조건이 같은 시드 세트를 쓴다. 조건 간 차이는 설정에서만 나온다 |

### 6.2 데이터 분리

| 시드 접두어 | 실험 | 쓰임 |
|---|---|---|
| `feas-*` (4개) | Feasibility | 가설 H3을 세운 탐색 데이터. 판정에 쓰지 않는다 |
| `cal-*` (16개) | E1 | δ를 정하는 데만 쓴다 |
| `main-*` (16개) | E2, E3 | 판정에만 쓴다. δ가 등록된 뒤에 실행한다 |
| `gen-*` (8개) | E4 | 일반화 확인 |
| `smoke-*` | 실행 점검 | 결과로 쓰지 않는다 |

분석기(`kit/analyze.py`)는 E1이 δ를 등록하기 전에는 E2–E4를 판정하지 않는다.

### 6.3 지표

| 지표 | 정의 | 역할 |
|---|---|---|
| Δ점수 | 참가자 하나의 리그 한 바퀴 점수를 같은 시드의 BASE와 뺀 값의 시드 평균 | 주 지표 (RQ1, RQ3, RQ4) |
| 승·무·패, 무접촉 경기 수 | 조건별 전 참가자 합계 | 모든 결과의 맨 앞에 보고 |
| 피치 추종 상관, 피치 추종 오차 | 기체별 경기 전체에서 피치 명령과 응답의 상관계수, 차이 절댓값의 평균 [°/s] | 주입 확인, RQ2의 연결고리 |
| Kendall τ | BASE 순위와 변형 순위의 순위 상관. 순서가 같은 쌍과 뒤집힌 쌍의 비율 차 | 보조 (RQ3) |
| 1위 유지 비율 | 시드 부트스트랩 표본에서 BASE 1위가 변형에서도 1위인 비율 | 보조 (RQ3) |
| 경기 일치율 | 같은 대진·시나리오·시드에서 승자와 판정 사유가 BASE와 같은 경기의 비율 | 보조. 무상관 기준과 함께 읽는다 |

경기 일치율을 주 지표로 쓰지 않는 이유가 있다. 교전은 작은 차이도 300초 동안 키우는 혼돈계다. Feasibility에서 비동기 지연의 일치율(0.633)은 "변형 경기를 BASE 결과 분포에서 새로 뽑았을 때"의 기대값(약 0.68)과 비슷했다. 이 지표는 일찍 바닥에 닿아 큰 효과끼리 구별하지 못한다. 대회에서 의미 있는 것도 개별 경기가 아니라 점수와 순위다.

### 6.4 판정

"차이가 없다"를 주장하려면 유의하지 않다는 결과만으로는 부족하다. 선행 실험과 같은 등가 판정을 쓴다.

1. 기준선 δ = max(2 × SHAM 짝 차이 |Δ점수|의 95 백분위수, 3점). SHAM은 물리적으로 구별할 수 없는 가짜 변형 κ = 1 + 10⁻⁶이다. 3점은 리그 한 바퀴에서 1승에 해당하는 실용 바닥이다. δ는 E1의 `cal-*` 시드로만 정하고 E2 전에 등록한다.
2. 각 (설정, 참가자)의 Δ점수에 대해 시드 단위 부트스트랩(10,000회) 신뢰구간을 구한다. 한 설정 안 참가자 8명에 Bonferroni 보정을 해서 99.375 % 구간을 쓴다.
3. CI ⊂ [−δ, +δ] 이면 차이 없음, CI가 δ를 완전히 넘으면 차이 있음, 그 밖은 판정 불가다.
4. 양성 대조는 κ = 25다. E2에서 적어도 한 참가자가 "차이 있음"이어야 판정 체계가 신호를 잡는다고 본다. SHAM은 모든 참가자가 "차이 없음"이어야 한다.

### 6.5 누락과 실패 처리

실행기는 요청한 경기 수와 기록된 경기 수를 매번 출력하고, 중단되면 같은 명령으로 이어서 돈다. 엔진 오류로 끝난 경기는 지우지 않고 기록한다. 분석기는 조건 하나라도 기록이 없으면 멈춘다.
