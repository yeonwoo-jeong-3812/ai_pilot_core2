# 추가 실험 사전 등록 (ASYM, E3X)

작성 2026-10-19, **실행 전**. 검토 의견 `FEEDBACK_FOR_CADET_v1.md`의 E-1, E-2를 실험으로 옮긴 것이다.
결정: 연구 책임자가 E-1 + E-2를 고름(2026-10-19).

**성격**: 본실험(E1–E4) 결과를 본 뒤에 추가한 실험이다. 등록된 E1–E4 판정은 바꾸지 않는다.
논문에는 "결과를 본 뒤 추가한 실험"이라고 명시하고 본실험 결과와 섞지 않고 따로 보고한다.
아래 기준은 실행 전에 고정하며, 결과를 본 뒤 바꾸지 않는다. 바꿔야 할 일이 생기면 바꾼 사실과 이유를 함께 보고한다.

## 1. 공통

| 항목 | 값 |
|---|---|
| 엔진·참가자·시나리오 | 본실험과 같다 (`kit/ENGINE_VERSION.txt`, 참가자 8종 `AGENTS_MAIN`, headon·perch_offense·neutral) |
| 시드 | `main-0`–`main-7`. 짝이 되는 BASE 경기는 이미 `kit/out/main/games.csv`에 있으므로 다시 돌리지 않는다 |
| 실행 | `kit/run_extra.py` (run.py의 주입·기록 `run.play`를 그대로 쓴다). 결과는 `kit/out/asym/`, `kit/out/e3x/` |
| 실행 PC | 본실험과 같은 PC. 다른 PC의 결과를 섞지 않는다 |
| 허용폭 | 새로 정하지 않는다. δ_D = 0.079 (`out/cal/tolerance.json`), 점수 δ = 11.10점 (`out/cal/delta.json`) |
| 실행 인공물 | `wall_clock`(실시간 120초 안전장치)으로 끝난 판은 절전 등 실행 환경 때문에 생긴 인공물이다. 실행이 끝나면 그 판을 지우고 한 번 다시 돌린다. 지운 판은 `wallclock_removed.csv`에 남기고 수를 보고한다 |

## 2. ASYM — 참가자 하나만 열화 (v1의 E-1)

**왜**: 대칭 열화에서는 아무도 더 지지 않으므로 D가 성과 저하를 재지 못한다(v1 §2.2, F-1).
한쪽만 열화하면 그 참가자의 점수 변화가 곧 성과 변화다.

| 항목 | 값 |
|---|---|
| 대상 | main BASE 점수 1위 RedPrime, 4위 GunTracker, 8위 Extender. 대상 기체만 열화하고 상대는 기준 제어기 |
| 조건 10개 | SHAM, 필터 25 Hz × 비동기 지연 0.5·1·2·4·6틱, κ 50, k_q 0.25, σ 6 °/s, 동기 지연 16틱 |
| 규모 | 대상 3 × 조건 10 × 시드 8 × (상대 7 × 시나리오 3 × 진영 2 = 42경기) = 10,080경기 |
| 주 지표 | 대상의 리그 한 바퀴(42경기) 점수 변화 Δ점수 = 열화 경기 점수 − 같은 경기의 BASE 점수 (승 3, 무 1, 무접촉 0). 시드 평균 |
| 예측 변수 | 대상 기체 자신의 피치 추종 오차 mae (대상이 청이면 `blue_mae_q_dps`, 적이면 `red_mae_q_dps`) |
| 보조 지표 | 대상의 승률 변화, 대상이 낀 경기의 결과 변화율 D |

**판정 (실행 전 고정)**

| ID | 질문 | 기준 |
|---|---|---|
| A1 | 조건·대상마다 점수가 바뀌는가 | Δ점수의 시드 부트스트랩 CI (2,000회, 대상 3명 Bonferroni → 98.33 %)를 δ = 11.10점과 비교. CI ⊂ [−δ, δ] "차이 없음", CI가 δ 밖 "차이 있음", 그 밖 "판정 불가". `analyze.py`의 비대칭 절과 같은 규칙 |
| A2 (주) | 추종 오차가 클수록 열화된 쪽 점수가 떨어지는가 | SHAM을 뺀 9조건 × 대상 3명 = 27점에 Δ점수 = 대상별 절편 + b·mae를 적합. b의 시드 부트스트랩 95 % CI가 0보다 완전히 작으면 "성립", 0을 포함하면 "성립하지 않음", 0보다 완전히 크면 "반대 방향" |
| A3 | SHAM은 점수를 바꾸지 않는가 (교정) | 대상 3명 모두 A1에서 "차이 없음". 아니면 A1·A2를 보고하되 교정 실패를 함께 적는다 |
| A4 (탐색) | 대상(전술)마다, 원인마다 기울기가 다른가 | 대상별·원인별 기울기를 기술만 한다. 판정하지 않는다 |

## 3. E3X — E3 검증 수준 확장 (v1의 E-2)

**왜**: 본실험 E3의 검증 수준은 사전 실험(SIG)에서 예측이 실패한 수준을 포함하지 않았다(v1 §2.3).
같은 수준을 넣어 적용 범위의 경계를 직접 잰다.

| 항목 | 값 |
|---|---|
| 조건 6개 (대칭) | κ 100·400, σ 10·20 °/s, k_q 3, 동기 지연 24틱 (SIG 수준) |
| 규모 | 6 × 시드 8 × 168경기 = 8,064경기 |

**판정 (실행 전 고정)**: 등록된 E2 곡선(직선, D = 0.144 + 0.0531·mae)과 등록 판정 규칙
(`predict.py`의 `validate`: 원인별 평균 예측 오차의 95 % CI를 ±δ_D와 비교)을 그대로 쓴다.

| ID | 무엇을 보고하나 |
|---|---|
| X1 | E3X 6조건만의 원인별 판정 (κ 2조건, σ 2조건, k_q 1조건, 동기 지연 1조건) |
| X2 | E3와 E3X를 합친 원인별 판정 (κ 8, σ 6, k_q 5, 동기 지연 5). E3 단독 판정은 바꾸지 않는다 |
| X3 | 조건마다 mae가 적합 범위(0.19–10.57 °/s) 안인지, D가 무상관 상한(0.403) 위인지 사실로 적는다. 범위 밖이라고 판정에서 빼지 않는다 |
| X4 | 원인별 기울기(E3 + E3X)를 v2의 D-1 표에 이어 붙인다 |

사전 실험(SIG)에서는 동기 지연 24틱 −0.348, κ 100·400 +0.100·+0.105가 나왔다. 같은 방향의 실패가 예상되며,
그 결과가 곧 적용 범위를 좁히는 근거다.
